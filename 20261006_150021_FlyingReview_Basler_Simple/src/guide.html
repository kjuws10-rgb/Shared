1. 물체면 1픽셀은 얼마나 작은가?

2.5 µm ÷ 20 = 0.125 µm / pixel

기본 영상 2600×2128 → FOV 0.325×0.266 mm.

20x는 200mm 튜브렌즈·1x Relay를 포함한 총배율 가정입니다. 렌즈의 광학 분해능은 약 1µm(NA0.28, λ550nm)이므로, 픽셀 크기가 측정 정확도를 뜻하지는 않습니다.

2. 노출 중 얼마나 길게 번지는가?

blur(px) = Y속도 × 노출(µs) ÷ 125

Y100 × 2µs ÷ 125 = 1.6 px = 0.2 µm

단위: Y속도 mm/s. X는 노출 중 정지하므로 blur에 X 이동속도를 더하지 않습니다. Global Shutter도 이동 blur는 발생합니다. 실제 잔류 X진동은 별도 검증합니다.

3. 허용 blur에서 노출·Y속도를 역산

노출 한계(µs) = 허용 px × 125 ÷ Y속도
Y속도 한계 = 허용 px × 125 ÷ 노출

허용 blur는 품질 요구값이며, 검출 성능을 보증하는 값은 아닙니다. 표는 blur 조건만 계산하며, 운전 가능 여부는 시간 조건까지 함께 봅니다.

4. X가 먼저 도착할 시간이 있는가?

다음 점까지 시간 = ΔY ÷ Y속도
다음 점까지 시간 ≥ 필요한 준비시간

필요 준비시간 = max(X이동 + 정착50ms + 여유20ms + 노출·지연·Jitter 여유, 카메라 주기). 기본 카메라 주기는 1/18.5 = 54.054ms. X이동 계산에는 가속·감속 모두 반영합니다.

fps는 재촬영 간격, 노출시간은 선명함.
두 조건은 따로 확인해야 합니다.

계산식 상세 · 개발자가 확인할 부분

센서 pixel p=2.5µm, 배율 M=20, 물체 pixel s=p/M=0.125µm/px.
이동량(µm)=vY(mm/s) × T(µs)/1000, blur=이동량/s.

X 이동은 정지→이동→정지. D=|X₂−X₁|, v=X속도, a=X가속도, b=X감속도.
vPeak=min(v, √(2D/(1/a+1/b))).
dA=vPeak²/(2a), dD=vPeak²/(2b), dC=max(0,D−dA−dD).
tMove=vPeak/a + dC/vPeak + vPeak/b.
같은 가감속이고 v에 도달하면 tMove=D/v+v/a. 도달하지 못하면 2√(D/a).

tNeed=max(T+tMove+0.05+0.02+50µs+2×5µs, max(1/18.5,T)+2×5µs).
여유=ΔY/vY−tNeed. 0 이상이면 명목 시간 조건 충족. 동일 Y의 서로 다른 X는 ΔY=0이므로 단일 Review 카메라로 동시에 촬영할 수 없습니다.

노출 중심 촬영: tCommand=tCross−tDelay−T/2. Y가 음의 방향이면 qCommand=qTarget+vY×(tDelay+T/2). 보정하지 않으면 평균 위치가 지연만큼 어긋납니다. Jitter는 위치 오차이며 이동 blur와 구분합니다.

Y 운동도 위 사다리꼴 식으로 계산합니다. Stage qStart=2345.9875mm, qEnd=−1584.5mm. 가공 첫 q=1845.9875mm, 마지막 q=622.7875mm → 등속이면 가공통과=1223.2/vY초.
전체 계산 Tact=Stage 전체 이동시간+기타60초+영상 여유1초. 가공 시작 전 선행500mm는 Stage 전체 이동에 포함하며, 30초 판정은 첫~마지막 가공점 통과시간입니다.

모든 가공점과 각 노출의 ±Jitter 구간이 Y 등속 구간 안에 있어야 합니다. 실제 Scanner/Laser 처리시간은 포함하지 않습니다. 기본값에서 Stage 이동39.504875초, 계산 Tact100.504875초, 가공통과12.232초입니다.
