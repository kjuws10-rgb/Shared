## 재생성 범위

Git 추적 파일 610개 각각에 문서를 만들었습니다. C# 파일 153개에서 타입 914개, 명시적 멤버 15,910개, 호출 위치 41,238개를 추출했습니다. XAML 57개에는 명명 요소 369개, 이벤트 272개, Binding 2,802개를 기록했습니다.

문서용 주석 사본은 336개 파일·663,476개 원문 행을 복원해 대조했습니다. 전체 텍스트 1,761,586행에는 복제하지 않은 CSV 행 수도 포함되므로 주석 사본의 행 수와 다릅니다. 검색 자료 31,299개는 기본 코드 21,025개와 선택용 생성 산출물 10,274개로 나눴습니다.

## 읽은 범위와 한계

변경된 90경로를 분류하고 코드·정의 및 영향을 받는 기존 소비자를 추적했습니다. 구조 담당은 48경로, Review 담당은 35경로의 검토 범위를 별도로 기록했습니다. 생성된 모든 멤버 해설을 사람이 런타임에서 검증한 것은 아닙니다. 프로그램 실행, Stage·Vision 연동, 물리 정밀도, 실제 운영 CSV를 이용한 재현은 수행하지 않았습니다. 후속 검증 시나리오는 계획이며 통과한 시험 수에 합산하지 않습니다.

운영·측정 CSV는 스키마만 제공합니다. SDK DLL은 경로·크기·해시와 호출 래퍼 근거만 제공합니다. 새 현장 주소값 4개가 출력에 재등장하지 않는 것을 확인했으며, 새 리터럴 비밀값 후보도 발견하지 못했습니다. 원본에서 물려받은 인코딩 이상은 원문 보존 예외로 구분했습니다. 인증정보, 개인 지식 작업실, 실측 CSV 행은 게시하지 않습니다.

문서 본문은 생성기 1.1.0과 추출기 1.0.3으로 작성했고, 물리 줄바꿈 정규화 수정은 생성기 1.1.1로 적용했습니다. 정규화는 원문 행 끝 공백을 나타내는 표식을 보존합니다. 구조 보고서의 링크·코드 블록·SVG, 게시 경로 범위는 [최종 검증 기록](validation.json)에 기록했습니다.
