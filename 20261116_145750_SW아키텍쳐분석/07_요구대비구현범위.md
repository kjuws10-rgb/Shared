# 요구 대비 구현 범위

이 표는 이번 Commit의 실제 범위를 설명합니다. 관련 UI가 보인다는 이유로 요구 전체가 완료됐다고 판단하지 않습니다.

| 요구/기대 | 소스에서 확인한 범위 | 추가 확인 |
| --- | --- | --- |
| 원하는 한 줄 Review | 같은 Glass 설계Y 실행가능점을 ONE_LINE으로 측정/저장 | Cell 범위·Masking 물리경로·Offset 적용 지원을 분리 |
| 기준 Shot 값 복사 | 결과 X/Y·JUDGE를 선택행에 복사하고 EDIT Revision 저장 | 최종 보정값 일괄 적용과 동일하지 않음; 출처열·형식별 소비 확인 |
| 오차를 사용자 범위로 레벨화 | 이번 source 검색에서는 사용자 Level1..N 임계값 편집 구현을 확인하지 못함 | MIN/MAX/UNIT 산포도 범위·Judge색·보정율%와 구분 |
| 직관적 결과 지도 | ShotMap·산포도·Grid·선택 수정 | 지도 초록은 결과존재이며 실측OK/EDITED OK와 구분 필요 |
| Default 중앙/55·110 기준 | AK1/AK3 X 평균, (head−4.5)×HeadGapX | AK3 설계 fallback/수동 입력과 새 실측 구분; Y/회전 보정 아님 |
| DOE없는 원빔 | 전역 1×1 Slot/Fit 지원, 1빔 실측점을 중심으로 사용 | 3 DOE+5 원빔의 Head별 혼합 구성/Beam11 대응은 별도 계약 |
| 옵셋 적용 전후 확인 | 선택 Shot·레이어별 현재 좌표 미리보기 | Station 실행 스냅샷·최종 Script와 대조 필요 |
| 수정 결과의 원복/재적용 | 원본을 덮지 않는 별도 EDIT/REINSP 파일 | Revision 파일 저장과 보정값 Rollback/계보 중복 차단은 별개 |
| 보호윈도우 교체 재시도 | 추가0~3회, Count 인계·OFF확인, 소진 LIGHT/AUTO계속 | 재시작·동일불량 Stage인계·정상완료 없는 소진 상태 평가 |
| 오프라인 알람 원인 설명 | 시간창·이전구간·규칙 후보·NG 요약 | 모델학습/원인확정 아님; 큰로그·시간순·상관키 검증 |

상세 근거는 [Review 영향](03_가공Review영향분석.md), [위험도](05_위험도별발견사항.md), [코드 레퍼런스 상세장](../A3%20LD%20Code%20Ref/README.md)을 따릅니다. 검증 시나리오는 계획이며 이번 문서 검사 통과 수에 포함하지 않습니다.
