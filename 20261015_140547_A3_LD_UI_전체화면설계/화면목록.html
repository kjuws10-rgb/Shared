A3 LD 전체 UI 화면 설계 · 74 PNG

295개 체크리스트와 고객 리뷰 28개 요약 반영 / 2026-10-15

모든 화면은 새 UI 구성 제안입니다. 실제 프로그램 캡처 또는 구현·검증 완료 증거가 아닙니다. 원본 소스는 변경하지 않았습니다. 로직 구현·실행 사양 설계는 포함하지 않습니다.
압축을 모두 푼 뒤 이 파일을 여세요. 이미지를 클릭하면 원본 가로 3840 px PNG (A01: 2160 px 높이 / 상세: 2560 px 높이)가 열립니다. 로직·통신주소가 미확정인 항목은 협의 필요로 표시했습니다.

추가 고객 요청 반영: Auto는 사이드메뉴 없는 단일 대시보드입니다. A02~A08 및 D02·D03은 탭·팝업이 아니라 같은 Auto 페이지 아래로 펼쳐진 상세 상태입니다. 비 Auto도 연계 작업을 통합 작업공간에 묶어 대상·입력·결과를 유지합니다.
74개 PNG는 74개 독립 메뉴를 뜻하지 않습니다. 같은 작업공간의 여러 표시 상태를 포함합니다. A01은 16:9 대표 화면, 나머지는 상세 작업영역 전체 높이 이미지입니다.
