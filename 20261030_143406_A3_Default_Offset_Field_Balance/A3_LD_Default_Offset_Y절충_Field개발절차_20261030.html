공통 출사 기준을 나누고, Head에는 남은 차이만 반영합니다.

왜 끝 Head의 Offset이 커지는가

한쪽에 맞추면 반대쪽 보정량이 커집니다. 전체 Head의 여유를 함께 봅니다.

추천 방식: 공통 Y 기준 + Head별 잔여 Default

먼저 8개 Head를 모두 측정합니다. 실제 MOF 출사 구간을 함께 바꿀 수 있으면 공통 기준을 가운데로 분담하고, 각 Head에는 남은 차이만 반영합니다. 지원 기능이 없으면 공통값은 0으로 두고 큰 오차는 기구 조정 대상으로 표시합니다.

스캐너 설치 위치를 옮긴다는 뜻은 아닙니다

1467/380 기구 기준은 유지합니다. Default가 적용된 16빔의 가상 중심과 실제 출사 엔코더 구간을 함께 맞춰, 기판의 같은 설계 위치를 가공하도록 하는 방식입니다.

측정 기준은 유지합니다

기판 기준·16개 빈 중심·1467/380 기구 관계를 먼저 확정합니다.

먼저 각 Head의 실측 거리를 구합니다

상단 Align의 Y는 기판 기준으로 보존합니다. 스캐너 Y Default는 그 값에 임의의 가공줄 거리·단차를 더해 맞추는 방식이 아니라, 같은 마크의 가공/Review 엔코더 차이로 Review–스캐너 거리를 측정해 맞춥니다.

작업 순서

  1. 선택 Head와 스캐너 열 확인가까운 열인지 먼 열인지 선택합니다. Head 번호만 보고 홀수/짝수로 자동 배정하지 않습니다.
  2. 가공 위치 도착 → 엔코더 저장 → 16빔 한 번 가공Stage를 정지하고 Scanner 기준 명령 Y=0, 추가 Shift=0, 현재 Default 적용 조건으로 시험합니다. 가공 당시 Main Y와 현재 Default·Head·마크 묶음 번호를 저장합니다.
  3. 출사 종료 → 기판을 Review 쪽으로 되돌리기방금 가공한 같은 마크 묶음을 Review 아래로 가져옵니다. 가공 전 Review를 통과했을 때는 아직 이 마크가 없으므로, 가공 후 되돌려 확인합니다.
  4. 16개 중심을 Review 화면 중앙에 맞추기자동 탐색·16/16 측정·빈 가운데 계산·중앙맞춤을 진행하고 실제 도착한 Main Y를 저장합니다.
  5. 실측 거리 → 오차 → 추천 새 Default 계산가공 Y와 Review Y의 차이에 축 방향을 반영해 실측 거리를 구합니다. 해당 열의 기준거리 대비 편차를 저장한 뒤, 아래 공통 기준과 Head별 잔여를 함께 계산합니다.
  6. 새 Default 적용 → 새 시험가공으로 확인새 마크를 가공하고 다시 왕복 측정합니다. 고정 기준 모드는 1277/1657, 공통 출사 기준 모드는 1277+c/1657+c와 비교합니다. 두 열의 설계 간격은 380 mm로 유지합니다.

실측 거리 = 축 방향 × (가공 당시 Main Y − Review 중앙맞춤 Main Y)

추천 공통값과 Head별 새 Default

현재값까지 포함한 새 총값을 계산합니다.

값계산·의미
rₕ: 열 기준 대비 편차실측 거리 Dₕ − 해당 열 기준거리 (1277 또는 1657)
c: 추천 공통 Y 기준설계 기구거리의 변경이 아니라, 실제 가공에 사용할 공통 광학 Y 기준의 이동량
Head별 물리 수정량c − rₕ
추천 새 Default Y현재 Default Y + (c − rₕ) ÷ Head 입력 반응 kₕ
공통 출사 구간 변경현재 출사 엔코더 + 축 방향 s × (새 공통값 c − 현재 공통값)
적용 후 기대 실측 거리가까운 열 1277+c / 먼 열 1657+c
새 가공 검증 잔차적용 후 실측 거리 − (해당 열 기준거리+c)
처음 계산은 양끝의 중간값으로 이해하면 됩니다

모든 Head의 현재 Default가 0이고 Field 여유·입력 반응이 같다면 c=(가장 작은 편차+가장 큰 편차)÷2입니다. 예: 0~14 mm → 공통 7 mm / Head 잔여 +7~−7 mm. 기존 Default가 다르면 이 식만 쓰지 않고, 각 Head의 최종 패턴과 새 총 Default로 추천합니다.

개발식 · 같은 기판 위치가 유지되는 이유
// Review를 기계 Y=0, 엔코더 증가방향 s=+1인 예
기판상의_가공위치 = 실제_광학Y - s * 실제_출사엔코더
기준모드: Dnom - s * Qref
공통모드: (Dnom+c) - s * (Qref+s*c)
// 두 결과가 같음. 실제 출사 엔코더·실행구간을 바꿔야 성립.
// 현재 공통값이 c_old라면 엔코더 변경은 s*(c-c_old).
// c를 Script/Default에 다시 더해 최종 Galvo가 같아지면 Field 개선은 없음.

작업 순서

X 완료 후 측정 → Field 검사 → 추천 → 일괄 적용 → 새 가공 확인.

  1. X 정렬 완료 → 현재값 저장기판 중앙·설계 Pitch를 유지합니다. 현재 공통 기준, Head Default, Recipe/보정 버전을 함께 저장합니다.
  2. 8개 Head의 16빔 중심과 Y 거리 측정각 Head를 정지 시험가공하고 같은 16개 마크를 Review에 되돌립니다. 가공 Y·Review Y로 실측 거리를 계산하고 소속 열의 1277/1657을 빼 편차를 모읍니다.
  3. 실제 Field 여유 계산사용할 Recipe 전체 점·16개 분기빔·현재 보정과 앞으로 허용할 보정 여유를 합쳐 Head별 가용 범위를 구합니다.
  4. 추천 공통 기준 + 새 Default 계산가장 Field 여유가 부족한 Head의 부담을 줄이는 공통값을 찾습니다. 현재 Default까지 포함한 새 총값을 계산합니다. 불가능하면 적용 버튼을 비활성화합니다.
  5. 공통 기준·MOF 출사 구간·Head Default 함께 적용Stage/PGM에서 실제 출사 엔코더를 변경하고, 바뀐 기준으로 좌표·버퍼·이동 범위를 다시 검사합니다. 한쪽만 적용되면 가공을 시작하지 않습니다.
  6. 새 가공으로 기판 위치와 Field 확인가상 중심 거리의 공통 이동분과 Head 잔차, 설계 홀의 실제 가공 위치, Field 경계 여유를 확인한 뒤 저장합니다. Simple/Rough/Fine는 그다음에 진행합니다.

추천 알고리즘 · 개발 순서
1. Head별 동일 마크의 가공/Review 엔코더와 현재값 Snapshot을 검증한다.
2. r = s*(가공Y-ReviewY) - rowNominal을 계산한다.
3. 각 Head의 기존 Default를 포함해 새 총값 Bnew=Bnow+(c-r)/k로 둔다.
4. 현재 공통값=0이고 공통 변경 미지원이면 c=0으로 제한한다.
   현재 공통값≠0인데 변경 지원이 끊기면 추천을 차단한다.
5. 전체 패턴·16빔·기존 보정·예비 보정으로 Field 가용범위를 만든다.
6. 모든 Head가 만족하는 c 구간을 구한다. 없으면 INFEASIBLE.
7. 구간 내에서 가장 부족한 Head의 정규화 Field 여유를 최대화한다.
8. 비선형/회전/축간 영향이 있으면 실제 XY 변환·Field로 전점 재검사한다.
9. 출사·트리거·이동범위와 기판상 설계좌표 등가성을 검증한다.
10. 공통 기준+PGM/버퍼+Default를 일괄 적용, 새 가공으로 확인한다.
