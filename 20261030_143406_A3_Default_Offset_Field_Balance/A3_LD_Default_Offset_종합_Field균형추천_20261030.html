셋업 전체 흐름

기판 기준은 한 번 저장하고, Head마다 16개 마크의 중심을 찾아 X와 Y를 맞춥니다.

찾는 대상

선택 Head가 한 번 출사해 만든 4×4 마크 16개의 가운데입니다.

이동하는 축

Review X와 Main Y를 움직여, 계산한 가운데를 Review 화면 십자선 중앙에 놓습니다.

그다음 적용

X는 기판 목표와 측정 중심을 비교합니다. Y는 가공/Review 거리의 편차를 구하고 공통 출사 기준·Head 잔여를 함께 계산합니다.

두 동작의 차이

[중심으로 이동]은 카메라가 보는 위치를 바꿉니다. [Default 입력]은 다음 레이저 가공 위치를 바꿉니다. 중심을 찾았다는 이유만으로 Default를 자동 변경하지 않습니다.

이번 추천의 핵심

설치 기울기 때문에 끝 Head의 Default가 커지면, 지원되는 실제 Y 출사 기준과 Head 잔여를 나눕니다. 전체 패턴이 Field 안에 들어오지 않으면 추천값을 만들지 않고 조정할 Head와 부족 여유를 표시합니다.

1. 상단 Align 2개로 기판 기준 저장

가운데를 계산하는 단계와, 실제 도착한 위치를 저장하는 단계를 나눕니다.

  1. [좌상단 Align 측정]좌측 상단 Align 마크를 Review 화면 십자선 중앙에 맞추고 [현재 위치 저장]을 누릅니다. Review X와 Main Y 엔코더값을 mm로 저장합니다.
  2. [우상단 Align 측정]우측 상단 Align 마크도 같은 방법으로 측정합니다. 좌·우 위치를 화면에 함께 표시합니다.
  3. [가운데 계산]두 X값의 평균과 두 Y값의 평균을 계산합니다. 화면에는 계산 위치를 먼저 보여줍니다.
  4. [가운데로 이동]계산 위치로 Review X와 Main Y를 이동합니다. 이동 중에는 저장 버튼을 끄고, 도착 확인 후 켭니다.
  5. [기판 기준 저장]실제 도착한 엔코더값을 저장합니다. 이름은 ‘기판 중앙 X’와 ‘상단 기준 Y’로 표시합니다.
기판 기준과 Y Default 거리를 구분합니다

저장한 중앙 X와 상단 Y는 기판 기준입니다. Y 측정의 설계 기준거리는 가까운 열1277 / 먼 열1657 mm입니다. 공통 출사 기준을 분담한 뒤의 목표는 각각 기준거리+c입니다. 상단 Y에 300 mm나 임의의 2 mm 단차를 더한 이전 예제는 이 절차에서 사용하지 않습니다.

2. 실제 마크 16개로 ‘빈 가운데’를 계산

한 번 가공하면 4×4 배열의 마크가 생깁니다. 가운데에 홀을 하나 더 찾는 작업이 아닙니다.

시험가공 조건을 먼저 맞춥니다

선택 Head의 중앙 명령 (0, 0)에서 한 번 출사합니다. 추가 X/Y Shift는 0으로 두고, 현재 Default X/Y는 적용한 상태로 가공합니다. 이렇게 만든 16개 중심을 그 Head의 현재 가공 중심으로 비교합니다.

  1. 선택 Head로 한 번 시험가공Head 번호와 가공줄을 선택합니다. 가공할 때의 Main Y 위치와 현재 Default를 기록하고, 다른 시험가공과 구분되도록 새 마크 묶음 번호를 붙입니다.
  2. 16개 마크의 위치 측정한 화면에 다 보이면 한 번에 측정하고, 다 보이지 않으면 카메라를 이동해 나누어 측정합니다. 같은 묶음의 16개 마크를 모읍니다.
  3. X 평균·Y 평균 계산각 마크의 위치를 mm로 모은 후, X 16개를 더해 16으로 나누고 Y도 같은 방법으로 계산합니다.
  4. 계산한 중심 표시·이동16/16 측정이 끝나면 중심 좌표를 표시합니다. 이 중심이 해당 Head의 가공 위치입니다.
측정 화면에 꼭 보여줄 것

마크 번호 1~16, 측정한 개수, 각 마크의 X/Y, 계산한 중심 X/Y. 빠진 마크는 해당 마크만 다시 측정한 뒤 중심을 계산합니다.

3. 카메라 설정으로 픽셀을 이동거리로 바꾸기

해상도와 렌즈 배율에 센서 픽셀 크기까지 알아야 mm로 계산할 수 있습니다. 실제 FOV를 재서 입력해도 됩니다.

4. 먼저 ‘축을 움직이면 화면에서 어디로 가는지’ 확인

같은 마크를 보면서 Review X와 Main Y를 각각 조금 움직입니다. 화면의 좌우·상하를 축의 ±방향으로 단정하지 않습니다.

  1. 기준 마크를 화면 안에 놓고 촬영이때의 실제 Review X/Main Y 엔코더와 마크 픽셀 위치를 저장합니다.
  2. Review X를 +/− 시험 이동도착하고 흔들림이 멈춘 뒤 같은 마크를 다시 촬영합니다. 실제 엔코더 차이와 픽셀 차이를 모읍니다.
  3. Main Y도 +/− 시험 이동X와 같은 방법으로 반복합니다. 시험 이동 중 마크가 시야에서 나가지 않게 이동량을 정합니다.
  4. 방향·비율 저장 → 중앙맞춤 시험두 축의 영향으로 변환값을 만들고, 임의의 화면 위치에서 마크가 십자선 중앙으로 오는지 시험합니다.
개발 상세 · 실제 이동 보정행렬 J
J = [[Δu/ΔReviewX, Δu/ΔMainY],
     [Δv/ΔReviewX, Δv/ΔMainY]]     # 단위: pixel/mm

목표 이동량 = inverse(J) × (화면 중앙 픽셀 − 마크 픽셀)
다음 엔코더 목표 = 현재 실제 엔코더 + 목표 이동량

# +/− 여러 샘플로 J를 계산하고 역행렬·반복오차를 검사
# 2축의 영상 영향이 구분되지 않으면 보정 실패 처리
추천 Default 계산과 다른 값입니다

이 J는 Review 카메라를 중앙에 맞추기 위한 축 이동 관계입니다. 스캐너 Default 입력을 늘렸을 때 가공점이 이동하는 관계는 Head별로 별도 측정합니다. Align 카메라의 보정값을 Review 축에 그대로 사용하지 않습니다.

5. 어느 시작 위치에서도 마크를 찾는 탐색

현재 화면과 예상 가공 위치를 먼저 확인하고, 없으면 설정된 검색영역을 지그재그로 훑습니다.

  1. 현재 화면 → 선택 Head 예상 위치 확인찾으려는 Head와 이번 시험가공 묶음을 선택합니다. 현재 화면에 없으면 예상 위치를 확인합니다.
  2. 검색영역을 겹친 촬영 위치로 나누기X/Y 최소·최대 위치와 겹침 비율을 사용합니다. 예: 유효 FOV의 20%가 서로 겹치게 이동합니다.
  3. 도착 → 정지 안정 → 촬영 → 마크 저장촬영할 때 실제 엔코더와 프레임 번호를 함께 저장합니다. 마크가 없으면 다음 위치로 진행합니다.
  4. 일부를 찾으면 해당 묶음 주변부터 수집한 개만 보이면 4×4 중 몇 번째인지 아직 모릅니다. 주변을 더 측정해 16개 전체를 확정합니다.
  5. 끝까지 없으면 미발견으로 종료찾은 위치·탐색한 영역·남은 영역을 보여주고 영역 확대나 수동 선택으로 이어갑니다.
개발 상세 · 누락 없는 탐색과 묶음 구분
문제처리
화면 가장자리 잘린 마크가장자리 여유를 뺀 유효 FOV로 탐색 간격을 정합니다. 잘린 마크는 다음 겹친 화면에서 다시 측정합니다.
카메라가 회전한 경우보정된 FOV 네 모서리를 축 좌표로 옮겨 촬영 범위가 전체 영역을 덮는지 확인합니다. 영상 가로폭을 축 X 간격으로 그대로 쓰지 않습니다.
다른 시험가공 마크 혼입새 시험가공 영역과 Head별 예상 범위를 분리합니다. 같은 모양의 묶음이 여럿이면 작업자에게 한 묶음을 선택하게 합니다.
영역 밖/이동 제외구역해당 구역은 탐색 미완료로 표시합니다. 어디서든 무조건 성공했다고 처리하지 않습니다.
시간·촬영 수 제한검색 시간·촬영 수·최대 이동량·최대 재시도를 설정값으로 관리합니다.
기록촬영 위치·유효 촬영 범위·발견 마크·시도 결과를 남겨 미발견과 이동 불가를 구분합니다.

6. 한 번에 보이든 나누어 보든 ‘16/16’으로 모으기

16개 마크 각각의 중심을 측정합니다. 밝은 마크에 더 큰 비중을 주지 않고, 한 마크당 한 값으로 모읍니다.

검사완료 조건
같은 시험가공선택 Head·이번 시험가공 영역에 속한 한 묶음
16개 고유 위치4줄 × 4열, 각 칸에 실측 마크 1개
배치 확인설정 Pitch·회전·가로세로 전체 폭(3×Pitch)·배열 오차 확인
중복 제거같은 마크가 여러 화면에 보이면 하나로 합치고 더 좋은 측정을 사용
누락 처리실측이 빠지면 해당 위치 재측정. 15개 평균이나 가상 생성값으로 완료 처리하지 않음
방향 확인대칭 4×4의 중심은 회전해도 같지만, 대칭 모양만으로 빔 번호 방향을 확정하지 않음
개발 상세 · 탐지와 4×4 맞춤
  1. 마크 후보 찾기십자/원 등 선택 형상에 맞춰 중심을 검출하고 크기·대비·잘림 여부를 확인합니다. 전체 영상의 밝기 무게중심을 사용하지 않습니다.
  2. 같은 축 좌표로 변환각 촬영의 실제 엔코더와 보정값으로 마크 위치를 계산합니다. 중복 허용거리는 측정 반복오차보다 크고 빔 간격보다 충분히 작게 정합니다.
  3. 4×4 배열에 고유 배정대략적인 회전·Pitch를 찾아 후보를 줄/열에 배정하고 이상 후보를 제외합니다. 배열 맞춤은 묶음 식별용이며 유효한 실측 편차를 설계 격자로 덮어쓰지 않습니다.
  4. 16개 모두 확인 후 중심 계산다른 묶음이 섞였거나 한 칸이 중복/누락이면 중심 이동을 보류하고 다시 측정합니다.

7. 16개 위치를 평균해 중심 엔코더 계산

촬영 위치가 달라도, 각 마크의 위치를 같은 Review X/Main Y 기준으로 바꾸면 가운데를 구할 수 있습니다.

마크 위치 = 촬영 엔코더 + 그 마크를 화면 중앙에 맞추는 이동량
16빔 중심 = 마크 위치 16개의 평균
개발 상세 · 서로 다른 촬영 위치를 한 좌표로 모으는 식
p0 = ((W-1)/2, (H-1)/2)      # 같은 영상 좌표의 화면 중앙
q_i = q_capture_i + inverse(J) × (p0 - p_i)
q_center = sum(q_i for 16 measured marks) / 16

8. 중심을 FOV 중앙으로 옮기는 반복 동작

한 번 계산해 이동한 뒤 반드시 다시 확인합니다. 남은 오차만큼 작은 이동을 반복합니다.

  1. 중심 목표와 현재 엔코더 차이 계산다음 목표는 계산한 16빔 중심입니다. 작업자가 이동 방향을 따로 판단하지 않게 X/Y 이동량을 표시합니다.
  2. 이동상한을 적용해 요청큰 오차는 한 번 이동상한으로 나누어 접근합니다. 목표·속도·구동 모드를 먼저 기록한 뒤 이동을 요청합니다.
  3. 실제 도착·정지 안정 후 새 이미지 획득이전 프레임이나 이전 동작의 완료 신호로 다음 단계에 가지 않습니다.
  4. 중심을 다시 계산해 잔여오차 판정X/Y 오차가 설정 μm 이내이면 확인 완료입니다. 초과하면 제한 횟수 안에서 재이동합니다.

11. 카메라 설정과 중앙맞춤 계산을 직접 확인

해상도·픽셀 크기·배율을 바꾸고 [예제에서 1회 이동]을 누르면 남은 오차가 줄어드는 모습을 볼 수 있습니다.

카메라 입력

계산 중심·현재 위치·이동 조건 바꾸기
계산 예제 동작

이 예제는 가상의 16개 마크와 축 응답으로 계산합니다. 실제 장비나 Default 값을 바꾸지 않습니다. 화면 밖/작은 FOV에서는 먼저 16개를 수집해야 하므로 바로 중앙맞춤 성공으로 넘기지 않습니다.

개발 상세 · 예제와 실제 구현 연결

예제의 A는 ‘마크가 화면 중앙에서 벗어난 픽셀 → 중앙에 맞추기 위한 축 이동량’ 변환이며 A = −J⁻¹입니다. 회전·반전·픽셀 크기를 바꿔 계산합니다. 실제 구현은 시험 이동으로 얻은 J, 왜곡 보정, 이동 후 새 영상을 사용합니다.

12. 수동 단위 동작도 같은 중심 계산으로 연결

자동 탐색이 어려운 마크는 작업자가 직접 선택하거나 화면 중앙에 맞춰 저장할 수 있습니다.

마크 하나의 중앙맞춤과 16개 가운데 이동

마크 하나를 화면 중앙에 맞춰 저장하는 동작은 16개 위치를 수집하는 방법입니다. 16개를 모은 뒤 평균한 위치로 다시 이동해야 전체 가운데에 도착합니다.

13. X Default: H4·H5부터 좌우 간격 맞추기

저장한 기판 중심에서 각 Head의 목표 X를 구하고, 실제 16마크 중심과 비교합니다.

  1. H4·H5 시험가공 → 각각 16개 측정두 Head를 구분해서 가공하고 각 Head의 중심 X를 계산합니다.
  2. [X 추천값 계산]설계 간격과 저장된 기판 중심으로 목표 X를 구합니다. 목표에서 실측 중심을 빼 필요한 이동량을 구합니다.
  3. [H4 X 입력] / [H5 X 입력]Head별 방향을 반영한 추천 새 Default X를 입력합니다. 현재값·입력할 보정량·추천 새값을 함께 보여줍니다.
  4. [새 가공으로 X 확인]바뀐 Default로 새 마크를 가공합니다. 16개를 다시 측정해 목표 X와 차이가 줄었는지 확인합니다.
  5. 3·6 → 2·7 → 1·8도 같은 방법모든 Head의 목표는 저장한 기판 중심과 설계 간격에서 직접 구합니다. 바로 옆 Head의 측정 오차를 이어받지 않습니다.
X도 Field 여유를 확인합니다

기판 중앙과 설계 Pitch는 유지합니다. 공통 X 분담은 실제 기판 X 정렬까지 지원하는 경우에만 사용하며, Review X 카메라 이동으로 대신하지 않습니다. Y 기울기 보상에 실제 회전을 쓰면 X도 다시 측정합니다.

14. Y Default: 측정한 뒤 공통 기준과 Head 잔여로 나누기

X를 맞춘 다음, 8개 Head의 Y 편차를 모아 끝단의 과대 보정을 줄입니다.

추천 방식: 공통 Y 기준 + Head별 잔여 Default

먼저 8개 Head를 모두 측정합니다. 실제 MOF 출사 구간을 함께 바꿀 수 있으면 공통 기준을 가운데로 분담하고, 각 Head에는 남은 차이만 반영합니다. 지원 기능이 없으면 공통값은 0으로 두고 큰 오차는 기구 조정 대상으로 표시합니다.

스캐너 설치 위치를 옮긴다는 뜻은 아닙니다

1467/380 기구 기준은 유지합니다. Default가 적용된 16빔의 가상 중심과 실제 출사 엔코더 구간을 함께 맞춰, 기판의 같은 설계 위치를 가공하도록 하는 방식입니다.

먼저 각 Head의 실측 거리를 구합니다

상단 Align의 Y는 기판 기준으로 보존합니다. 스캐너 Y Default는 그 값에 임의의 가공줄 거리·단차를 더해 맞추는 방식이 아니라, 같은 마크의 가공/Review 엔코더 차이로 Review–스캐너 거리를 측정해 맞춥니다.

작업 순서

  1. 선택 Head와 스캐너 열 확인가까운 열인지 먼 열인지 선택합니다. Head 번호만 보고 홀수/짝수로 자동 배정하지 않습니다.
  2. 가공 위치 도착 → 엔코더 저장 → 16빔 한 번 가공Stage를 정지하고 Scanner 기준 명령 Y=0, 추가 Shift=0, 현재 Default 적용 조건으로 시험합니다. 가공 당시 Main Y와 현재 Default·Head·마크 묶음 번호를 저장합니다.
  3. 출사 종료 → 기판을 Review 쪽으로 되돌리기방금 가공한 같은 마크 묶음을 Review 아래로 가져옵니다. 가공 전 Review를 통과했을 때는 아직 이 마크가 없으므로, 가공 후 되돌려 확인합니다.
  4. 16개 중심을 Review 화면 중앙에 맞추기자동 탐색·16/16 측정·빈 가운데 계산·중앙맞춤을 진행하고 실제 도착한 Main Y를 저장합니다.
  5. 실측 거리 → 오차 → 추천 새 Default 계산가공 Y와 Review Y의 차이에 축 방향을 반영해 실측 거리를 구합니다. 해당 열의 기준거리 대비 편차를 저장한 뒤, 아래 공통 기준과 Head별 잔여를 함께 계산합니다.
  6. 새 Default 적용 → 새 시험가공으로 확인새 마크를 가공하고 다시 왕복 측정합니다. 고정 기준 모드는 1277/1657, 공통 출사 기준 모드는 1277+c/1657+c와 비교합니다. 두 열의 설계 간격은 380 mm로 유지합니다.

16. 추천값 계산: 공통 기준·현재 Default·Field를 함께 사용

기판상 설계 위치를 유지하면서 가장 여유가 부족한 Head의 부담을 줄입니다.

값계산·의미
rₕ: 열 기준 대비 편차실측 거리 Dₕ − 해당 열 기준거리 (1277 또는 1657)
c: 추천 공통 Y 기준설계 기구거리의 변경이 아니라, 실제 가공에 사용할 공통 광학 Y 기준의 이동량
Head별 물리 수정량c − rₕ
추천 새 Default Y현재 Default Y + (c − rₕ) ÷ Head 입력 반응 kₕ
공통 출사 구간 변경현재 출사 엔코더 + 축 방향 s × (새 공통값 c − 현재 공통값)
적용 후 기대 실측 거리가까운 열 1277+c / 먼 열 1657+c
새 가공 검증 잔차적용 후 실측 거리 − (해당 열 기준거리+c)
처음 계산은 양끝의 중간값으로 이해하면 됩니다

모든 Head의 현재 Default가 0이고 Field 여유·입력 반응이 같다면 c=(가장 작은 편차+가장 큰 편차)÷2입니다. 예: 0~14 mm → 공통 7 mm / Head 잔여 +7~−7 mm. 기존 Default가 다르면 이 식만 쓰지 않고, 각 Head의 최종 패턴과 새 총 Default로 추천합니다.

개발식 · 같은 기판 위치가 유지되는 이유
// Review를 기계 Y=0, 엔코더 증가방향 s=+1인 예
기판상의_가공위치 = 실제_광학Y - s * 실제_출사엔코더
기준모드: Dnom - s * Qref
공통모드: (Dnom+c) - s * (Qref+s*c)
// 두 결과가 같음. 실제 출사 엔코더·실행구간을 바꿔야 성립.
// 현재 공통값이 c_old라면 엔코더 변경은 s*(c-c_old).
// c를 Script/Default에 다시 더해 최종 Galvo가 같아지면 Field 개선은 없음.
  1. X 정렬 완료 → 현재값 저장기판 중앙·설계 Pitch를 유지합니다. 현재 공통 기준, Head Default, Recipe/보정 버전을 함께 저장합니다.
  2. 8개 Head의 16빔 중심과 Y 거리 측정각 Head를 정지 시험가공하고 같은 16개 마크를 Review에 되돌립니다. 가공 Y·Review Y로 실측 거리를 계산하고 소속 열의 1277/1657을 빼 편차를 모읍니다.
  3. 실제 Field 여유 계산사용할 Recipe 전체 점·16개 분기빔·현재 보정과 앞으로 허용할 보정 여유를 합쳐 Head별 가용 범위를 구합니다.
  4. 추천 공통 기준 + 새 Default 계산가장 Field 여유가 부족한 Head의 부담을 줄이는 공통값을 찾습니다. 현재 Default까지 포함한 새 총값을 계산합니다. 불가능하면 적용 버튼을 비활성화합니다.
  5. 공통 기준·MOF 출사 구간·Head Default 함께 적용Stage/PGM에서 실제 출사 엔코더를 변경하고, 바뀐 기준으로 좌표·버퍼·이동 범위를 다시 검사합니다. 한쪽만 적용되면 가공을 시작하지 않습니다.
  6. 새 가공으로 기판 위치와 Field 확인가상 중심 거리의 공통 이동분과 Head 잔차, 설계 홀의 실제 가공 위치, Field 경계 여유를 확인한 뒤 저장합니다. Simple/Rough/Fine는 그다음에 진행합니다.
X 오차 종류처리
전체 Head가 같은 방향으로 치우침기판 X 정렬을 실제로 변경하고 Align 기준/가공 좌표도 함께 갱신할 수 있는 경우에만 공통 분담
Head 사이 Pitch 오차설계 Pitch를 유지해 Head별 잔여 보정. Field가 부족하면 기구 조정
Y 기울기를 θ로 보상X도 변하므로 X 완료값을 고정한 채 Y만 끝내지 않음. X/Y 재측정·재추천
지원되지 않는 공통 X 보정기판 중앙 기준의 기존 Default X를 유지. Review X 카메라 이동은 공통 가공 보상이 아님
추천 알고리즘 · 개발 순서
1. Head별 동일 마크의 가공/Review 엔코더와 현재값 Snapshot을 검증한다.
2. r = s*(가공Y-ReviewY) - rowNominal을 계산한다.
3. 각 Head의 기존 Default를 포함해 새 총값 Bnew=Bnow+(c-r)/k로 둔다.
4. 현재 공통값=0이고 공통 변경 미지원이면 c=0으로 제한한다.
   현재 공통값≠0인데 변경 지원이 끊기면 추천을 차단한다.
5. 전체 패턴·16빔·기존 보정·예비 보정으로 Field 가용범위를 만든다.
6. 모든 Head가 만족하는 c 구간을 구한다. 없으면 INFEASIBLE.
7. 구간 내에서 가장 부족한 Head의 정규화 Field 여유를 최대화한다.
8. 비선형/회전/축간 영향이 있으면 실제 XY 변환·Field로 전점 재검사한다.
9. 출사·트리거·이동범위와 기판상 설계좌표 등가성을 검증한다.
10. 공통 기준+PGM/버퍼+Default를 일괄 적용, 새 가공으로 확인한다.
