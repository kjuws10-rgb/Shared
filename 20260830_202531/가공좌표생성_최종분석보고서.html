1. 가공 중심 Pitch 정의

Pitch는 현재 DOE 중심 명령좌표에서 다음 DOE 중심 명령좌표까지 이동하는 원본 Pixel 개수입니다. DOE 내부 Hole 간격과 같은 값은 아니지만, 현재 4×4 구성에서는 중심 간격을 축당 분기 수 4로 나누어 명목 Hole 간격을 계산합니다.

가공 중심 간격

가공 중심 간격 [mm] = 픽셀 크기 [mm/px] × 피치 [px]
0.09 mm/px × 10 px = 0.9 mm

현재 중심에서 다음 중심까지의 Scanner 명령좌표 간격은 0.9 mm입니다.

DOE 4×4 가공홀

중심 1개당 명목 가공홀 수 [개] = 가로 분기 수 [개] × 세로 분기 수 [개] = 4 × 4 = 16
DOE 명목 빔 간격 [mm] = 가공 중심 간격 [mm] ÷ 축당 분기 수 [개] = 0.9 ÷ 4 = 0.225 mm

명목 배열은 0.225 mm 간격이며, 실제 장비 좌표에는 DOE Branch별 X/Y Calibration과 회전을 추가 적용합니다.

DOE 패턴 중심 Offset [mm] = DOE 명목 빔 간격 [mm] × (축당 분기 수 [개] − 1) ÷ 2 = 0.225 × 1.5 = 0.3375 mm
축별 명목 분기 오프셋 [mm] = {−0.3375, −0.1125, +0.1125, +0.3375}
실제 가공홀 좌표(중심 번호, 분기 번호) = DOE 중심 명령좌표(중심 번호) + 명목 분기 오프셋(분기 번호) + 분기별 Calibration 보정량
분기 번호 = B01 … B16
4×4는 짝수 배열이므로 단일 중앙 Hole이 없고, 가운데 4개 Hole 사이의 교점이 Scanner 가공 중심입니다. 첫 Hole 중심에서 이 교점까지는 X/Y 각각 1.5간격, 즉 0.3375 mm입니다. Review는 중심이 아니라 B06 또는 B11 같은 지정 Branch를 볼 수 있으므로, 측정값을 가공 중심 오차로 환산할 때는 해당 Branch Offset을 제거해야 합니다.

3.1 중심 격자

가공 중심 간격 [mm] = 픽셀 크기 [mm/px] × 가공 중심 피치 [px] = 0.09 × 10 = 0.9 mm
DOE 명목 빔 간격 [mm] = 가공 중심 간격 [mm] ÷ 축당 DOE 분기빔 개수 [개] = 0.9 ÷ 4 = 0.225 mm
DOE 패턴 중심 Offset C26 [mm] = DOE 명목 빔 간격 [mm] × (축당 DOE 분기빔 개수 [개] − 1) ÷ 2 = 0.225 × 1.5 = 0.3375 mm
전역 X좌표 [mm] = Cell 기준 X좌표 [mm] + X 기준거리 합계 C25 [mm] + DOE 패턴 중심 Offset C26 [mm] + X방향 격자 번호 × 가공 중심 간격 [mm]
전역 X좌표 [mm] = Cell 기준 X좌표 + 25.8375 + 0.9 × X방향 격자 번호
전역 Y좌표 [mm] = Cell 기준 Y좌표 [mm] + DOE 패턴 중심 Offset C26 [mm] + Y방향 격자 번호 × 가공 중심 간격 [mm]
전역 Y좌표 [mm] = Cell 기준 Y좌표 + 0.3375 + 0.9 × Y방향 격자 번호

현재 파일은 X방향 격자 번호 0…13, Y방향 격자 번호 0…24를 사용합니다. 설계 X방향 격자가 GY(Review)에, 설계 Y방향 격자가 부호 반전되어 GX(Stage)에 반영됩니다.

3.2 Head 선택과 GY 로컬·GX(Stage) 출력좌표

스캔필드 폭 [mm] = 110 mm · 스캔필드 반폭 [mm] = 55 mm
Head 번호 = 내림(전역 X좌표 [mm] ÷ 스캔필드 폭 [mm]) + 1
Head 스캔필드 중심 X좌표 [mm] = 스캔필드 반폭 [mm] + 스캔필드 폭 [mm] × (Head 번호 − 1)
스캐너 로컬 GY [mm] = 전역 X좌표 [mm] − Head 스캔필드 중심 X좌표 [mm]
명목 GY 범위: −55 mm ≤ 스캐너 로컬 GY < +55 mm
Head별 GX(Stage) 출력좌표 [mm] = −{전역 Y좌표 [mm] + MOF 버퍼 오프셋 120 mm + 홀수 Head이면 380 mm}

GX(Stage)는 Stage/MOF 절대성분을 포함하므로 Scanner Local GX 범위로 직접 해석하지 않습니다.

Head 전수 대조는 Cell 열 번호와 X방향 명령 격자 번호만 사용해 전역 X좌표 = 100 × (Cell 열 번호 − 1) + 25.8375 + 0.9 × X방향 격자 번호로 독립 계산했습니다. 16,742개 모두 Excel Head와 일치하며, Excel GY로 복원한 전역 X좌표와의 차이도 0 mm입니다.

5. Ground Truth 출력 패턴과 실행 의미 확인사항

5.1 Ground Truth 992개 연속 반복 좌표 레코드

각 Head는 125개 Stage Lane(5 Cell rows × 25 Y index)을 갖습니다. 첫 Lane을 제외한 124개 Lane에서 첫 좌표가 정확히 두 번 연속 기록됩니다. 이는 서로 다른 두 공간점이 아니라 같은 (GY,GX)의 두 번째 Raw 레코드입니다.

예시GY1GX1판정
A19:B19−29.1625−501.2375완전 동일
A20:B20−29.1625−501.2375
좌표 생성 SW는 정답 탭의 992개 반복을 제거하지 않고 16,742개 Raw 레코드를 그대로 출력해야 합니다. 다만 모든 행을 Laser-On 가공점으로 처리하면 992개 중심이 이중 가공됩니다. DOE 16개 기준으로는 15,872회의 추가 Hole 노광, 총 267,872 Hole 노광 위험입니다 (공간 고유 중심 기준 명목 252,000 Hole 대비). 이 반복이 실행 시 Jump/Lead-in 역할이라면 CommandType과 LaserGate를 반드시 명시해야 합니다. “Lane 시작”은 위치·순서를 설명하는 분석상 분류이며, 실제 장비 명령 의미는 파일만으로 확정할 수 없습니다.

5.2 P0 보정 후 110 mm Field Guard

현재 명령 중심만 보면 Field 이탈은 0개입니다. 그러나 H4의 최소 중심 여유 0.3375 mm와 DOE 외곽 Hole 중심 Offset 0.3375 mm가 같아, H4의 최외곽 명목 Hole 중심은 −55 mm 경계에 놓이고 실질적인 양(+)의 Guard는 없습니다. H4 최소 GY를 갖는 고유 DOE Pattern은 125개이며 Raw 기록으로는 반복 124개를 포함해 249개입니다.

명목 중심 수용 조건: −55 mm ≤ 보정 전 스캐너 로컬 GY < +55 mm
H4 최외곽 명목 Hole 중심 [mm] = −54.6625 mm − DOE 패턴 중심 Offset 0.3375 mm = −55.0000 mm
H4 명목 DOE Hole 중심 Guard [mm] = 명령 중심 여유 0.3375 mm − DOE 외곽 Hole 중심 Offset 0.3375 mm = 0 mm
사전 안전여유 조건: |명목 스캐너 로컬 GY| + 보정 이동량 예산 + 회전 반영 DOE 최대 GY 오프셋 + 빔 반경 + 매핑 오차 < 55 mm
실행 시 수용 조건: |보정 후 스캐너 로컬 GY| + 회전 반영 DOE 최대 GY 오프셋 + 빔 반경 + 매핑 오차 < 55 mm
안전여유 수식 항목한글 정의
보정 이동량 예산Align·Default·Process 보정이 GY 방향으로 이동시킬 수 있는 최대 합산량 [mm]
회전 반영 DOE 최대 GY 오프셋무회전 명목값은 0.3375 mm이며, DOE 패턴 회전과 분기별 Calibration을 적용한 뒤 가장 바깥쪽 빔 중심까지의 최대 GY 거리 [mm]
빔 반경가공홀 중심에서 Laser Beam 외곽까지의 반경 [mm]
매핑 오차Scanner 좌표 매핑·수차보정 후 남는 최대 위치 잔차 [mm]
Head를 먼저 고정하고 보정값을 나중에 더하면 H3/H4 경계에서 Field를 벗어날 수 있습니다. 처리 순서는 Global 중심 생성 → Cell Align·Global Process 보정 → 보정된 Global X와 보정된 Head Field map으로 Head 재선택 → Head별 설치/Default 변환과 왜곡 보정 → Local GY 변환 → Field Guard 검사여야 합니다. 경계 초과 좌표를 Clamp하면 실제 가공 위치가 바뀌므로 금지해야 합니다.

5.3 P0 끝점 생성 정책

현재 Ground Truth 적용 정책

Cell당 X방향 중심 수 [개] = 내림(X방향 픽셀 수 [px] ÷ 피치 [px]) = 내림(144 ÷ 10) = 14
Cell당 Y방향 중심 수 [개] = 내림(Y방향 픽셀 수 [px] ÷ 피치 [px]) = 내림(256 ÷ 10) = 25
전체 공간 고유 중심 수 [개] = Cell 수 45 × X방향 중심 수 14 × Y방향 중심 수 25 = 15,750

명령 Pixel 위치는 X방향 0…130 px, Y방향 0…240 px이며, Raw 출력은 반복 패턴 992개를 포함한 16,742개입니다.

좌표 생성 SW는 위 14×25 정책과 Raw 반복 순서를 그대로 재현해야 합니다. 끝점 포함 규칙을 변경할 경우에는 별도의 사양 변경 및 새 Ground Truth 승인이 필요합니다.

5.4 확정 C26: DOE 4×4 패턴 중심 Offset

C26=0.3375 mm는 첫 DOE Hole 중심을 기준으로 4×4 Pattern의 기하학적 중심까지 이동하는 X/Y 공통 Offset입니다. 가공 중심 간격 0.9 mm를 축당 분기빔 4개로 나누면 DOE 명목 빔 간격은 0.225 mm이며, 4개 빔의 중심은 첫 빔에서 1.5간격 떨어져 있으므로 0.225×1.5=0.3375 mm가 됩니다.

좌표 생성 SW에는 DOE_BRANCH_COUNT_PER_AXIS=4, DOE_NOMINAL_SPACING_MM=0.225, DOE_PATTERN_CENTER_OFFSET_MM=0.3375처럼 의미가 드러나는 명명 파라미터를 사용해야 합니다. 실제 장비에서는 이 명목값에 DOE Branch별 X/Y Calibration과 Pattern 회전을 적용해야 합니다.

6. 좌표 생성 SW에 반영할 권장 구조

6.1 계산 계층을 분리해야 합니다

① 설계 / CellAlign, 픽셀 격자, 회전
→
② 명령 중심픽셀 크기 × 피치
→
③ Scanner 로컬Scan Field 110 mm + 안전여유
→
④ 실제 가공홀명목 Offset + Calibration
// 1) 가공 중심 간격
가공중심간격_mm = 픽셀크기_mm_per_px × 가공중심피치_px;

// 2) DOE 4×4 명목 간격과 Pattern 중심 Offset
축당DOE분기빔개수 = 4;
DOE명목빔간격_mm = 가공중심간격_mm ÷ 축당DOE분기빔개수;
DOE패턴중심Offset_mm = DOE명목빔간격_mm × (축당DOE분기빔개수 − 1) ÷ 2;
// 현재값: 0.9 ÷ 4 = 0.225 mm, 0.225 × 1.5 = 0.3375 mm

// 3) Cell 내부 DOE 중심 명령좌표와 전역 보정
기본전역중심 = Cell좌표변환 × (AlignKey에서첫픽셀까지거리
              + [DOE패턴중심Offset_mm, DOE패턴중심Offset_mm]
              + [X격자번호 × 가공중심간격_mm, Y격자번호 × 가공중심간격_mm]);
보정전역중심 = 전역공정보정적용(기본전역중심, 전역보정맵);

// 4) Scan Field 110 mm 기준 Head 선택과 Scanner Local 변환
스캔필드폭_mm = 110.0;
스캔필드반폭_mm = 스캔필드폭_mm ÷ 2.0;
선택Head = 보정Field맵으로Head선택(보정전역중심.X, Head별Field맵);
로컬중심 = 선택Head.전역좌표를로컬로변환(보정전역중심, Head설치XYθ, 수차보정맵);
필수조건(−스캔필드반폭_mm ≤ 로컬중심.GY < 스캔필드반폭_mm);

// 5) DOE 전체 footprint를 포함한 Field 안전여유 검사
명목DOE분기Offset목록_mm = {−0.3375, −0.1125, +0.1125, +0.3375};
회전반영DOE최대GY오프셋_mm = 각 명목 분기 Offset에 Calibration과 회전을 적용한 |GY| 중 최대값;
필수조건(|로컬중심.GY| + 회전반영DOE최대GY오프셋_mm
        + 빔반경_mm + 매핑오차_mm < 스캔필드반폭_mm);

// 6) DOE 실제 가공홀 좌표
각 DOE 분기에 대해:
    실제가공홀좌표 = 로컬중심 + 회전적용(DOE회전각, 명목분기XY오프셋 + 분기별Calibration보정량);

// 7) Review 측정 기준점
Review측정좌표 = 로컬중심 + Review분기XY오프셋;
