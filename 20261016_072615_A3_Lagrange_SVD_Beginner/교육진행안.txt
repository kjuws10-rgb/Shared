라그랑주 보간법과 SVD — 수학 사전 지식이 없는 청중을 위한 진행안
2026-10-16 / A3 LD 가공 SW / 약 20분

[교육 목표]
수식 계산이나 알고리즘 구현을 가르치는 시간이 아니다.
“왜 쓰는가, 무엇을 해 주는가, 어디까지 믿을 수 있는가”를 설명할 수 있으면 된다.
A3_Lagrange_SVD_Beginner.html을 브라우저에서 열고 다음 버튼으로 진행한다.
각 화면 아래 ‘발표자 메모’에 바로 읽어 줄 수 있는 설명이 있다.
인터넷 없이 사용할 수 있고, 인쇄 / PDF 버튼으로 전체 교육 내용을 출력할 수 있다.

[0–3분 / 화면 1]
질문을 먼저 던진다: “카메라로 찍지 않은 두 점 사이의 상태는 어떻게 알까요?”
세 점과 물음표만 가리킨다. 행렬, 직교, 특이값부터 설명하지 않는다.
라그랑주는 점 사이를 추정하는 방법이고, SVD는 계산을 나누어 보는 도구라고 소개한다.

[3–7분 / 화면 2]
① 측정점만 → ② 점 사이 연결 → ③ 안 찍은 곳 추정 순서로 누른다.
“파란 점은 측정, 초록 선은 계산입니다.”
“위쪽과 가운데의 중간은 3 pixel로 추정됩니다. 실제로 찍은 값은 아닙니다.”
pixel은 사진 속 위치를 세는 단위, 편차는 예상 위치와 측정 위치의 차이라고 설명한다.
두 점이면 직선, 세 점이면 2차 이하 곡선이라고만 설명해도 충분하다.
‘점 사이를 채우기’와 ‘측정 범위 밖을 예측하기’는 구분한다.

[7–10분 / 화면 3]
가정 A와 가정 B 버튼을 번갈아 누른다.
“파란 측정값은 1, 4, 1로 똑같지만 실제 모양은 두 가지일 수 있습니다.”
“한 번 찍은 값만으로 어느 쪽인지 알아낼 수는 없습니다.”
주황색 정답은 설명을 위해 알고 있다고 가정한 것이며 실제 설비에서 아는 정보가 아니라고 말한다.

[10–14분 / 화면 4]
행렬은 계산을 담은 숫자 표라고 처음 소개한다.
SVD는 입력 쪽 방향, 영향 크기, 출력 쪽 방향으로 그 계산을 나누는 방법이다.
이번 예제는 ‘굽음 계산표’를 선택한 경우다.
함께 이동하면 위치는 바뀌지만 굽음은 없다.
기울어져도 직선이면 굽음은 없다.
가운데가 더 움직이면 굽음이 나타난다.
‘방향’은 화살표 하나뿐 아니라 여러 점이 같이 움직이는 패턴을 말한다.
작은 특이값은 ‘지금 계산에 작게 드러남’이지 ‘항상 잡음’이라는 뜻이 아니다.
U, Σ, V 기호는 첫 교육에서 생략해도 된다. 질문이 나오면 참고 설명을 펼친다.

[14–17분 / 화면 5]
‘굽음 유지’와 ‘굽음 줄이기’를 누르고 아래 두 상황을 비교한다.
1,4,1 = 2,2,2 + (-1,2,-1) 이다. 굽음 성분을 빼면 2,2,2가 된다.
“선이 매끈해져도 실제 굽음을 지우면 오히려 틀립니다.”
SVD는 나눠 보는 도구이고, 얼마나 줄일지는 별도 판단이다.
Auto Tune도 독립 검증이 필요하다. 현재 측정점을 잘 통과한다는 이유만으로 최적이라고 하지 않는다.

[17–19분 / 화면 6]
4개 Align 카메라 → 정렬 → 그중 2개로 Y축 스캔하는 현재 컨셉에 연결한다.
6/4/2 Key를 균등하게 두 카메라로 나눈다는 가정하에 카메라당 3/2/1점이다.
한 카메라의 세 점을 설명한 그림이며, 서로 다른 카메라의 pixel을 바로 섞지 않는다.
같은 Key, 카메라, 촬영 위치, ROI, 정렬 상태의 기준 pixel이 먼저 필요하다.
설계 위치만 입력해서 전역 좌표나 실제 μm 정확도가 확보되는 것은 아니다.
Model / Glass ID 레시피로 위치와 촬영 조건을 구분해 누적 비교한다.

[19–20분 / 화면 7]
세 문항을 한 번씩 답하게 한 뒤 답을 펼친다.
마지막으로 청중이 자기 말로 설명하도록 한다.
“라그랑주: 알고 있는 점 사이를 추정한다.”
“SVD: 선택한 계산을 방향과 영향 크기로 나누어 본다.”
“실제와 잘 맞는지는 따로 검증해야 한다.”

[발표자가 피해야 할 말]
“점을 많이 찍으면 무조건 정확하다.”
“라그랑주가 잡음을 제거한다.”
“SVD가 잡음과 실제 변형을 자동으로 알아낸다.”
“작은 특이값 공간은 언제나 최적이다.”
“선이 매끄러워졌으니 더 정확하다.”
“설계치가 있으면 서로 다른 카메라 pixel을 바로 합쳐도 된다.”

[교육 범위]
가상 데이터로 개념을 설명한다. 실제 장비의 보정 성능 검증이나 생산 알고리즘 채택이 아니다.
SVD 그림의 기본 모양은 이번 굽음 계산에 맞춘 예이다. 모든 행렬의 SVD에서 같은 모양이 나오지 않는다.
실제 구현은 카메라, Key 배치, 측정 반복성, 독립 검증 결과에 따라 결정한다.
