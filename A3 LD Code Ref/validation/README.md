## 발견해 바로잡은 사항

- 동명 로컬 함수가 서로 합쳐지던 심볼 ID 문제를 수정했습니다. 선언·호출자·대상·연산 참조를 같은 규칙으로 고쳤고 11개 합성 회귀검사를 통과했습니다.
- IOF 입력 타입을 `ST_STAGE_IOF_POINT`로 바로잡았습니다. Stage 이동 X/Y와 Vision TCP 검색 식별자를 구분하는 실제 bridge 근거를 추가했습니다.
- Rollback의 history 복구까지 포함하도록 소스 인용 범위를 보완했습니다.
- MAIN START의 MANUAL/Semi Auto와 Stage 요청의 AUTO 진입을 분리했습니다. AUTO 준비 시 Shift를 0으로 처리하는 현재 구현과 별도 정책 제안을 혼동하지 않도록 설명했습니다.
- HTML 상세장 간 링크를 `.md.html`로 연결하고 각 원본 근거 옆에 오프라인 파일 해설 이동 링크를 추가했습니다.

## 그대로 남긴 원본 문제와 검증 경계

`CStationProcess.cs`의 원본 570행 주석에는 이미 U+FFFD 대체 문자가 9개 있습니다. 원본을 임의로 고치지 않고 그대로 문서 사본에 보존했으며 원본에서 유래한 문자와 새 생성 오류를 구분해 검사했습니다. 이 원본 주석 1건을 제외한 미확인 대체 문자 도입은 없었습니다.

Roslyn 부분 컴파일의 미해결/후보 호출과 WPF·벤더 SDK 진단은 확인 대상으로 남겼습니다. 이 진단은 장비 정식 빌드 결과가 아닙니다. 기존 아키텍처 보고서의 별도 장비 빌드 이력도 이번 문서 검증에서 다시 실행한 것으로 보고하지 않습니다.

파일별 주석 사본과 검색 자료는 실행 지시가 아닙니다. 장비 개선에 적용할 때는 현재 소스 버전 대조, 승인된 별도 검증 clone의 빌드·시뮬레이션, 장비 조건 검증이 필요합니다. 자료 첨부만으로 모델 가중치가 재학습되거나 답변 정확도가 보장되지는 않습니다.
