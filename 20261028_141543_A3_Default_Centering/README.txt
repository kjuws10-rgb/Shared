포함 내용
- 상단 Align 두 점의 가운데로 이동해 기판 기준 엔코더 저장.
- 선택 Head의 DOE 4×4 실제 마크 16개를 모아 빈 가운데 계산.
- 카메라 해상도·센서 픽셀·전체 광학 배율 또는 실측 FOV로 mm 환산.
- 실제 Review X/Main Y 시험 이동으로 회전·반전·축 방향 보정.
- 빈 화면에서 시작하는 설정영역 탐색과 겹침 촬영·16개 중복/누락 처리.
- 큰 FOV/작은 FOV의 중심 계산·이동·재확인·Head 중심 저장.
- 개발 상태 시퀀스·Melsec 이동 연결·응답 계약·작업자 단위 버튼.
- H4/H5부터 X/Y 맞춤·추천 Default·새 가공 확인·전후 비교.
- 중앙맞춤 계산 및 8Head Default 비교 예제 2개.

사용 방법
ZIP을 풀어 HTML을 브라우저에서 엽니다. 인터넷 없이 본문·그림·예제가 동작합니다.
목차/그림확대/개발상세펼치기/인쇄 기능을 사용하세요.

센서 픽셀 크기 또는 실제 측정한 FOV 크기도 입력합니다.
