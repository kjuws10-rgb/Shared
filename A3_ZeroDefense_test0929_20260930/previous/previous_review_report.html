ZERO DEFENSE REVIEW · 01

0선방어 Review 운영 및 산출 보고서

AM 11 자동 가공 실행 | A3 Laser Driller | 2026.09.30

설계안은 Glass당 2점, 헤드당 1점을 H1·H2 → H3·H4 → H5·H6 → H7·H8 순서로 순환 검사한다. 두 점의 촬영 가능성은 실제 좌표와 모션 조건으로 먼저 검증한다. 가공 보정값을 산출·갱신하지 않고, 가공 흔적과 보조 전극 진입에 대한 검증된 영상 기준으로 합불을 판정한다.

주요 산출 요청현재 조건으로 제시할 결과
Glass 1매당 Review 개수목표 2점. 시간·좌표·FOV·트리거·Tact 검증 통과 시 2점. 동일 Y의 서로 다른 X 중심점은 단일 통과에서 기본적으로 1점.
8개 헤드 대표점 1회 커버모든 2점 조합이 유효하면 4매. 150초/매 기준 600초 = 10분.
각 헤드 2개 Cell 대표점총 16점인 경우, 2점/매와 각 조합의 유효성이 보장되면 8매 = 20분.
실제 전체 가공 포인트 커버N과 실제 좌표 목록 미제공. 고정 0선 대표점 목록 밖의 포인트는 현재 모드에서 커버되지 않는다. 별도 전수 모드의 이상적 하한은 ceil(N/2)매.
Stage Y 가공 속도가공 유효 이동거리 L과 비정속·대기 시간 필요. 순수 등속 30초이면 vY = L/30.
Review X 및 카메라200 mm/s는 제공된 A5 비교 조건. 본 장비 적용 여부, 가속도·정착 시간·실제 촬영 주기를 별도 확인.
이 보고서의 900 mm, X 간격 110 mm, Y 간격 30 mm, X 가속도 1,000 mm/s², 정착 50 ms, 여유 20 ms는 설명용 가정이다. 실장비 측정 결과로 표시하지 않는다.

첨부는 자동 MOF/Review 시퀀스, Manual IOF/P to P 시퀀스 및 DOE 기준점 개념을 제공한다. 숫자로 된 Glass별 가공 좌표 목록·포인트 총수·가공 Y 경로 길이는 포함되어 있지 않다. 따라서 실제 최대 검사 수와 정확한 전수 매수는 이 자료만으로 확정할 수 없다.

02. 1,467 mm와 두 촬영 간격의 차이

거리로 생기는 준비 시간과 좌표로 생기는 촬영 시간을 따로 계산한다
t_Review,i = t_Process,i + D_h / vY (같은 방향 등속, Review가 하류인 경우)
Δt_Review,ij = |ΔY_ij| / vY (Glass의 실제 검사 대상점 기준)

1,467 mm는 센터 기준 예산 거리다. 실제 가공 시 Laser Spot의 Head-local Y 위치와 Head 설치 Y 편차까지 포함한 유효 거리 D_i로 보정해야 한다. 정확한 통과 시각은 가공 이벤트의 Stage Encoder 위치와 qY_Review 사이 이동량으로 계산한다. 본문의 D_h는 해당 0선점에 적용되는 유효 거리이며, 수치 예시는 이를 1,467 mm로 가정한다.

스캐너의 지그재그 배치는 Head별 가공 시각과 D_h를 바꾼다. 그러나 같은 Glass Y에 있는 두 Hole이 동일한 Review 위치를 지나는 시각을 자동으로 분리해 주지는 않는다. Head 간 설치 Y 차이를 검사점의 재료 좌표 ΔY로 대체하면 안 된다.

Review가 실제 가공 방향의 상류에 있으면 동일 통과에서 미가공 영상을 보게 된다. 이때 1,467/vY 계산만으로 가공 후 검사를 보장할 수 없으며, 복귀 통과 또는 별도 이동 계획으로 다시 계산해야 한다.

첫 X는 첫 촬영 시각 이전에 도착·정착하여 대기한다. 두 번째 X는 첫 노출이 끝난 직후 이동하고, 다음 촬영 시각 이전에 도착·정착하여 다시 대기한다. 첫 위치를 Stage 시작 전에 준비하면 1,467 mm의 이동 시간은 충분한 선행 준비 여유가 될 수 있다.

ZERO DEFENSE REVIEW · 04

03. 같은 Y와 다른 Y의 촬영 가능성

0선 기준좌표를 임의로 바꾸지 않고, 승인된 고정 후보점의 시간 조건을 검증한다

고정 0선이 모든 Head에서 정확히 동일 Y이고 검사 ROI가 서로 멀리 떨어진 X에 있다면, 카메라 1대·무정지 단일 통과에서는 2점 계획이 성립하지 않는다. 이 경우 1점/Glass 순환, Stage 정지 촬영, 다른 승인된 0선 후보점 조합 또는 복귀 검사를 선택한다.

FOV 내부에서 촬영 중심을 앞뒤로 약간 옮길 수 있다면 허용 시간 창을 추가할 수 있다. 그러나 이 허용량은 (FOV_Y - 필요한 ROI_Y)/vY에 제한되고, 승인된 영상 품질을 만족해야 한다. 큰 X 이동 시간을 FOV 여유만으로 확보할 수 있다고 가정하지 않는다.

“보정영역 재조정”은 이미 승인된 0선·전극 영역 안에서 후보점 조합을 다시 선택하는 의미로 한정한다. 범위 밖 Y 이동이나 레시피 기준점 변경은 생산 중 자동으로 하지 않는다.
ZERO DEFENSE REVIEW · 05

04. 속도와 촬영의 계산식

등속 구간, 정지 간 X 이동, 비동기 영상처리를 기본 모델로 사용한다
계산 항목식 / 기준
Stage Y 속도vY = L_process / (30 - T_nonconstant). 순수 등속 가공 구간이면 L_process/30. L은 외곽 Glass 길이가 아니라 실제 Stage 가공 이동거리.
X 이동 시간d ≤ vX²/aX: T_move = 2√(d/aX). d > vX²/aX: T_move = d/vX + vX/aX. 시작·종료 속도 0인 대칭 삼각/사다리꼴 모델.
X 준비 시간T_X = T_exposure + T_move + T_settle + T_guard. 첫 노출 종료 후 X 이동.
카메라 준비 시간T_cam = 실측 최소 Trigger 간격. 1/fps는 사양 기반 예산용 값이며 Trigger mode, ROI, readout, 버퍼 영향을 확인.
필요 촬영 간격T_req = max(T_X, T_cam). 카메라 처리와 X 이동을 병렬로 운영할 때.
가능 판정Δt = ΔY/vY ≥ T_req, 첫 X 준비 완료, 두 점이 이동 범위·ROI·가공 후 시점·Tact 조건을 만족.
필요 Y 간격ΔY_min = vY × T_req. 또는 해당 조합의 vY 상한 = ΔY/T_req.
영상 처리 직렬 대기 시다음 X 이동을 결과 수신 뒤 시작하면 처리/전송 대기 시간을 X 준비 시간에 추가. 본안은 Frame ID로 결과를 비동기 수집.

S-curve나 jerk 제한을 쓰면 이 사다리꼴 계산보다 X 이동이 길어질 수 있다. 설비 승인값은 실제 MoveDone 시간과 InPosition 유지 시간을 측정하여 설정한다. Frame 수신 완료를 노출 종료와 혼동하면 X 이동 시작이 불필요하게 늦어진다.

가공 처리량 조건: 각 Head의 N_shot,h / 30 ≤ 검증된 Head별 Shot 처리능력

가공 Point 수는 Laser/Scanner 처리량을 결정한다. Stage 이동거리로 계산한 vY만 만족해도 30초 가공이 보장되는 것은 아니다. Head별 점수, Mark/Jump 시간, Pulse 수, iFOV 추종 및 Buffer 상태까지 별도로 검증한다. Masking 적용 후 실제 Shot 수와 실제 Hole 수를 함께 기록한다.

가공 30초 이내의 vY 하한 = L_process / (30 - T_nonconstant)
Tact의 vY 하한 = (D_h + Y_span) / (150 - T_other - t0 - T_tail)

가공·Tact 하한의 큰 값이 좌표 조합의 vY 상한(ΔY/T_req) 이하여야 속도 해가 존재한다. 분모가 0 이하이면 시간 예산이 부족하다. 가공을 정확히 30초로 고정하면 vY는 L/30으로 결정되며, 시간을 맞추려고 임의로 속도를 높일 수 없다. Tact 식의 기호는 07항에서 정의하며, 하류 등속 단일 구간의 예산 모델이다.

06. 카메라 Shot과 영상 품질

fps, 노출 시간, 트리거 지연은 각각 다른 제한이다
구분관계적용 방법
연속 촬영 간격T_cam ≈ 1/f_eff23 fps: 43.478 ms / 15 fps: 66.667 ms. 실제 Trigger 수용 주기 측정.
Y방향 프레임 간격ΔY_camera = vY/f_eff30 mm/s, 23 fps이면 약 1.304 mm. X 이동 제한과 함께 적용.
Motion blurBlur(mm) = vY × T_exposure30 mm/s, 10 µs이면 0.0003 mm = 0.3 µm. 허용 Blur는 검사 ROI로 검증.
트리거 지연 편차Y 오차 = vY × 지연 편차30 mm/s에서 50 µs는 1.5 µm. 평균 지연과 jitter를 분리하여 검증.
X 대기 조건InPosition + 정착 유지 + 저속노출 동안 X 위치 유지. 이동 재개는 Exposure End 확인 뒤.
검사 처리량Frame 버퍼 + 결과 Deadline전송/분석을 비동기화하되 프레임 손실·큐 초과·결과 미도착을 판정한다.

XCG-CG510을 사용하는 경우 Sony 공식 페이지는 Mode0의 8 bit 23 fps와 Mode1의 8/10/12 bit 15 fps를 구분한다 [S1]. ROI는 프레임 주기에 영향을 줄 수 있으므로 현재 설정의 유효 속도를 읽고 시험한다. 이 보고서의 10 µs는 계산 예시이며 실제 노출값과 조명 밝기는 확인 항목이다.

20배 배율·3.45 µm Sensor pixel을 예시로 쓰면 물체 좌표 1 px는 0.1725 µm이고, 위 Blur 0.3 µm는 약 1.74 px다. 정밀 Offset 측정과 합불용 Hole 검사는 허용 품질이 다르므로, “노출이 짧다”는 이유만으로 영상 판정을 승인하지 않는다.

150초 × 23 fps = 3,450 Frame을 실제 검사 가능 포인트 수로 사용할 수 없다. 실제 검사 창, 대상점 Y 분포, X 이동, Camera Ready, 가공 완료 상태, Stage 범위, 2점 정책이 검사 수를 제한한다.

카메라만 고려한 한 촬영 창의 상한은 floor(T_window/T_cam)+1이다. 동일한 X 이동을 반복하는 예시에서는 T_req를 적용한 시간 상한도 구할 수 있다. 모두 후보 좌표를 무시한 상한이며, 실제 최대 개수는 좌표 기반 스케줄 검증으로 결정한다.

ZERO DEFENSE REVIEW · 08

07. 전체 Tact 150초의 배분

가공과 Review가 겹치는 시간은 한 번만 센다

가공 시작을 t=0으로 둔다. 첫 0선 가공 시각을 t0, 첫점~마지막점의 검사 대상 Y 간격을 Y_span, 마지막 Frame부터 판정 종료까지를 T_tail로 둔다. 같은 속도·하류 배치 모델에서는 다음 식을 사용한다.

t_R,first = t0 + D_h/vY ; t_R,last = t_R,first + Y_span/vY
T_active = max(30, t_R,last + T_tail)
T_tact = T_other + T_active ≤ 150초

T_other는 Loading, Align, 비정속 이동, 복귀, Unload 등 위 시간 창 밖에서 실제로 더해지는 시간이다. 병렬 물류가 있으면 선후 관계 기준의 실제 완료 경로로 다시 합산한다. 150-30=120초를 전부 Review 순수 촬영 시간으로 취급하지 않는다.

예시 조건계산 결과150초 내 남는 T_other 상한

09. 실제 가공 Point 전체 커버의 해석

조건 변경 계산

두 점의 시간 조건과 Tact 예산 계산기

기본값은 보고서의 설명용 가정입니다. 실제 좌표·Stroke·첫 X 준비·Camera Ready를 모두 검증해야 설비 운전값으로 승인할 수 있습니다. 이 계산기는 단일 하류 등속 통과에서 입력한 두 점만 비교합니다.

두 점은 서로 다른 Head의 유효 Point이며 첫 X는 선행 준비되었다고 가정합니다. 비정속 시간을 입력하면 실제 Review 도달 시각은 속도 프로파일로 다시 확인해야 하므로 Tact 출력은 등속 환산 예산입니다. N의 매수는 두 점과 같은 시간 조건을 모든 배치에서 만족하고 전 대상에 접근 가능한 경우의 이상적 하한입니다. 고정 0선 목록 밖의 Point는 이 계산으로 커버되지 않습니다.
