## 먼저 알아야 할 결론

1. **리뷰 보정 저장 장소가 바뀌었습니다.** 예전에는 레시피 내부, 지금은 `Config/RECIPE/<레시피명>_reviewoffset/<날짜_시간_밀리초>_reviewoffset.csv`입니다. 예전 레시피 내부 보정값은 가공 준비 때 제거합니다. 자동 이전 코드는 이 경로에서 찾지 못했습니다.
2. **Shift Offset과 First Beam Offset이 가공 좌표에 추가됩니다.** Shift는 MANUAL MAIN START에서 실행 자료에 넣는 임시 전체 이동값입니다. 설계 좌표나 Head 배정 자체를 바꾸는 기능은 아닙니다.

4. **MAIN START는 MANUAL에서만 가능합니다.** AUTO는 Stage PC 요청 경로를 사용하도록 UI가 안내합니다. 수동 Stage/CAMERA POS 쓰기와 Controller Reset 순서 화면도 추가됐습니다.
