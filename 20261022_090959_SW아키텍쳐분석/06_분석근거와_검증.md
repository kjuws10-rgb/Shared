## 실제 확인 범위

Git 기준점 비교와 전체 변경 목록2,284개 분류, JHMI/Recipe의 의미 단위 비교, 핵심 C#/UI/File/Station 호출을 확인했습니다. 166개 소스의 모든 동작과1,950개 생성물의 의미를 전부 검증했다는 뜻은 아닙니다. 주요 근거의 최신 파일/실제 줄 범위/파일 SHA는 [소스 링크](소스링크.json)에 있습니다.

기준 README는 Shared의 `20261013_183942_SW아키텍쳐분석`입니다. 소스 최신 main은 `e6ff3c6fd8fb706adbff3ded070cca2502000b4d`에 고정했습니다. 분석 Clone과 검증 Clone을 분리하고 분석 Clone에서는 빌드나 파일 수정 없이 읽었습니다. 임시 Probe 소스는 검증 Clone에만 추가했습니다. 등록된 원래 Downloads SW checkout은 변경하지 않았습니다.

## 빌드

별도 검증 Clone에서 `dotnet build Drilling.sln --configuration Release --nologo --verbosity minimal`을 실행했습니다. UI/Common/File 3개 프로젝트가 빌드됐고 경고0/오류0, 31.00초였습니다. UI를 실행하거나 장치 관리자·레이저·축을 기동하지 않았습니다. 빌드 성공은 논리 정확성/장비 연동 합격이 아닙니다.
