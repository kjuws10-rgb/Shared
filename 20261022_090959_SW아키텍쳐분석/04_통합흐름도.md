# 갱신된 통합 흐름도

실선은 코드의 데이터/호출 연결이며 점선의 미연결 노드는 실제 장비 동작이 아직 완성되지 않았음을 뜻합니다. 사각형이 존재한다고 동작 검증이 끝난 것은 아닙니다.

## 프로그램 전체 계층

```mermaid
flowchart TD
  App["CAppStartup"] --> File["File 계층: CSV와 로그 읽기 쓰기"]
  File --> Manager["CManager: Recipe / Setting / Product / Review / Station"]
  Manager --> UI["UI: Auto / Manual / Recipe / Review / Correction / Monitor"]
  UI --> Recipe["CRecipeManager: 선택 저장 캐시 이력"]
  UI --> Review["CReviewManager: 검사 계획과 결과"]
  UI --> Manual["수동 모션 / PowerMeasure 서비스"]
  Manager --> Device["Interface / Automation / Motion"]
  Device --> Cache["공유 Snapshot 수집"]
  Cache --> UI
  Cache --> Alarm["독립 알람 감시와 이력"]
  Recipe --> Station["가공 Runtime과 Script 계획"]
  Station --> Product["Product 당시 Recipe와 진행 결과"]
  Station -.-> Reserved["일반 Auto Review 실행은 예약 로그"]
```

## 새 Align 보정 데이터의 전체 경로

```mermaid
flowchart TD
  Base["Recipe의 AK4 / DK6 Base"] --> Delta["Base - LastLoad"]
  Live["MELSEC 1회 Load: 주소 단위 확인"] --> Delta
  Sim["Simulation Load: 샘플 값"] --> Delta
  Delta --> Model["X 선형 + Y 구간선형 또는 Lagrange"]
  Model --> Calc["전체 설계 Shot의 보정 계산"]
  Calc --> Check["범위 / Tolerance / 입력 변경 확인"]
  Check --> Save["CELL Shot ALIGN_OFFSET_X/Y 저장"]
  Check --> Keep["제외 Shot은 기존 X/Y 유지"]
  Keep --> Save
  Save --> Log["AlignOffset KEY / SHOT 이력 CSV"]
  Save --> Runtime["Recipe + Option + Motor + 최신 ReviewOffset"]
  Runtime --> Transform["Stage Y방향 / Head 축 변환"]
  Transform --> Command["최종 GX/GY에 Align 성분 가산"]
  Command --> Script["AeroScript와 좌표 CSV"]
```

Simulation 표시와 로그 출처는 있지만 이 경로에서 Simulation 보정을 Recipe 저장에서 강제 거부하는 gate는 확인되지 않습니다. 보정 성분의 출처/적용 조건을 분리해야 합니다.

## Model Cell Shot Beam과 Review

```mermaid
flowchart TD
  Recipe["Recipe CSV + JHMI 메타데이터"] --> Model["Model 픽셀 / Pitch / Beam / Mask / Round / Chess"]
  Model --> Cell["Cell 위치와 회전"]
  Cell --> Shot["설계 Shot 중심과 영구 Shot 키"]
  Shot --> Head["Head 할당과 제외 판정"]
  Head --> Proc["가공: Offset과 축 변환"]
  Head --> All["Review Points: 전체 대응"]
  All --> Select["Rule 선택: Simple / Rough / Cell별 Fine"]
  Select --> Targets["ReviewPoints: 실제 측정 예정"]
  Targets -.-> Motion["일반 Stage Y / Review X 전송 TODO"]
  Targets --> Beam["다중 Shot x Beam 진단"]
  Beam --> Gate["실기 미연결이면 Simulation 전용 차단"]
```

## 일반 결과와 새 Beam 결과는 따로 보관

```mermaid
flowchart TD
  Measure["Vision 결과: UID와 Point 대응"] --> Normal["일반 ReviewResult CSV / Product 진행"]
  Normal --> Projection["Simple Rough Fine 결과 투영"]
  Projection --> Preview["원시 / 계산 / 현재 / Apply Preview"]
  Preview --> Offset["ReviewOffset 최신 CSV"]
  Offset --> Process["다음 가공 Runtime에 병합"]
  Measure --> Beam["BeamInspection Snapshot"]
  Beam --> Matrix["52열 CSV: Shot 한 행 / Beam16개"]
  Matrix --> Display["최근 저장 결과 표시"]
  Display -.-> NoAuto["현재 Recipe 목표나 보정에 자동 적용하지 않음"]
```

Fine 계획의 Cell별 선정과 결과 투영의 Head+X 그룹은 서로 다른 단계입니다. 현재 뒤 단계의 Cell 누락은 위험도 문서의 R02/N09를 참고하세요.

## 장치 조회와 명령 완료

```mermaid
flowchart LR
  Worker["공통 수집 작업자"] --> Snapshot["Snapshot 값 / 상태 / 시각 / 세대"]
  Snapshot --> UI["UI 읽기"]
  Snapshot --> Alarm["알람 감시"]
  Snapshot --> Log["상태 로그"]
  Cmd["축 이동 명령"] --> Ack["명령 ACK"]
  Ack --> Fence["이전 캐시 무효화와 새 수집 경계"]
  Fence --> Done["경계 이후 신선한 상태로 도착 확인"]
  Snapshot --> Done
```
