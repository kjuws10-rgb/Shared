# 02 · 데이터 구조와 흐름

## 저장 위치와 형식

로그 루트는 configRoot의 상위 폴더 아래 Log입니다. 아래 경로의 날짜는 예시 표기이며 실제 레코드를 옮긴 자료가 아닙니다. [로그 구성과 저장 위치](https://github.com/kjuws10-rgb/A3Drilling/blob/334b3599651b2e8e0181fd4459bafaf3cddafff3/Drilling.Common/Log/CLogManager.cs#L18-L69).

| 종류 | 경로 규칙 | 형식·문자 인코딩 |
|---|---|---|
| Recipe | Log/Recipe/YYYYMMDD/Recipe_YYYYMMDD_Trace.txt | 시각·레시피명·동작·항목·이전/새 값, UTF-16 |
| Setting | Log/Setting/YYYYMMDD/Setting_YYYYMMDD_Trace.txt | 시각·SETTING·Section·동작·항목·이전/새 값, UTF-16 |
| Interface | Log/Interface/모듈/YYYYMMDD/Interface_모듈_YYYYMMDD_Trace.txt | 명령/응답 또는 프로토콜 원문, UTF-16 |
| Station / Product / UI | 각각의 종류/YYYYMMDD/*_Trace.txt | 역슬래시 구분 텍스트, UTF-16 |
| Sequence | Log/Sequence/YYYYMMDD/Sequence_YYYYMMDD_Trace.txt | HH:mm:ss.fff와 GLASSID/분류/메시지, UTF-8 BOM |
| Alarm | Log/Alarm/YYYYMMDD/Alarm_YYYYMMDD.jsonl | 한 줄에 JSON 객체 하나, UTF-8 BOM 없음 |
| PM | Log/PM/YYYY/MM/DD/PM_세션ID.json | JSON 객체, UTF-8 BOM 없음 |
| ProgramOpen | Log/ProgramOpen/ProgramOpen_YYYYMMDD.log | 시작/예외 설명 텍스트, 기본 UTF-8 기록 |

## PM 데이터

ST_PM_HISTORY_ENTRY는 SessionId, LockedAt, UnlockedAt(미완료이면 null), Reason, Operator로 구성됩니다. 시작은 사유를 공백 제거 후 검사하고 200자 이하만 받으며, 파일을 임시 이름으로 쓴 뒤 교체합니다. 해제는 같은 SessionId의 파일을 다시 확인한 다음 UnlockedAt을 기록합니다. 이미 해제된 세션은 기존 완료값을 반환합니다. 이력 캐시는 해당 인스턴스 안에서 갱신됩니다. [PM 세션 저장·완료·조회](https://github.com/kjuws10-rgb/A3Drilling/blob/334b3599651b2e8e0181fd4459bafaf3cddafff3/Drilling.Common/Log/CLogManager.cs#L72-L174).

PM 파일의 미완료 기록과 실제 애플리케이션 잠금 상태는 구분해야 합니다. UI는 메모리 잠금 상태를 따로 가지며 초기값은 해제입니다. 이 diff만으로 비정상 종료 후 PM LOCK을 자동 복원한다고 해석할 수 없습니다. [PM 잠금의 초기 메모리 상태](https://github.com/kjuws10-rgb/A3Drilling/blob/334b3599651b2e8e0181fd4459bafaf3cddafff3/Drilling.UI/CRootView.cs#L125-L129).

## 큐와 저장 완료의 의미

| 구분 | 생산자에서 하는 일 | 저장 경계와 실패 |
|---|---|---|
| 동기 Trace | 필드 문자열 생성 → 경로별 lock → 파일 append | 파일 I/O 예외가 호출자로 전파될 수 있음 |
| Interface | 파일별 큐에 TryWrite | 16,384항목/대기 문자열 16MiB 계산 한계 초과 시 거부; 실패 배치 재전송 없음 |
| Sequence | 문구 변환 → 16,384 이벤트 큐에 TryWrite | 큐 포화 시 이벤트 유실; 파일 실패 배치도 재전송 없음 |
| Alarm | 상위 AlarmManager queue → CLogManager.Append | 상위 worker가 예외를 저장 오류로 노출; 단일 시도 |

Interface는 최대 256항목/대략 128Ki 문자 배치와 10ms 묶음 대기를 사용합니다. 이는 디스크·큐 지연을 포함한 ‘최대 10ms 저장 보장’이 아닙니다. Sequence의 개수 제한은 문자열 길이까지 일정 바이트로 제한하지 않습니다. Flush의 barrier는 앞선 큐의 처리 순서를 기다리고, 오류 속성이 있으면 예외를 내므로 ‘barrier 통과=모든 원문 영구 보존’으로 해석하면 안 됩니다. [Interface 큐·Flush·종료](https://github.com/kjuws10-rgb/A3Drilling/blob/334b3599651b2e8e0181fd4459bafaf3cddafff3/Drilling.Common/Log/CLogManager.cs#L422-L537), [Sequence 큐·배치·오류 처리](https://github.com/kjuws10-rgb/A3Drilling/blob/334b3599651b2e8e0181fd4459bafaf3cddafff3/Drilling.Common/Log/CLogManager.cs#L801-L940), [상위 Alarm worker의 실패 처리](https://github.com/kjuws10-rgb/A3Drilling/blob/334b3599651b2e8e0181fd4459bafaf3cddafff3/Drilling.Common/Alarm/CAlarmManager.cs#L339-L375).

## 이력 필드 왕복에서 확인된 문제

독립 exact-source 순수 시험에서 Setting의 이전 값이 빈 경우 기록 한 행이 조회 결과에서 사라졌습니다. Recipe 배치 기록의 Tab/Group이 빈 경우에는 Action 또는 항목명이 섞이거나 메타정보가 유실됐습니다. 반면 Setting의 마지막 새 값만 빈 경우는 정상 왕복했습니다. 빈 문자열 전체를 하나의 결함으로 묶으면 안 됩니다. 5인자 단순 Recipe 기록은 개행을 escape하지 않아 한 이벤트가 두 물리 행으로 저장되는 사례도 재현됐습니다. 로그 조회의 문제이며 실제 Recipe/Setting 값 소실을 재현한 시험은 아닙니다.

## 운영자 문구와 원문

CSequenceLogText는 요청/확인 중복, 초기 OFF, Pending, 일부 polling 이벤트를 의도적으로 생략합니다. Cycle별 Glass ID는 최대 128회차를 기억하며, Process와 겹친 Review의 Glass를 섞지 않도록 미확정 표시를 사용합니다. 따라서 Sequence에 한 줄이 없다고 실제 제어 이벤트가 없었다고 단정할 수 없습니다. 상세한 통신 분석은 Interface/Station 원문과 함께 해야 합니다. [시퀀스 문구·기판 식별자 투영](https://github.com/kjuws10-rgb/A3Drilling/blob/334b3599651b2e8e0181fd4459bafaf3cddafff3/Drilling.Common/Log/CLogManager.cs#L997-L1399).

일반 로그 화면은 CLogFileScope를 통해 허용 경로를 정한 뒤 읽습니다. CLogTextReader 단독 호출이 같은 루트 제한까지 제공하는 것은 아닙니다. Alarm은 전용 HISTORY/TREND에서 조회하고 PM JSON은 PM 이력 화면을 사용합니다. [일반 로그 탐색 범위](https://github.com/kjuws10-rgb/A3Drilling/blob/334b3599651b2e8e0181fd4459bafaf3cddafff3/Drilling.Common/Log/CLogManager.cs#L945-L994), [전체/페이지 로그 읽기와 인코딩](https://github.com/kjuws10-rgb/A3Drilling/blob/334b3599651b2e8e0181fd4459bafaf3cddafff3/Drilling.Common/Log/CLogManager.cs#L1401-L1501), [PM 화면 이력 소비](https://github.com/kjuws10-rgb/A3Drilling/blob/334b3599651b2e8e0181fd4459bafaf3cddafff3/Drilling.UI/Menu/Menus/CMenuPm.cs#L35-L56).
