A3 LD Default Offset 개발·작업절차서
2026-10-23

최초 스캐너 가공평가에 앞서 수행할 Default Offset 셋업의 별도 상세 자료입니다.

내용
- 기판 중심과 4·5번 Head의 서로 다른 가상 원점, 전체 Head 설계 배치.
- 기준 고정 → 시험 가공 → Review 측정 → 원점/후보 계산 → 적용 → 새 가공 검증의 10단계.
- 각 단계의 작업자 행동, 가공SW 처리, 다음 단계 조건.
- Review 영상과 촬영 위치의 공통 mm 변환, 분기빔 전체 변위, X/Y 보정.
- 개발 화면안, 데이터/Revision 관리, 적용·미검증·검증 완료 상태와 복구.
- 그림8개, 고정 학습 예제, 완료 체크리스트와 실제 장비에서 확정할 항목.

사용 방법
HTML을 다운로드한 뒤 웹 브라우저로 엽니다. 인터넷 연결이나 추가 라이브러리 없이
본문·그림·학습 예제를 사용할 수 있습니다. 그림의 '크게 보기'와 인쇄/PDF 저장을 지원합니다.
체크박스는 열람 중 확인용이며 새로고침 시 초기화됩니다.
본문 끝의 이전 원문3개 링크는 작성환경의 로컬 참고 경로이며 공유 위치에서는 열리지
않을 수 있습니다. 원문 파일은 이 패키지에 포함하지 않았습니다.

범위와 검증
완성된 HTML을 내용 변경 없이 동일 바이트로 복사했습니다.
3개 보조 에이전트의 작업·계산·그림 검토, 브라우저17항목, 독립 수학/JS27항목,
작업11항목 검사를 수행했습니다. 기준 빔·Y 절대기준·실제 필드의 부호/단위·허용치와
실제 가공 동작은 장비 담당자가 별도 확정·검증해야 합니다.
화면·데이터·상태 구성은 개발안이며 생산 구현 완료를 뜻하지 않습니다.

ZIP에는 동일 HTML과 이 안내문만 포함됩니다.
