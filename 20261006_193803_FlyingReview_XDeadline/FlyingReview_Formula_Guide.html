1. 역방향 가공시간이30초 안인가?

가공시간 = 가속 + 등속 + 감속

정지 출발→역방향 이동→정지하는 사다리꼴/삼각형 모델입니다. 가공대기 위치부터 입력 Stroke 끝까지이며, 정방향 이동이나 전체 장비 Tact는 이 계산에 포함하지 않습니다.

2. 리뷰가 입력 Stroke 안에 들어오는가?

최소 Stroke = 마지막 측정점 도달거리 + 노출 여유 + Y 감속거리

노출±Jitter까지 Y 등속을 확보해야 합니다. 단순히 마지막 점이 이동거리 안에 있어도 감속 중이면 Flying Review 조건을 만족하지 않습니다. Stroke 밖의 점은 촬영 완료로 처리하지 않습니다.

현재 선택한 기판의 공통 시간축

3. 노출 중 이동 blur는 얼마인가?

blur(px) = Y속도 × 노출(µs) ÷ 125

2.5µm 센서 pixel ÷ 총20x=0.125µm/px. X는 노출 중 정지합니다. Global Shutter도 이동 blur는 발생하며 pixel 환산값이 측정 정확도를 뜻하지는 않습니다.

4. X가 다음 점에 먼저 도착하는가?

다음 점까지 시간 ≥ X 이동·정착 준비시간과 카메라 주기

정착50ms·Guard20ms·지연50µs·Jitter±5µs·노출시간 포함. 기본 카메라 주기1/18.5=54.054ms. X 이동은 가속·감속을 모두 반영합니다.

기판당기판 / HeadY 등속 후보점최소 Stroke(mm)판정

정확한 수식·고정값·계산 전제

Y속도 v, 가속 a, 감속 b, 입력 Stroke S. dA=v²/(2a), dD=v²/(2b). S≥dA+dD이면 T=S/v+v/(2a)+v/(2b). 그보다 짧으면 삼각형 운동으로 T=√(2S(1/a+1/b)), 설정속도에 도달하지 못하므로 등속 가공 불가입니다.

30초 허용 최대 S는30≥v(1/a+1/b)이면 Smax=30v−v²(1/a+1/b)/2. 그보다 짧은 시간창이면 Smax=30²/[2(1/a+1/b)]. 초기2980mm는 Y100·가감속500에서30초를 역산한 예시이며 실제 Stroke 확정값이 아닙니다.

StageY 시작1982.5mm(Scanner 기판 진입 전500mm), 종료=시작−입력Stroke. 측정점까지 이동거리 s=시작StageY−측정StageY. 등속 구간 도달시각 t=v/a+(s−v²/2a)/v. Stroke 외부에는 등속을 유지할 때 필요한 시각만 표시하며 실제 재생·촬영을 늘리지 않습니다.

마지막 노출 중심 이후 여유=Y속도×(노출/2+Jitter), 최소Stroke=max(측정점까지거리)+이 여유+Y감속거리. 첫 노출−Jitter는 가속 종료 이후여야 합니다. Trigger 명령은 노출중심보다 지연50µs+노출절반만큼 선행합니다.

X 이동: vPeak=min(vX,√(2D/(1/aX+1/dX))); Tmove=vPeak/aX+max(0,D−vPeak²/2aX−vPeak²/2dX)/vPeak+vPeak/dX. Tneed=max(노출+Tmove+0.05+0.02+50µs+2×5µs, max(1/18.5,노출)+2×5µs). X 여유=ΔY/vY−Tneed.
