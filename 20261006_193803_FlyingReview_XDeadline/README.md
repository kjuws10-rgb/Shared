# Flying Review — 30초 통과와 촬영점 사이 마감을 분리

현재 조건에서 기판1500mm를 등속 가공할 거리는 충분합니다. **불가는 현재 고정된 측정점 배치에서 X가 다음 점에 늦게 준비되기 때문**입니다. 장비 조건 자체가 불가능하다는 뜻은 아닙니다.

| 문의 입력 | 값 |
|---|---|
| 가감속 포함 역방향 Stroke |2700mm|
| 노출 / 허용 이동blur |10µs / 8px|
| X 속도 / 가속 / 감속 |200mm/s / 150 / 150mm/s²|
| Y 등속속도 / 가속 / 감속 |100mm/s / 150 / 150mm/s²|

| 독립 판정 | 결과 |
|---|---|
| 역방향30초 |27.666667초 — 통과|
| Y 등속 범위 |0.666667~27.000000초 / 2633.333mm — 후보4/4점|
| 이동blur |8px = 1µm — 허용 경계|

**H04 명목 노출 시작26.165078초, X 준비 예산 종료26.544549초, 전체Stroke 종료27.666667초.** 전체30초 안에 준비해도 목표점은 이미 지났습니다. 0.379471초 동안 기판은 Y37.947108mm 이동합니다. 현재 X200mm 구간은 A=D150으로 최고173.205mm/s에 도달하는 삼각형 이동이며, 순수 이동2.309401초+노출/정착/Guard/Trigger여유0.070070초입니다.

기존 “Stroke 내 촬영4/4” 표시는 Y 위치만 확인한 숫자였습니다. **“Y 등속구간 내 후보4/4”**로 수정하고, X·카메라 간격을 별도 판정합니다. 실제Frame·Vision결과가 촬영 완료를 결정합니다.

- `FlyingReview_8Head_Simulator.html`: 문의 조건4점 모드로 시작. 네 조건의 통과/불가, 실패 구간 시간 예산, X 상태 관찰 슬라이더, 구간별 표. 원인 슬라이더는 불가 조건에서도 작동하며 실제 촬영 완료 재생이 아닙니다.
- `FlyingReview_Formula_Guide.html`: 같은 계산 엔진과 설명/도식을 사용합니다. 현재9개 입력·2/4모드·기판 번호를 URL로 전달하며 같은 출처에서 열린 가이드는 변경을 반영합니다. `file://`의 채널/저장소는 브라우저마다 제한될 수 있어 URL 전달과 “현재 조건 가이드 저장” 버튼을 제공합니다. 저장된 가이드는 내보낸 조건을 HTML 안에 고정합니다. 가이드의 복귀 링크도 현재 조건을 보존합니다.
- `0선방어_검토자료.pptx`: 문의 조건 기준3장. ①통과3개·실패1개 ②2초와2.379초의 차이 ③개선 비교. 편집 가능한 도형·텍스트이며 HTML 입력에 따라 자동 갱신되지 않습니다.
- `FlyingReview_X_Timing_Diagnosis.png`: 문의 조건 H03→H04 도식.

## 개선 비교

**A. 조건은 그대로, 유효 측정점만 재선정.** H04를 Cell32의 col2/row16/B07로 선정하면 리뷰 도착이40.5mm 늦어져 간격2.405초, 여유25.529ms입니다. H08은 Cell36 col2/row9/B07로 선정하면21.6mm 늦어져 간격2.216초, 여유31.850ms입니다. X거리 동일, 최소Stroke2657.009333mm <2700mm, 두기판 모두 명목상 가능입니다. 다른8개Cell을 유지하며 기존 기하 엔진의 가공점·Mask·Head소유권 검증을 통과했습니다. 비교만 보여주며 활성 선정점을 자동 교체하지 않습니다.

**B. 현재 선정점 그대로, X 가속/감속250mm/s² 비교.** X속도200 유지, H03→H04 준비1.870070초, 여유0.129930초로 두기판 모두 명목상 가능입니다. 동일 X속도200에서 대칭 가감속 최소값은215.069952mm/s²입니다. Y속도84로만 낮추면 X간격은 개선되지만 전체Stroke32.702857초로30초를 넘습니다.

## 계산 범위와 고정값

역방향 가공대기 StageY1982.5mm에서 출발해 입력Stroke 끝에서 정지합니다. Y 가속·등속·감속을 모두30초 판정에 포함합니다. 정방향·반송·전체Tact는 포함하지 않습니다. Scanner→Review1467mm. 해당점 가공 후 리뷰하며 전체 가공완료를 기다리는 직렬 순서가 아닙니다. 기존 유효Shot범위843.2mm와 전체Process Stroke는 별개이며, 전체Process창을 Laser ON으로 해석하지 않습니다.

기판925×1500mm, Cell9×5/Pitch100×200mm. H01C01/H02C11/H03C21/H04C32/H05C05/H06C15/H07C25/H08C36 모두 다른Cell. X정착50ms, Guard20ms, Trigger지연50µs, Jitter±5µs, 해당점출사여유1ms, X Park0/선행준비2초. Stage설계Stroke3960mm, ReviewX Stroke1025mm. 기존 기본 예시2980mm·노출2µs·blur2px·X A/D1000·Y A/D500는 별도 버튼으로 유지합니다.

Basler a2a2600-20gcBAS: 2600×2128, 센서pixel2.5µm, Global Shutter, 기본18.5fps, 최소노출2µs. Mitutoyo378-810-3 M Plan APO SL20x: NA0.28, WD30.5mm. 200mm 튜브렌즈+1xRelay 총20x 전제로 물체면0.125µm/px, FOV0.325×0.266mm. blur(px)=Y속도×노출(µs)/125, X는 노출 중 정지합니다. 이동blur값은 측정정확도를 뜻하지 않습니다.

실제 S-Curve·FollowError·밝기·SNR·검출성능·Scanner/Laser/Frame/Vision처리시간은 별도 확인이 필요합니다. 개선안의 여유는 위 고정 시간 가정에 대한 명목값입니다. ProcessDone과 ReviewDone은 실제 완료신호로 독립 판정합니다. 자동Offset 적용은 범위에 포함하지 않습니다.

검증: 수치28개+HTML DOM13개, 총41개 통과. 문의 조건의 독립 판정, 두 실패 구간, 대안의 실제 유효점 소유권/Mask, 자동 선정점 교체 없음, X250 비교, 9개 입력·모드·기판 URL 전달, 열린 가이드 변경, 단독 가이드 snapshot, 복귀 링크, 입력오류를 확인했습니다. HTML의 실제 SVG 및 PPT3장을 렌더링해 한글·배치를 확인했습니다. 전체브라우저 픽셀·모바일터치 검증은 Chromium socket 생성 제한으로 미완료이며 live 연결은 동일출처 채널을 모의한 시험입니다. 실제 장비 촬영성공은 검증하지 않았습니다.
