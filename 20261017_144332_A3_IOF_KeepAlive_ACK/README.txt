0선방어 측정 i=1~N 각각의 시퀀스 시작에서1900을1회 확인합니다.
정상 N회 측정이면1900은 총 N번입니다.1002/1003 앞에 추가1900을 넣지 않습니다.
0선 OFF에서는 해당0선 업무를 생략합니다.

i 시작1900 정상 확인 →1001 Ready/ACK → LINE 연속 Trigger/Grab
→ LINE 끝·마지막 노출 종료 →1002 송신 → Process의 정상1002 ACK 수신

1002 ACK를 Process가 받기 전에는 다음 X Request를 시작하지 않습니다.
정상 ACK 수신 시 X 허가·이전 요청 복귀를 확인하여 다음 X 요청을 시작합니다.
1003 송신·응답·결과 완료는 X 개시 조건이 아니며 두 경로가 병행합니다.
1002 ACK는 검사 전체 완료·측정 OK·0선Done을 뜻하지 않습니다.
연속 Y의 다음 촬영 마감에는1002 ACK 지연과 그 뒤 X 이동·정착 시간을 포함합니다.

Process 도식의 수평 전달은 실선 화살표입니다. 화살촉이 수신자이며 라벨에 송신자→수신자와 통신 종류를 표기했습니다.
남색=Melsec(Stage↔Process), 주황=TCP 요청(Process→Vision), 초록=TCP 응답(Vision→Process), 보라=HW Trigger(Stage→Vision).
세로선은 PC별 시간 흐름입니다. Process 내부 Trigger 관측은 상자로 표시했습니다.

Process Ready 위치 도착·정지 확인 후 Melsec에 PEG 위치 쓰기.
이동 중 PEG 쓰기 금지,0선 OFF의 Stage 좌표 미읽기/미적용·잔류0선 Trigger 미사용을 유지합니다.
실제 MOF가 먼저 시작되고 일반 측정/TCP 오류로 중도 정지·재실행하지 않습니다.
0선 ON: 가공Done AND0선Done, OFF: 가공Done으로 상위 Process COMPLETE.
마지막 촬영까지 필요한 유한 Y 주행을 유지하고 TCP만 남았다고 무한 주행하지 않습니다.
미촬영·미수신·연결 복구를 정상0선Done으로 바꾸지 않습니다.
