A3 Review 보정 · Head / Head–Cell 첫 가공홀 기준
작성일: 2026-10-23

HTML을 다운로드하여 브라우저로 열면 그림과 직접 조작 예제를 볼 수 있습니다.
페이지 상단 바로가기로 두 방식 비교, Head·Cell 직접 바꾸기, Rough 자동 측정을 확인하세요.

핵심 기준
- Head: 각 Head가 담당하는 최상단 Cell의 첫 가공홀에서 얻은 값을 해당 Head의 모든 Cell에 동일하게 적용합니다.
- Head–Cell: 각 Cell 안의 해당 Head 첫 가공홀에서 얻은 값을 해당 Cell·Head 구역에만 적용합니다.
- 같은 Head끼리 값을 공유할지, Cell·Head마다 독립적으로 값을 가질지를 금색 첫 홀과 색상 구역으로 비교합니다.
- Simple은 선택 대상 한 개의 측정·적용, Rough는 선택 대상들의 첫 홀을 자동 순회·측정합니다.

수정 내용
- 06 비교, 08 Simple, 09 Rough와 관련 개발·검수 항목을 최신 기준으로 정리했습니다.
- 비교·선택 구역·진행 순서 그림 3종을 5곳에 배치하고 공통 예제의 금색점도 첫 홀로 맞췄습니다.
- Head·Cell·보정 방식을 바꾸면 기준점과 적용 구역이 함께 변경됩니다. 대상별 편차 입력은 독립적으로 기억됩니다.
- 기존 Fine·Y보간과 관련 없는 28개 section 및 내장 이미지 11개를 보존했습니다.

검증 및 적용 범위
- 3개 에이전트가 의미·그림·JS를 분담하고 검토했습니다.
- Chromium 화면·동작 41개 검사 PASS, 독립 JS 검토 12개 PASS입니다.
- 원본 첨부와 완성 HTML을 보존한 공유본입니다. 외부 폰트·이미지·스크립트 없이 동작합니다.
- C1 최상단, 2 Cell × 3 Head, Y0/X1·3·5는 교육용 가정입니다. 실제 기준점은 실제 Recipe의 배치·가공 순서·유효 목록으로 결정합니다.
- 생산 SW·실제 Recipe/장비·가공 정확도는 이번 문서·교육 예제의 검증 범위에 포함되지 않습니다.
