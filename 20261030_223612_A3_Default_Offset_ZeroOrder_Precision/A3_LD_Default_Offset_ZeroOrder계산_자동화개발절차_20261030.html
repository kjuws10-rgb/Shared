방법장점주의점권장 사용

3. Zero Order는 “16빔의 가공 기준 중심”

리뷰카메라는 실제 마크를 보고, 프로그램은 마크 사이의 가상 중심을 구합니다.

평균을 무조건 바꾸는 것이 목표가 아닙니다.

대칭 4×4를 정확히 찾았다면 평균은 올바른 중심입니다. 새 기능은 DOE 배치에 맞는지 확인하고, 비대칭·잘못 찾은 빔·측정 불량을 구분한 뒤 중심을 계산합니다.

4. 분해능 × Pitch로 “예상 간격”부터 계산

예상 간격은 탐색과 슬롯 식별을 돕습니다. 실측 간격·회전·왜곡 검사까지 통과해야 최종 중심을 저장합니다.

입력기능검증
Rows / Columns / 슬롯 좌표4×4뿐 아니라 DOE별 배열과 원점 위치 저장16 슬롯 모두 고유 번호
Pitch 값 + 단위명령단위면 r을 한 번 곱함. mm면 그대로 사용가공홀 Pitch를 DOE Pitch로 자동 대체하지 않음
카메라 가로·세로 해상도, 센서 Pixel, 유효 배율초기 FOV와 탐색 간격 계산해상도·배율만으로는 mm/px 확정 불가
실측 Camera 보정, Head별 DOE 프로필Flip·회전·왜곡 반영 후 좌표 변환DOE/렌즈/높이 변경 시 다시 확인
현재 Default와 입력 응답 K추천된 물리 이동량을 입력 Offset으로 변환카메라 이동 환산값과 구분
Recipe 필드 연결

확인한 코드의 CELL_PIXEL_SIZE는 가공점 표시 크기로, CELL_PITCH_X/Y는 Cell 가공좌표 생성에 쓰입니다. 이름만으로 DOE 분기간격이라고 연결하지 않습니다. DOE Pitch 전용 정의 또는 확인된 변환관계를 등록합니다.

5. “비율을 고려한다” = DOE 원점 기준 격자 맞춤

빔에 임의의 가중치를 주는 방식이 아니라, 각 빔과 원점 사이의 알려진 위치 관계를 계산에 넣습니다.

개발 계산식
설계 슬롯 dᵢ = (DOE 원점 기준 X, Y)
대칭 4×4: dᵢⱼ = ((j−1.5) PitchX, (i−1.5) PitchY)
실측 mᵢ = 중심 c + A × dᵢ + 측정오차

구할 값: c(중심 X/Y), A(회전·간격·전단의 2×2 행렬)
min Σ || mᵢ − c − A dᵢ ||²
→ c가 DOE 원점(0,0)의 실측 위치

설계 좌표는 알려진 입력값. 16점 잔차를 숨기려고 슬롯 좌표를 임의로 변경하지 않음.
실제 구현은 수치 안정성을 위해 QR/SVD 사용, 좌표/행렬 퇴화와 조건수 검사.

6. 평균이 맞는 조건과 더 정밀하게 가는 조건

16개 평균은 대칭·동일 비중 모델의 정확한 특수해입니다. 새 계산은 식별·모델·품질을 함께 검사합니다.

경우계산개발 판단
대칭 완전 4×4 + 선형 변환 + 동일 비중c = 16점 평균 = affine 맞춤 원점평균 대비 숫자 정밀도가 자동 향상되는 것은 아님
비대칭 DOE 기준 좌표각 슬롯의 알려진 좌표를 넣어 c 계산단순 평균과 다른 원점이 맞을 수 있음
점마다 반복측정 분산이 다름WLS/GLS: 분산이 작은 좌표에 더 높은 신뢰도밝기·마크 면적·중심까지 거리로 임의 가중 금지
검증된 비선형 Beam Map 존재원점에 대한 교정된 상대 좌표/모델로 맞춤Camera 왜곡은 먼저 교정. Beam Map은 원점 기준과 버전 필수
잔차 큼 / 오인식 / 15개만 검출해당 슬롯 재촬영·재접근후보 추정은 탐색용. 최종 16/16 gate 유지
가중치와 불확도 구현
Σᵢ = 반복 촬영·재접근으로 확인한 마크 좌표 공분산
GLS: min Σ (mᵢ − c − A dᵢ)ᵀ Σᵢ⁻¹ (mᵢ − c − A dᵢ)
축별 독립·등방성인 단순 경우만 wᵢ = 1 / σᵢ²인 WLS로 축별 계산

잘못된 식: Σ wᵢ mᵢ / Σ wᵢ     // DOE 설계좌표 관계를 빠뜨림
올바른 식: 설계좌표 dᵢ와 실측 mᵢ를 함께 가중 맞춤

엔코더·카메라 교정·프로필 원점 오차는 공통 성분으로 별도 관리.
16점이라고 전체 정확도가 항상 4배 좋아지는 것은 아님.
중앙 4점과 외곽 점의 원점 차이는 이상 진단값이며, 더 작은 RMS만 보고 모델을 바꾸지 않음.
순환 교정 방지

실측 DOE 간격을 예상 Pitch와 강제로 같게 만들어 카메라 배율을 맞추지 않습니다. 카메라는 독립 기준으로 교정하고, 실제 DOE 간격 편차와 원시 16점 좌표는 그대로 보존합니다.

7. 어디에서 찾든 FOV 중앙까지 자동 이동

분해능과 예상 Pitch로 탐색 범위를 만들고, 실측한 위치로 중심을 다시 계산합니다.

작업쉬운 설명개발 처리
영상 좌표를 mm로 변환마크가 화면 중앙에서 얼마나 떨어졌는지 실제 길이로 환산카메라 Flip·회전·왜곡 보정 → 실제 축 기준 이동
촬영 위치와 연결사진 찍은 순간 카메라가 본 위치를 엔코더로 기록같은 시점의 X/Y + 영상 차이. 이미 절대좌표면 엔코더를 재가산하지 않음
가상 중심 이동16개 마크에서 구한 중심 위치로 Review X / Main Y 이동이동 제어권·축 범위·Laser OFF 확인 후 이동
빈 중심 검증중앙에 홀이 없어도 주변 마크를 다시 보면 위치가 맞는지 확인 가능선택 슬롯 재방문 → 재계산 중심 복귀 → 편차 확인
좌표 변환과 중앙 맞춤
p₀ = ((영상폭−1)/2, (영상높이−1)/2)   // 실제 지정 FOV 중심
J = [축 X/Y를 실제로 움직였을 때 영상이 몇 px 움직이는지] 2×2 교정 행렬
각 마크를 중앙에 맞추는 축 이동 = J⁻¹ × (p₀ − 마크 영상위치)
마크 위치 = 촬영 당시 축 엔코더 + 위 이동량     // 공통 축 좌표 표현

1) Laser OFF → 제어권 확인 → 이동 → 정지·안정화 → 촬영
2) 왜곡 보정 후, 각 점을 개별 변환. 비선형 변환은 픽셀 차이만 넣지 않음.
3) 카메라 축 좌표에서 기판/Head 공통 mm 좌표로 변환 후 격자 맞춤.
4) 계산된 중심의 축 목표로 이동 → 실제 도착 엔코더 확인.
5) FOV가 작아 중심이 비어 있으면 기준 슬롯 재방문으로 검증.

J는 카메라 구동 환산. Scanner Default 응답 K와 별도 저장.

8. 자동 탐색은 “예상 → 식별 → 재측정”

Pitch는 첫 위치를 찾는 힌트입니다. 슬롯 확인과 실제 측정이 최종 판단입니다.

기능자동 동작미완료 조건
예상 간격 탐색FOV보다 조금 작은 간격으로 겹쳐 검색 → 실제 간격으로 다음 후보 예측시간/영역 초과·이미지 불량
슬롯 식별DOE Rows/Cols·방향·원점좌표표로 후보 비교대칭 격자의 방향이 복수로 가능하면 기준 마크/Head 방향정보 추가
재측정최대 잔차·흐림·중복 슬롯을 지정해 재촬영이상점을 삭제하거나 15점 평균으로 최종 완료하지 않음
중심 복귀16점 맞춤 후 중심 위치 이동축 범위·교정·제어권·공통 기준 불일치

9. 계산 비교: 평균과 원점이 언제 달라질까?

16개 숫자만 평균하지 않고, 그 숫자가 어느 슬롯의 위치인지 함께 계산합니다.

예제를 눌러 중심 계산을 비교하세요. 모든 값은 장비 규격과 무관한 합성 데이터입니다.

비대칭 예제

원점은 (1.234, 5.678) mm입니다. 알려진 X 슬롯 좌표가 −135, −45, +55, +165 μm이면 평균은 X=1.2442 mm로 치우치지만 격자 맞춤은 원점 X=1.2340 mm를 구합니다. 대칭 예제에서는 두 결과가 같습니다.

이 예제의 계산 범위

16점 affine 모델과 독립·등방성 위치 오차를 가정합니다. 최대 잔차 한계 5 μm·공통 표준편차 2 μm는 설명용 값입니다. 실제 장비는 검증된 허용치, 방향/크기/전단/Pitch·반복성·Field·Revision 조건을 추가로 검사합니다.

10. Y 측정은 Q−R, 중심 계산만 새 방식으로 개선

카메라 중심 계산이 정밀해지면 R도 더 안정적으로 얻을 수 있습니다. 기존 기구거리와 측정쌍은 유지합니다.

Y 목표와 Offset을 구분

1277/1657 mm는 기구 기준거리입니다. 이 전체 거리를 Default에 입력하지 않습니다. 실측 거리와 목표의 차이만 보정합니다. 가공 명령 Y=0, 추가 Shift=0 조건을 저장합니다.

11. 유효한 Default 추천: 중심 + 현재 값 + Field

중심을 잘 찾는 것과 스캔 가능한 추천값을 만드는 것은 별도의 계산입니다.

추천값 계산과 실제 반영
현재 Default가 반영된 실측 거리 D
Head 열별 목표 Dnom = 1277 또는 1657 mm
거리 편차 r = D − Dnom
Head의 Default 입력 응답 k = Default 1 변화 시 물리 거리 변화

공통 출사 조정 없음: Bnew = Bcur − r / k
실제 공통 Y 조정 지원: Bnew = Bcur + (c − r) / k
→ 실제 광학 기준 Dnew = Dnom + c
→ 실제 MOF 출사 엔코더 Qnew = Qcurrent + s × (cnew − ccurrent)

예: 1277 − 5000 = −3723
    1284 − 5007 = −3723   // 같은 기판 위치 유지

c는 단순 평균으로 고정하지 않고, 전체 Head의 최종 Field 제약 안에서 선택.
기존 Default도 포함. 값 이름만 나눠 적고 실제 출사 구간이 같으면 Field 개선 없음.
공통 이동 미지원: c=0 고정. 현재 c≠0인데 지원 상실: 계산·적용 차단.
축추천 계산적용 경계
X기판 중앙 + 설계 Head Pitch − 실측 중심 → Head별 입력 응답 역변환Review X 이동은 측정 이동. 실제 가공 X 보상과 구분
Y기구 목표거리와 실측 Q−R 잔차 + 지원되는 공통 출사 c실제 출사 엔코더·구간까지 함께 반영
X 공통 / θ실제 기판 X/UVW 회전 지원이 확인된 경우에만 함께 계산기판 기준·회전 중심·X/Y 재측정·전체 Field 확인
2축 결합Default 입력 반응 K가 2×2라면 ΔB = K⁻¹ × 필요한 물리 이동X/Y 교차반응이 크면 독립 1축 계산으로 적용하지 않음
8 Head 격자 원점과 Field는 별개

각 Head의 설치 오차를 전 Head 직선 회귀로 지워서 처리하지 않습니다. Head별 실측 중심은 보존하고, 그 결과를 이용해 공통 기준·개별 Default를 제한 범위 안에서 함께 추천합니다.

Default 이후의 리뷰 보정

Default로 기판 기준과 Head 기본 가공 위치를 맞춘 뒤, 실제 가공 결과에 Simple / Rough 보정 → Fine 정밀 보정을 적용합니다. 슬롯 식별 실패나 무효한 중심 계산을 리뷰 보정으로 덮어 완료 처리하지 않습니다.
