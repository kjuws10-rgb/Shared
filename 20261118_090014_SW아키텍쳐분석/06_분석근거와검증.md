## 도구 자체의 검증과 보완

추출기 .NET 합성 회귀 18/18, Python 생성/검증기 회귀 9/9를 별도 도구 작업 사본에서 실행했습니다. 소스 솔루션을 빌드하거나 벤더 참조를 로드한 검사가 아닙니다.

생성기 1.1.2는 PreviewTextInput·LostMouseCapture·Expanded·LoadingRow·AutoGeneratingColumn의 누락 이벤트를 추가했습니다. 검증기 1.1.1에는 생성기의 whitelist에만 의존하지 않는 XML/코드비하인드 이벤트 후보 대조와 XAML/manifest 수량 검사를 추가했습니다. 이 소스의 58 XAML에서 독립 확인한 이벤트305·명명요소377·Binding2904개를 재검증합니다.

생성 출력 경로가 소스 또는 manual 입력과 같거나 상위/하위로 중첩되는 경우를 양방향 차단했습니다. 합성 fixture로 거부와 입력 보존을 확인했습니다. 실제 이번 작업의 소스·manual·staging은 처음부터 서로 분리되어 있었으며 이 경계 문제로 원본이 바뀐 사실은 없습니다.

새 staging을 만든 뒤 검증된 생성 영역만 병합합니다. 기존 출력 폴더에 반복 생성하여 남는 오래된 JSONL이나 원본 정규화 위험을 피하면서 manual/CHANGELOG/과거 검증·다른 Shared 문서를 보존합니다.

## 근거 수준·개인정보·재현 한계

모든 추적 파일을 분류하고 모든 명시적 C# 타입·멤버와 원본 줄을 자동 추출했습니다. 사람이 추적한 15개 상세장은 별도 manual에 있습니다. 자동으로 모든 줄에 해설이 붙는 것과 모든 줄의 물리 의미를 사람이 검증했다는 것은 다릅니다. resolved는 문서용 부분 컴파일의 정적 심볼 연결입니다.

측정·운영 CSV 실제 행, 인증정보, 로컬 비공개 작업실은 공개하지 않습니다. 벤더 DLL은 경로·크기·해시와 호출 래퍼 근거만 다룹니다. 장비 프로그램·AeroScript·벤더 DLL 실행/로드/역컴파일은 하지 않았습니다. source-model 전체 대형 JSON과 private 조사 로그는 게시하지 않습니다.

기존 원문에서 물려받은 인코딩 이상은 원문 복원 예외로 기록하며 새 해설 문자 오류와 구분합니다. 삭제되었던 offline-studio 생성 자료는 현재 source SHA로 재생성해 복구했습니다. 이전 manual/CHANGELOG/검증 이력과 다른 Shared 파일을 보존했습니다.
