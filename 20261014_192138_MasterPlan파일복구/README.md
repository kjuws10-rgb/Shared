# A3 LD MasterPlan 파일 복구

[복구본 엑셀 내려받기](A3LD_SW_MasterPlan_개발검증분리_복구본_20261014.xlsx)

기존 문제 파일 대신 이 폴더의 복구본을 사용하세요. Process 데이터를 포함한 셀과 수식은 원래 파일에 남아 있었으며, 데이터를 다시 작성하지 않고 Excel 파일 내부의 구조 오류를 수정했습니다.

## 수정 내용

- Process와 Total: 셀 메모의 표시 정보를 파일 규격에서 요구하는 순서로 옮겼습니다. 기존 메모 내용과 표시 연결은 보존했습니다.
- Vision과 PLC: 허용되지 않는 인쇄 해상도 값 0을 제거하여 기본 인쇄 해상도를 사용하도록 했습니다. 용지·방향과 화면 서식은 유지했습니다.

Total, Stage, Vision, Process, PLC의 5개 탭과 탭 순서를 유지했습니다. 진행률, 개발·검증 일정, 상세항목, 수식, 병합, 행·열 설정, 조건부 서식, 그림과 메모는 변경하지 않았습니다. 원본 파일은 덮어쓰지 않았습니다. A3 프로그램 코드도 수정하지 않았습니다.

## 검증 결과

Microsoft Open XML SDK의 파일 규격·구조 검사에서 오류가 수정 전 4건에서 수정 후 0건으로 줄었습니다. 파일 압축 무결성, 내부 파일 연결 49개, 행·셀 순서와 병합 영역도 확인했습니다.

복구본을 다시 읽어 5개 탭의 값과 수식을 대조하고, Process의 머리말·Manual MOF·통합검증 구간 및 다른 탭의 화면을 확인했습니다. Process의 같은 구간은 수정 전후 렌더링 이미지도 동일합니다. 스타일 정의와 수정 대상 밖의 파일 구성 77개도 동일합니다.

이 환경에는 Microsoft Excel 데스크톱이 설치되어 있지 않아 실제 Excel 앱에서 재열기 시험은 수행하지 못했습니다. 규격 검사와 재읽기·화면 검증 결과는 [검증 기록](검증기록.json)에 있습니다.
