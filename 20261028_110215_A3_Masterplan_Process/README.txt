코드 진행률 평가 기준
0%: 해당 구현/완료 근거 미확인
25%: 구조·준비 기능 또는 초기 구현
50%: 부분 구현, 또는 실제 실행 연계가 남음
75%: 주요 경로 구현, 일부 기능/통합·검증이 남음
100%: 명시된 코드 단위 기능 구현 확인
25% 간격의 검토 추정치이며 공수 실적이나 실기 검수 합격률이 아닙니다.
실기·고객 Script 비교·실측 검증이 필요한 항목은 근거를 별도로 구분했습니다.
