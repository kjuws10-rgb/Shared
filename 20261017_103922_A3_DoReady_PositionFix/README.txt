A3 DoReady 시퀀스 · 객체 배치 수정 / 틀고정 없음
2026-10-17

이전 파일에서 객체가 한쪽으로 겹친 배치 방식을 수정했습니다.
시나리오와 평가 체크리스트 두 시트 모두 틀고정·분할 없이 열립니다.
41개 객체는 시트의 절대좌표에 배치됩니다.
텍스트 도형32개와 선/화살표9개는 각각 직접 수정할 수 있습니다.
이미지 객체는 없으며 문구·크기·화살표·상세표·평가 입력란은 보존했습니다.

상자 문구는 객체를 선택해 텍스트 편집, 위치/크기는 조절점으로 수정합니다.
선택이 어려우면 Excel의 선택 창에서 이름으로 객체를 선택합니다.
행·열 크기를 바꿔도 도식의 고정된 위치·크기는 유지됩니다.

기존 사용자1~8단계와 Stage 이동/Process 준비 병행,
Script·0선방어·MOF/Melsec 갱신·두 COMPLETE·ZeroSet/8TaskRUN·Laser/Precheck,
선후도착 Process ABLE 대기 조건을 유지했습니다.
상세표는71행부터, 평가24항목과Task8개 기록의32개 판정은미평가입니다.
실제 Ready좌표·주소·OFF복귀조건·설비 내부순서 및 장비시험은 별도확인 대상입니다.
