A3 LD UI HTML 체험판

폴더 전체를 유지한 채 index.html을 Edge/Chrome에서 여세요. 인터넷·별도 설치·서버 없이 열립니다. ZIP은 먼저 전체 압축 해제하세요.

  1. 상단 Auto / Manual / Recipe / Setting / Monitor와 PNG 안 버튼을 누르면 연결된 상태로 이동합니다.
  2. 항목에 마우스를 올리거나 키보드 초점을 주면 말풍선이 열립니다. ‘설명 모드’를 켜고 클릭하면 조작 없이 설명을 고정합니다. Escape로 닫습니다.
  3. 입력칸과 복수 Head 선택을 변경할 수 있습니다. 같은 작업공간은 이전 결과 요약을 남기고 다음 구역을 펼칩니다. 좌측 단계·하단 연결도 같은 방식입니다.
  4. Auto에는 사이드메뉴·탭·상세 팝업이 없습니다. 대표 상태 클릭 시 인라인 상세가 열립니다. 다른 메뉴의 확인창은 대상과 초안을 배경에 유지합니다.
  5. 셀을 누르면 Cell→Shot 상세, 보정에서는 현재/후보/적용 비교, Interface에서는 신호 매트릭스가 화면 아래 펼쳐집니다. ‘상세로’로 펼친 부분까지 이동할 수 있습니다.
  6. ‘전체 항목 검색’에서 항목명이나 체크리스트 번호로 찾고 해당 화면·말풍선을 바로 열 수 있습니다.
  7. 시연 시작·정지·저장은 브라우저 임시값과 체험 로그만 처리합니다. 실제 장비 명령·Recipe 파일·PLC 메모리·레이저·보정 계산은 실행하지 않습니다.

표시와 실제 동작 구분

PNG는 UI 제안 이미지이고 새 기능 화면은 HTML 요소입니다. Git UI 화면 코드를 참고했지만 프로그램을 실행해 캡처한 자료는 아닙니다. 기존 PNG의 정적 숫자 대신 파란 ‘체험 상태’ 줄과 노란 초안 표시를 보세요. 현장 안전·RMS/CIM 매핑·ATT 산식 등 미확정 사양은 확정된 것처럼 구현하지 않았습니다.

실제 개인정보·비밀번호·운전 파라미터를 입력하지 마세요. 임시값은 이 브라우저에만 저장하며 브라우저 정책에 따라 파일 열기에서는 저장이 제한될 수 있습니다. ‘체험 초기화’는 이 체험판 값만 초기화합니다.

74개 상태 / 공통 상세

기존 74 PNG를 모두 포함하며 72개 운전·설정 상태와 안내 2개를 연결했습니다. 모든 이미지의 필드·표 셀·열 제목·상태·단계·도식·버튼에는 말풍선 대상이 있습니다. 복잡한 부가 동작은 의도와 다음 확인사항을 인라인 설명으로 제시합니다.
