발견 후 개선한 부분

  • Head 상태 카드 위에 불필요하게 씌워지던 선택 음영 제거
  • 마우스·포커스 말풍선이 버튼 클릭을 막지 않도록 수정
  • 복수 Head 확인 표를 정적 예시에서 실시간 선택 초안 표시로 개선
  • 공통 표준 00B의 말풍선 좌표를 실제 4개 패널 구조로 보완
  • MOF 안에서 PtoP/결과/보정을 메뉴 이동 없이 인라인 연결
  • 흐린 제한 버튼은 가짜 진행 대신 차단 사유·확인 영역을 표시
  • 실제 원본에서 확인되지 않는 Controller Reset 줄 범위를 정정
  • 확인창 딥링크가 해당 메인 작업공간에서 열리도록 수정

  • 실장비·원본 앱 실행·가공 좌표 계산·보정 알고리즘·CIM/PLC/Vision 통신 검증은 하지 않음
