# A3 LD 완료 항목 상세 화면 안내

요구기능 체크시트에서 완료 항목의 상세내용을 누르면 해당 항목의 설명과 부분 화면을 볼 수 있습니다. 화살표는 확인할 버튼, 입력값 또는 상태 표시를 가리킵니다. 원본 체크시트의 상태와 이번 코드 분석 판정을 구분했으며, 코드 본문은 싣지 않았습니다.

## 엑셀 사용

[완료 항목 상세 탭과 화살표 안내 엑셀](A3_LD_완료항목상세탭_화살표안내.xlsx)을 내려받아 Excel에서 여세요. 첫 탭의 상세내용을 클릭하면 완료 항목의 상세 탭으로 이동합니다. 상세 탭 상단에서 체크시트 또는 이전과 다음 완료 항목으로 돌아갈 수 있습니다. 설명과 화살표는 편집할 수 있습니다.

- 녹색 완료 음영 113개는 개별 상세 탭과 부분 화면을 제공합니다.
- 연한 노란색 진행중 음영 11개는 본표의 상세내용만 작성했습니다. 기존 행 높이를 유지하므로 긴 내용은 수식 입력줄이나 F2로 읽을 수 있습니다.
- 밝은 노란색과 무음영 171개는 원본 그대로 유지했습니다.
- 첫 체크시트의 기존 값, 음영, 글꼴, 행 높이, 열 너비와 병합은 보존했습니다.
- 253번은 녹색이지만 상태 글자가 미완료입니다. 원문을 유지하고 상세 탭에 불일치를 표시했습니다.

## 검증 범위

화면은 실제 WPF 프로그램을 별도 검증 Clone에서 전 장치 시뮬레이션으로 구성한 뒤 일부를 캡처했습니다. 화면 표시와 코드 구현 확인은 실장비 합격 판정과 다릅니다. 레이저 출사, 축 이동, Home과 Power Tune은 실행하지 않았습니다. 전용 구현이 확인되지 않은 항목이나 빈 결과 표에는 참고 범위를 명시했습니다.

원본 저장소의 파일 수정, Commit과 Push는 수행하지 않았습니다. 읽기 전용 분석 Clone은 분석 Commit 그대로이며 작업 트리가 깨끗하고 Push URL은 비활성화되어 있습니다.
