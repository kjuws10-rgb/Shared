A3 LD 요구기능 검증 체크시트 — 완료 항목 상세 탭 / 부분 화면 화살표 안내

사용 방법
1. 첫 체크시트 탭의 상세내용(I열)을 클릭하면 해당 완료 항목의 상세 탭으로 이동합니다.
2. 상세 탭에서 화살표가 가리키는 버튼·입력값·상태 표시를 확인하세요. 빨간 버튼 위에는 잘 보이도록 노란 화살표를 사용했습니다.
3. 상단의 ‘체크시트로 돌아가기’와 이전·다음 완료 항목 링크로 이동할 수 있습니다.
4. 설명과 화살표는 Excel에서 편집할 수 있습니다. 프로그램 화면 부분 캡처는 그림 객체입니다.

작성 범위
- 녹색(FFC6EFCE) 113개: 상세내용 작성 + 개별 상세 탭 + 부분 화면 + 확인 화살표.
- 연한 노란색(FFFFEB9C) 11개: 본표 상세내용에 분석 작성. 개별 상세 탭 없음.
- 밝은 노란색 및 무음영 171개: 분석 대상에서 제외하고 원본 그대로 보존.
- 본표의 글꼴·음영·행 높이·열 너비·병합·기존 상태 글자는 원본을 유지.
- 진행중 항목은 기존 행 높이를 유지하므로 자세한 셀 내용은 수식 입력줄 또는 F2로 읽을 수 있습니다.
- 253번은 녹색이지만 진행현황 글자가 ‘미완료’입니다. 원문을 수정하지 않고 불일치를 설명했습니다.

판정 및 화면의 의미
- 원본 ‘완료’ 음영과 이번 코드 분석 판정은 별개입니다. 원본 상태를 새 합격 판정으로 바꾸지 않았습니다.
- ‘코드 구현 확인’은 소스 경로가 확인되었다는 의미이며 실장비 합격을 뜻하지 않습니다.
- ‘부분 구현 또는 사양 차이’와 ‘현재 코드에서 미확인’을 구분했습니다.
- 화면은 실제 WPF 프로그램을 별도 검증 Clone에서 전 장치 시뮬레이션으로 구성해 캡처했습니다.
- 실장비 연결, Laser 출사, 축 이동, Home, Power Tune 명령은 실행하지 않았습니다.
- 빈 결과 표나 참고 화면은 기능 완료를 증명하는 결과로 제시한 것이 아닙니다.
- 소스 위치는 파일 이름과 Commit 고정 링크만 제공하며 코드 본문은 싣지 않았습니다.
