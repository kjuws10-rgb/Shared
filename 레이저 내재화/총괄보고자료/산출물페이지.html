2. A3 LD 과제 요약

A3 LD는 넓은 기판 안에 정의된 수많은 미세 가공점을 여러 Laser Scanner가 빠르고 정확하게 가공하도록, Recipe → 좌표계산 → Stage 이동 동기화 → Laser 가공 → Review 측정 → Offset 보정 을 하나의 SW 흐름으로 연결하는 과제다.

  1. 사용자가 Excel/CSV Recipe에 기판, Cell, Pixel Pattern, Laser와 Scanner 조건을 입력한다.
  2. Review Camera가 기판의 기준표시인 AK1을 측정해 실제 기판 위치와 회전을 찾는다.
  3. SW가 설계좌표를 Stage Global 좌표로 바꾸고 각 Scanner가 움직일 GX/GY 명령을 계산한다.
  4. 기판이 Scanner 아래를 이동하는 동안 Stage Encoder를 읽어 MOF 방식으로 가공한다.
  5. 가공 후 Review Camera가 결과를 측정하고 오차를 다음 가공 Offset으로 반영한다.

3. 장비 배치와 실제 물류

기판 기준으로 Review Camera가 먼저 있고 Scanner가 그 뒤에 있다. 기판은 Scanner 위치까지 정방향으로 이동한 뒤 방향을 반전하고, 원점 방향으로 돌아오면서 MOF 가공한다. 가공 후 Review Camera에서 측정하고 Home으로 복귀한다.

  2. 정물류 이동 중 Review Camera 통과
  3. AK1 측정
  4. Scanner 뒤쪽 Turnaround까지 이동
  5. 방향 반전
  6. 역물류 AK1→AK2 순서 MOF
  7. Review 후측정
  8. Offset 계산
  9. Home 복귀

8개 Scanner는 X 방향으로 넓은 기판을 나누어 담당한다. 기계적으로 홀수/짝수 Head가 Y 방향으로 어긋난 지그재그 배치지만, MOF에서는 기판이 Y 전체를 지나가므로 가공 가능 여부는 각 Scanner의 X 중심과 X Field 반폭을 기준으로 판단한다.
