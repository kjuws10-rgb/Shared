# CIM·PLC·가공 인터페이스 명세

기준: 2026-11-18. 참고 PPT는 이번에 첨부한 상세플로우 검토자료 3장이며, 현재 첨부 OSS·CIM V235와 대조했다. 사양 확인·설계 제안·협의를 구분한다. 구현·실통신·실장비 검증 완료 자료가 아니다.

- 주소 확인은 구현/통신/실기 합격을 뜻하지 않는다.
- SECS 전문의 A[40]은 메모리 FLOAT/INT/Factor와 다른 계층이다.
- 미할당 주소·필드길이·타이밍·Timeout·단위·기본값은 새로 만들지 않았다.
- 같은 주소라도 module endpoint가 다르면 별도 공간일 수 있다.
- 표의 No를 ECID/PLC주소/전역고유ID로 해석하지 않는다.
- 첨부 2쪽 03의 신규 기판 투입과 3쪽 PinReady 후 수신은 순서가 충돌한다. 실제 투입 허가를 임의 확정하지 않는다.
- 첨부의 약 5~6분은 전셀검사 제외 예상이고 실측/인수 기준이 아니다. 전셀검사는 최종 완료 요구에서 별도로 유지한다.
- 가공 SW의 제품별 요구 핀정보, PLC 기존 핀설정, 실제 핀상태/실측값은 역할이 다르다.
- Distortion의 제품명목조건·원측정·계산보정·이번기판 적용좌표·영구 Recipe 저장은 구분한다.
