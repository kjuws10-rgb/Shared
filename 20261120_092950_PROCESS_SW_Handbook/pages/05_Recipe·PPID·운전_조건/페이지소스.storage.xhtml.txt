<p>Recipe를 화면에 여는 일, 운전 대상으로 선택하는 일, 수정값을 저장하는 일은 서로 다르다. 이번 기판에서 사용한 값은 준비 단계에서 합성된 실행 사본으로 확인하며, PPID의 상위 요청과도 구분해 연결한다.</p>
<h2>VIEW·SELECT·SAVE를 나누어 읽기</h2><p>VIEW는 내용을 보고 편집할 대상을 여는 기능이다. SELECT는 운전에서 사용할 Recipe를 정하는 기능이며, SAVE는 변경한 내용을 저장한다. 화면에 Recipe가 보인다는 사실만으로 운전 선택이 바뀌었다고 판단하지 않는다.</p><p>예를 들어 운전 Recipe를 선택해 준비한 뒤 다른 Recipe를 열어 볼 수 있다. 이때 화면의 편집 대상, 운전 선택 대상, 이미 준비된 실행값이 각각 다를 수 있으므로 세 값을 이름과 시점으로 맞춘다.</p><p><ac:image ac:width="1200" ac:alt="화면에서 보는 대상과 운전 선택, 실행 사본을 분리한다."><ri:attachment ri:filename="p19_05_A.png"/></ac:image></p><p><em>화면은 편집 대상, 문서는 운전 Recipe, 자물쇠는 준비된 실행 사본을 나타낸다. 화살표는 선택·준비 동작을 거친 연결이며 열기만으로 가공 조건이 바뀐다는 뜻은 아니다.</em></p><table class="wrapped"><tbody><tr><th>동작</th><th>바뀌는 것</th><th>그 동작만으로 끝나지 않는 것</th></tr><tr><td>VIEW</td><td>현재 열어 보는 대상</td><td>운전 선택과 장치 적용</td></tr><tr><td>SELECT</td><td>운전 Recipe 선택</td><td>좌표·실행 파일의 재생성</td></tr><tr><td>SAVE</td><td>저장한 조건</td><td>이미 준비된 실행 사본의 교체</td></tr><tr><td>준비</td><td>이번 기판의 합성 조건·좌표·실행 대상</td><td>실제 가공과 검사 완료</td></tr></tbody></table>
<h2>Recipe와 장비 설정이 합쳐지는 곳</h2><p>Recipe에는 제품 배치, Cell·패턴과 Head별 가공 조건이 들어간다. 준비할 때는 Recipe 사본에 장비 설정과 적용 가능한 보정을 반영해 실제 가공용 조건을 만든다. 따라서 Recipe 파일의 한 항목만 읽어 최종 좌표나 장치 적용값이라고 단정하지 않는다.</p><p>AK Margin처럼 장비 기준에 속한 값은 Setting의 관리값을 사용한다. 같은 이름의 값이 여러 자료에 보일 때는 값의 소유 위치와 합성 우선순위를 확인한다. 실적 매수나 요청·완료 상태처럼 운전 중 변하는 값도 제품 목표 조건과 분리해 읽는다.</p>
<h2>PPID와 전체 조건 전환의 경계</h2><p>PPID는 상위 요청이 어떤 공정 조건을 가리키는지 식별하는 값이고, 로컬 Recipe는 장비가 사용할 조건 자료다. PPID 수신, 로컬 대상 결정, 각 장치 조건 전달, 적용 결과 확인은 구분해 추적한다.</p><p>로컬 Recipe 선택이 성공했다고 상위 매칭과 모든 장치 전환까지 끝난 것으로 보고하지 않는다. 요청한 PPID·선택 Recipe·준비한 조건이 일치하는지와 실제 완료가 확인된 범위를 함께 본다.</p><p><ac:image ac:width="1200" ac:alt="상위 요청과 로컬 선택·준비·장치 적용 확인의 경계를 나눈다."><ri:attachment ri:filename="new_ppid-boundary.png"/></ac:image></p><p><em>왼쪽 PPID 요청과 로컬 Recipe 선택은 다른 단계다. 회색 점선은 상위 수신·매칭과 연동 확인의 경계이며 로컬 선택 성공만으로 전체 전환 완료를 뜻하지 않는다.</em></p>
<h2>값이 적용되지 않을 때</h2><p>변경값을 비교할 때는 '화면에서 수정했는가 → 저장됐는가 → 운전 대상으로 선택됐는가 → 다시 준비했는가 → 장치 적용이 확인됐는가'의 경계를 따라간다. 단순히 화면을 새로 고치는 일과 실행 사본을 다시 만드는 일은 다르다. 준비 이후 Review 보정본이 바뀐 경우에는 기존 사본으로 진행하지 않고 재준비 요구를 확인한다.</p><h2>함께 읽기</h2><p><ac:link><ri:page ri:content-title="03. 프로그램 구조와 실행 데이터"/><ac:plain-text-link-body><![CDATA[03. 프로그램 구조와 실행 데이터]]></ac:plain-text-link-body></ac:link> · <ac:link><ri:page ri:content-title="04. 실행 준비와 설정 관리"/><ac:plain-text-link-body><![CDATA[04. 실행 준비와 설정 관리]]></ac:plain-text-link-body></ac:link> · <ac:link><ri:page ri:content-title="06. 좌표 변환과 Head 분담"/><ac:plain-text-link-body><![CDATA[06. 좌표 변환과 Head 분담]]></ac:plain-text-link-body></ac:link> · <ac:link><ri:page ri:content-title="16. 데이터 관리와 변경 반영"/><ac:plain-text-link-body><![CDATA[16. 데이터 관리와 변경 반영]]></ac:plain-text-link-body></ac:link></p>
