반영한 촬영 구조
- 최초 Align Key 4개를 서로 다른 카메라 4대가 측정합니다.
- Stage가 Alignment를 완료한 뒤, 그중 2대가 Y 이동 중 Distortion Key를 측정합니다.
- 중앙 주변의 Key 위치는 Model별 설계치로 저장합니다.
- Distortion 6/4/2개를 지원하고, 실제로 4개 또는 2개만 있는 레시피도 저장할 수 있습니다.
- 6개는 카메라당 3점의 2차 Lagrange, 4개는 2점의 선형, 2개는 1점 관측입니다.
- 카메라별 관측 Y 구간만 보간하며 외삽·카메라 간 전역 벡터 합성을 하지 않습니다.
- Align 전 pixel을 Align 후 Distortion pixel에서 빼지 않습니다.
- 예제는 Y 단독 스캔에 맞춰 같은 카메라의 Align/Distortion 설계 X를 맞췄습니다.
  실제 배치는 Key별 X 위치와 카메라 FOV/기구 조건으로 촬영 가능 여부를 확인해야 합니다.

실측 분석의 조건
설계치만으로 개별 ROI의 기대 pixel·배율·회전·Stage 이동 오차는 결정되지 않습니다.
같은 Key/Camera/ROI/광학 조건/ScanPose/정렬 단계의 승인 기준 pixel이 필요합니다.
기준이 없으면 원측정 확인과 보정 후보를 보류합니다.
분석값은 카메라별 상대 pixel이며 mm/um 또는 Stage 가공 명령이 아닙니다.
기판 설계 mm는 배치·Y 순서·위치 정규화에만 사용합니다.
실제 장비에 적용하려면 카메라–Stage/가공계 대응, 축 부호, 공정 정밀도 검증이 필요합니다.
서로 다른 카메라의 같은 1 pixel이 같은 물리 변위라고 가정하지 않습니다.
Stage 반복 오차, 렌즈 계통오차, Z 휨과 기판 변형은 이 관측만으로 완전히 분리되지 않습니다.

Auto Tune
- Model/레시피 버전/설계·기준/촬영 조건/Key 수/합성·실측 출처를 분리합니다.
- 같은 기판·같은 척킹/정렬 조건의 독립 재촬영 pixel을 검증 목표로 사용합니다.
- 과거의 앞쪽 기판에서 후보 선정, 뒤쪽 과거 기판에서 재확인 후 현재 기판에 적용합니다.
- 현재/미래 기판과 가상 내부 정답을 후보 선택에 사용하지 않습니다.
- 같은 Glass ID 중복을 독립 학습 자료로 늘리지 않습니다.
- 재촬영이 없는 실측은 추세를 저장하며 설정 변경을 보류합니다.
- 카메라별로 보정 반영량·곡률 정규화를 선택합니다.
- 카메라당 1/2점이면 곡률 SVD는 비활성이고 반영량만 검토합니다.
- 초기에는 보수적인 정책으로 시작합니다. 12개 이상, 최근 최대 36개, 6개 추가마다 검토합니다.
- 개선·변동 기준은 시연용입니다. 전역 최적값, 정식 통계 신뢰도, 생산 승인 기준이 아닙니다.
- 단일 Key의 재촬영 일치도는 Key 사이의 복원·실제 레이저 가공 결과를 보증하지 않습니다.

내부 목적함수(숫자 슬라이더는 UI에서 숨김)
카메라별 c = argmin ||c-d||^2 + lambda^2 ||Lbar c||^2.
Lbar는 비균일 3점의 이산 2차 미분을 최대 특잇값으로 정규화한 행렬입니다.
SVD 해: c=V diag(1/(1+lambda^2 sigma_i^2)) V^T d.
Lagrange로 c를 잇고 정책의 반영량을 적용합니다.
원측정 척킹 판정은 별개이며, 시연은 축별 8px 예시 기준을 사용합니다.
이 8px를 실제 공정 공차로 승인하거나 Auto Tune으로 변경하지 않습니다.

시연
첫 실행은 가상 기판 12장의 이력과 다음 기판 분석으로 시작합니다.
한 Lot 버튼은 12장을 추가합니다. 각 상황의 가상 이력은 별도이며 최대 120장입니다.
잡음 증가/안정, 방향 변화, 국부 변형, Key 사이 숨은 변형, 촬영 조건 변경,
척킹 재확인, Key 실패 사례를 선택할 수 있습니다.
재촬영 잡음은 가상에서 독립입니다. 실제 상관 잡음·드리프트에서는 성능이 달라집니다.
보정 후 가상 정답은 시각화/사후 평가 전용이며 Auto Tune에 전달하지 않습니다.
실측에는 정답 기반 전후 비교와 방법별 정밀도 순위를 생성하지 않습니다.
