A3 가공SW 시나리오·평가 체크리스트 미팅 반영본
작성일: 2026-10-22

첨부 Excel을 기준으로 복사본에 회의록 내용을 반영했습니다.
기존 9개 탭 순서와 518개 도형의 위치·크기를 유지하고 관련 37개 도형 문구를 수정했습니다.
각 시나리오 하단에 미팅 보완 설명13개를 추가했습니다.
Default Offset, 보호윈도 관리 시나리오 탭2개를 추가해 총11개 탭입니다.

주요 반영
- DoReady 첫 Review X 선행 준비, AUX 초기화→대기→MOF 결합→대기.
- Script 생성/적재/Task RUN·대기/실제 가공을 구분하고 정확한 실행 호출 시점은 확인 사항으로 표시.
- Ready 도착·정지 후 PEG 기록 원칙 유지. IOF 요청·Stage 읽기/활성화 계약은 별도 확인.
- 1002 수신 ACK, Grab 개수, Mark Find 판정을 구분.
- Full Review는 기본1003 대기. 즉시 재측정 미사용 병행은 명시적 개수 확인 계약 확보 후 검토.
- 1점/3점 잔여 표현을1줄/3줄로 수정하고 셀별 X 포인트 수와 구분.
- 0선 기존 ACK 후 다음 X/1003 병행 유지, 실패 후 한 줄 추가 검사·AF·완료 정책 보완.
- Power 안정 구간/신규 샘플/기울기 보정, 보호윈도 교체·매수·Reset·TPM 재측정 보완.

평가 탭
- 시나리오평가 체크리스트: 기존36 + 추가24 =60항목.
- Full Review 평가: 기존20 + 추가5 =25항목.
- 기존 평가 결과/증거 입력은 유지했고 신규 항목은 미평가입니다.
- 드롭다운·조건부서식을 확장했으며 틀고정은 없습니다.
- 미결 조건은 실제 계약·설정 확정 후 평가합니다. 예시 수치·새 주소를 임의 확정하지 않았습니다.

검증
- 3개 분야 독립 내용 검토, 저장본 재읽기, 구조56검사, 기존 객체 위치/크기·다른 객체·입력 보존 확인.
- 평가표3범위와9시나리오의 OOXML 좌표 기반 객체 배치 미리보기를 확인했습니다.
- Excel 데스크톱 앱과 실제 PLC/Vision/축/가공 동작은 검증하지 않았습니다.
- 기존 생산 코드·이전 공유본은 변경하지 않았습니다.
