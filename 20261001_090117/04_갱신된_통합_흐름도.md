# 갱신된 통합 흐름도

## 1. 전체 데이터 흐름

```mermaid
flowchart TB
    subgraph Definition[정의 파일]
        JHMI[JHMI_RCP.csv<br/>항목 형식·범위·기본값]
        SET[Setting.csv<br/>Head·축·Flip·장비 옵션]
        IFACE[JHMI_INTERFACE.csv<br/>Vision 등 통신/Simulation]
    end

    subgraph Recipe[Recipe 저장]
        RCP[Config/RECIPE/test0929.csv]
        REVSET[Config/ReviewSetting/test0929/*.review]
    end

    subgraph Memory[메모리 계획]
        DICT[Recipe Dictionary]
        SHOT[ST_SHOT_COORDINATE_PLAN]
        MASK[CRecipeShotMaskingPlan]
        PROC[ST_PROCESS_MODEL]
        RPLAN[ST_REVIEW_PLAN]
    end

    subgraph Process[가공]
        SCRIPT[H01 Automation1 Script]
        SCANNER[Scanner 이동]
        LASER[Laser 발진/미발진]
    end

    subgraph Review[Review]
        RULE[Review Rule 대상 선정]
        MOVE[Stage Y / Vision X 이동]
        VISION[Vision 측정]
        PRODUCT[Product Checkpoint]
        RESULT[ReviewResult CSV]
    end

    subgraph Correction[보정]
        LOAD[Result Load]
        AXIS[Vision축 → Scanner축]
        PROJECT[Rule별 복사/보간]
        OFFSET[Shot REVIEW_OFFSET_X/Y]
    end

    JHMI --> RCP
    SET --> DICT
    IFACE --> VISION
    RCP --> DICT
    DICT --> SHOT
    SHOT --> MASK
    MASK --> PROC
    PROC --> SCRIPT
    SCRIPT --> SCANNER
    SCRIPT --> LASER

    RCP --> REVSET
    REVSET --> RULE
    PROC --> RPLAN
    MASK --> RPLAN
    RULE --> RPLAN
    RPLAN --> MOVE
    MOVE --> VISION
    VISION --> PRODUCT
    VISION --> RESULT

    RESULT --> LOAD
    LOAD --> AXIS
    AXIS --> PROJECT
    PROJECT --> OFFSET
    OFFSET --> RCP

    classDef danger fill:#ffd7d7,stroke:#c00000,stroke-width:2px;

```

빨간 `Stage Y / Vision X 이동` 상자는 현재 실제 장비 전송이 빠진 구간입니다.

## 2. 좌표가 바뀌는 단계

```mermaid
flowchart LR
    A[Cell 기준점<br/>0~800, 0~800] --> B[Model 내부 Group<br/>2.7 mm 간격]
    B --> C[Beam Offset<br/>0.675 mm 간격]
    C --> D[Recipe/Review Offset]
    D --> E[Head 기준점·간격]
    E --> F[Scan Start Delay<br/>Y 500]
    F --> G[Scanner Flip<br/>Y 반전]
    G --> H[최종 H01 좌표<br/>-28.4875,-501.0125 ...]
```

### 초보자용 비유

- Cell 기준점: 종이 위에 큰 칸을 놓는 위치
- Model Group: 큰 칸 안의 작은 격자
- Beam Offset: 한 격자 안에서 여러 레이저 점이 떨어지는 위치
- Head 기준점: 어느 스캐너가 맡을지 정하는 기준
- Scan Delay/Flip: 실제 장비 좌표계에 맞춰 원점과 방향을 바꾸는 과정

## 3. 한 Shot의 가공 판단

```mermaid
flowchart TD
    A[Shot 후보] --> B{사용 Head인가?}
    B -- 아니오 --> X[이 Head 스크립트에서 제외]
    B -- 예 --> C{CHESS 제외인가?}
    C -- 예 --> Y[좌표 줄 자체를 만들지 않음]
    C -- 아니오 --> D[좌표 이동 생성]
    D --> E{Hole 또는 Edge Mask인가?}
    E -- 예 --> Z[이동만 하고 Laser OFF]
    E -- 아니오 --> L[이동 후 Laser ON/OFF]
```

가공 스크립트와 Review는 같은 Masking 판정을 사용하도록 바뀌었습니다. 따라서 Review가 레이저를 쏘지 않은 Shot을 측정 대상으로 잡는 문제를 줄입니다.

## 5. P2P 실행 상태 흐름

```mermaid
stateDiagram-v2
    [*] --> PlanReady: Recipe + Review Setting
    PlanReady --> Running: Start
    Running --> MoveStage: 다음 Shot
    MoveStage --> MoveVision
    MoveVision --> Measure
    Measure --> SaveProgress: Error/Judge 수신
    SaveProgress --> MoveStage: 남은 Shot 있음
    SaveProgress --> SaveResult: 모두 완료
    SaveResult --> Completed
    Running --> Failed: 통신/검증 오류
    Failed --> Running: 저장된 Checkpoint와 Plan 일치 시 재개
```

현재 코드에서는 `MoveStage`와 `MoveVision` 상태가 실제 이동 완료를 보증하지 않습니다. 단순 지연 후 다음 단계로 넘어갈 수 있습니다.

## 6. IOF 실행 흐름과 현재 한계

```mermaid
sequenceDiagram
    participant RM as Review Manager
    participant Move as Stage/Camera
    participant V as Vision PC

    RM->>Move: 시작 위치 이동
    RM->>V: FLYING_READY + Line 검색 목록
    V-->>RM: Ready
    RM->>Move: 연속 이동 시작
    RM->>V: FLYING_MOVE_DONE
    RM->>V: MARK_FIND_LINE
    V-->>RM: Line 측정 결과
```

Vision 프로토콜은 구현되어 있지만 Move 쪽 MELSEC 전송·Handshake가 미연결입니다. 그러므로 IOF도 실장비 완료 상태가 아닙니다.

## 7. Review 결과에서 다음 가공까지

```mermaid
flowchart LR
    A[측정한 일부 Shot] --> B[ReviewResult CSV<br/>규칙 메타데이터 포함]
    B --> C[현재 Recipe Plan 재생성]
    C --> D[ShotKey·Head 대조]
    D --> E[축 Flip 변환]
    E --> F[전체 Shot으로 투영]
    F --> G[Apply Preview]
    G --> H[Recipe 저장]
    H --> I[다음 가공 Process Model]
```

이 왕복에서 가장 중요한 연결 키는 `RecipeId + ShotKey + HeadNo`입니다. 현재는 Recipe 내용 자체의 Hash가 없으므로 같은 ID의 Recipe 내용이 바뀌면 추가 확인이 필요합니다.

## 8. 저장 파일별 책임

| 파일/폴더 | 읽는 주체 | 쓰는 주체 | 역할 |
|---|---|---|---|
| `Config/JHMI_RCP.csv` | Recipe UI/검증 | 개발·설정 배포 | 필드 사전 |
| `Config/RECIPE/*.csv` | Recipe/Process/Review/Correction | Recipe UI/Correction | 실제 가공값과 Offset |
| `Config/ReviewSetting/<id>/*.review` | Review 화면 | Review 화면 | 표본 선택 규칙 |
| Product 파일 | 공정/Review | Product Manager | Glass별 진행·재개 상태 |
| `Data/ReviewResult/.../*.csv` | Correction | Review Result File | 실측 오차와 규칙 메타데이터 |
| Automation1 Script | Scanner 실행기 | Script File | 실제 이동·Laser 명령 |
