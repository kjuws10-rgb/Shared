A3 DoReady / Process 동작 시나리오와 통합 평가 체크리스트
2026-10-17

시트 구성
1. DoReady 시나리오: 완료된 DoReady 내용과 41개 객체 유지.
2. Process 시나리오: 같은 양식의 신규 시나리오와 54개 편집 가능한 객체.
3. 평가 체크리스트: 기존 DoReady 24항목 아래 Process 36항목 누적.

모든 시트에 틀고정·분할이 없습니다.
흐름도는 그림이 아닌 Excel 텍스트 도형과 선/화살표입니다.
객체를 선택해 문구·위치·크기를 수정할 수 있습니다.
선택하기 어려우면 Excel의 선택 창에서 이름으로 선택합니다.
행·열 크기를 바꿔도 도식의 절대 위치·크기는 유지됩니다.

Process는 주가공 Y/Script/MOF와 0선방어를 별도로 진행합니다.
Review X 데이터 기록 → 이동 Request → 도착·정착 → 촬영 → 결과 반영을 포함합니다.
일반 측정 NG·응답 지연·누락이 발생해도 현재 가공 시작~끝은 계속 진행합니다.
가공 완료와 Review 완료를 따로 확인하고 늦은 결과는 원래 Glass에 반영합니다.
비상정지·기계/레이저 안전 인터록은 기존 정지 기준을 유지합니다.

Process 상세 1~8단계는 101행, 0선방어 상세는 112행부터 이어집니다.
평가 탭의 Process 블록은 52행부터이며 C25~C60입니다.
총 60평가항목과 16기록행의 76판정칸은 전부 미평가입니다.
새 측정 기록 8행은 빈 입력칸이며 실제 레시피의 측정 N을 8로 고정하지 않습니다.

문서·내용·원본 보존·셀 표시·native 객체 구조를 검토했습니다.
실제 주소/형식/단위·패킷 길이·첫 X 준비 권한·완료/후속 조건은 본문 확인 항목을 참조합니다.
실장비 통신·축·레이저 평가와 데스크톱 Excel 객체 편집 시험은 별도입니다.
