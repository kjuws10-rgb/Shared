# 0선방어 Flying Review — 가공·리뷰 중첩 수정본

`FlyingReview_8Head_Simulator.html`을 브라우저에서 엽니다. 두 HTML은 외부 라이브러리 없이 실행되며 같은 폴더에 두면 서로 이동합니다. `0선방어_검토자료.pptx`는 편집 가능한 도식·텍스트로 구성한 3장 자료입니다.

정방향(+StageY)으로 가공대기 위치에 도착한 뒤 역방향(-StageY) 등속 MOF에서 Scanner를 먼저 만나고 공통1467mm 뒤 Review를 만납니다. 전체 가공완료를 기다리는 직렬 모델을 제거했습니다. 각 점의 가공 완료 후 촬영하며 다른 점의 가공과 리뷰가 병행될 수 있습니다. ProcessDone과 실제 Frame·Vision 완료인 ReviewDone은 독립 신호입니다. 가공이 먼저 끝나도 마지막 촬영±Jitter까지 등속을 유지합니다.

입력은 노출시간, 허용 이동blur(pixel), X·Y속도, X·Y가속도·감속도8개입니다. 측정 모드는 기판당2개 또는4개 Scanner, Head당1점입니다. 세부 좌표와 blur/X도식은 접힌 영역에 배치했습니다.

**중첩 기준:** 기판1500mm 전체의 물리 통과창, 레시피의 실제 Shot 좌표창, 선정 리뷰의 첫~마지막 노출 작업창을 구분합니다. 현재 가져온 test0929의 유효가공 범위는843.2mm이므로 물리적 통과창 중첩이 실제 출사 중첩을 보장하지 않습니다. 실제 연속가공 범위·ProcessDone 시각이 다르면 해당 좌표·신호로 재산정해야 합니다. 표의 리뷰 작업창에는 노출 사이 X이동·정착·대기가 포함됩니다. 실제 Frame/Vision 완료 시각은 계산하지 않습니다.

가공 종료 전 리뷰 종료와 가공 종료 후 리뷰 잔여의 두 관계를 가이드/PPT에 설명했습니다. 고정 좌표에서 둘 다 Y등속이면 속도 변경은 시간의 크기를 바꾸며 종료 순서를 바꾸지 않습니다. 현재 고정점은 모두 마지막 촬영이 MOF 주행창보다 늦습니다. 운전 중 가공이 계속될 때 이미 가공된 점의 리뷰를 허용하는 계산을 별도 fixture로 검증했습니다. 해당 fixture는 현재 실제 레시피 결과로 표시하지 않습니다.

대표점: H01C01, H02C11, H03C21, H04C32, H05C05, H06C15, H07C25, H08C36. 전체8개 Cell 모두 다릅니다. 기존 test0929 엔진의 유효 Shot·Mask·Head 소유권을 통과한 BranchB07을 사용합니다. 요구2/4점의 시간조건이 부족하면 축소하지 않고 불가로 표시합니다. 장수는 고정8점1회 순환이며 전체 가공점 전수검사 장수가 아닙니다.

카메라: Basler a2a2600-20gcBAS 2.5µm pixel, 기본2600×2128, Color·Global Shutter, 기본18.5fps, 최소노출2µs. 렌즈: Mitutoyo378-810-3 SL20x, NA0.28, WD30.5mm, 분해능약1µm@550nm. 총배율20x는200mm 튜브렌즈·1x Relay 전제, 물체면0.125µm/px는 sampling 간격입니다. 노출2µs·허용1px에서는 Y≤62.5mm/s라는 blur 조건을 만족해도 현재 왕복Tact는 초과합니다.

설계 가정: 투입/종료q=−1584.5mm, 가공대기q=1982.5mm, 왕복각3567mm/Stroke3960mm. 정방향에도 같은 Y속도·가감속 입력을 적용합니다. 기타60초는 명시적으로 계산한 왕복Y이동을 제외합니다. 가공15초/리뷰15초를 다시 직렬로 더하지 않습니다. 정착50ms, Guard20ms, Trigger지연50µs, Jitter±5µs, 해당점출사완료여유1ms, 영상여유1초, ReviewX Stroke1025mm. 공통1467mm를 적용하고 기존짝수+380mm는 제거했습니다. 실제 장비·투입좌표·지연·정착 확정 사양은 아닙니다. Trigger는 노출중심을 선행 보정합니다. 자동 Offset 적용은 포함하지 않습니다.

검증: 엔지니어링21개, HTML DOM10개 통과. 이동시간 역함수, 2/4점, Cell 중복, blur/노출/X준비/등속/왕복Tact 실패, 두 완료순서와 경계, 가공·리뷰 중첩허용, 해당점가공전촬영금지, 왕복애니메이션의 정방향무촬영을 확인했습니다. HTML 실제SVG를 PNG로 렌더링하고 PPT를 PDF로 변환해3장·배치·한글·슬라이드 경계를 확인했습니다. HTML 전체 브라우저 픽셀·모바일 터치 검증은 실행환경 Chromium socket 제한으로 완료하지 못했습니다. 실제 영상PASS·Follow Error·조명·SNR·Scanner/Laser서비스시간은 별도 검증사항입니다.

재생성: `node build.js`, `python make_ppt.py`. 수치검증: `node tests/engine.test.js`. DOM검증: linkedom0.18.12·sharp 필요. Browser 검증 스크립트는 실행 허용 환경용이며 이번 환경에서는 통과로 집계하지 않습니다. `references`는 소유권/좌표 검증의 기존 소스, 해당 엔진의 예전 직렬Tact 결과를 현 계산에 사용하지 않습니다.
