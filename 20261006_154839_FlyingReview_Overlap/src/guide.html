가공이 먼저 끝나도 남은 촬영이 있으면 Y 등속 이동을 계속합니다.

1. 같은 점은 언제 Review에 도착할까?

도착 지연 = 1467 mm ÷ Y속도

Y100 mm/s → 같은 점은 14.67초 뒤 도착

실제 노출 중심은 가공 Branch의 위치로 정합니다. 각 점은 자신의 가공 완료 후 촬영합니다. 전체 ProcessDone은 촬영 시작 조건이 아닙니다.

2. 기판의 통과창은 얼마나 겹칠까?

통과창 중첩 = max(0, 기판길이 − 1467) ÷ Y속도

1500 − 1467 = 33 mm
Y100 → 0.33초 중첩

이 값은 기판 전체의 Scanner·Review 통과창입니다. 실제 Laser ON 중첩은 유효 가공 좌표와 선정 리뷰점으로 다시 확인합니다.

같은 점의 14.67초 이동시간을 전체 공정 뒤에 더하지 않습니다. 가공과 리뷰의 진행시간은 공통 Y 시간축에서 겹쳐 계산합니다.

3. 가공 종료와 리뷰 종료, 어느 쪽이 먼저인가?

가공 후 남은 촬영시간 = max(0, 리뷰 마지막 노출 종료 − 가공 종료)

선정점 위치와 실제 가공 종료 위치가 선후 관계를 결정합니다. 두 구간 모두 등속이고 좌표가 고정되면 속도 변경은 시간 크기를 바꾸며, 종료 순서를 바꾸지는 않습니다. Frame 수신·Vision 판정 완료는 노출 종료와 별도로 확인합니다.

4. 현재 고정 조건에서는?

기판당 측정기판 / 측정 Head첫~마지막 노출(s)MOF 주행창 종료 후 남은 촬영(s)

시간 0=역방향 시작. 2개 모드: 4기판·10분 / 4개 모드: 2기판·5분(계획150초/기판). 모든 Head의 대표점은 서로 다른 Cell: 1, 11, 21, 32, 5, 15, 25, 36.

blur · X 선도착 · 8개 입력의 의미

입력 8개: 노출(µs), 허용blur(px), X속도, Y속도, X가속·감속, Y가속·감속.

물체면 pixel = 2.5 µm ÷ 20 = 0.125 µm/px
blur(px) = Y속도(mm/s) × 노출(µs) ÷ 125

Y100 × 노출2µs → 1.6px = 0.2µm. 최소 노출2µs에서 1px 요구는 Y≤62.5mm/s입니다. 이는 blur 조건이며, 느려진 왕복 이동의 Tact도 함께 확인해야 합니다. Global Shutter도 이동 blur는 발생합니다. X는 노출 중 정지합니다.

다음 점까지 Δt = ΔY ÷ Y속도
Δt ≥ max(X이동+정착+여유, 카메라 주기)

X 이동은 정지→이동→정지의 사다리꼴/삼각형 운동. D=|ΔX|, vPeak=min(vX,√(2D/(1/aX+1/dX))), 이동시간=vPeak/aX+max(0,D−vPeak²/2aX−vPeak²/2dX)/vPeak+vPeak/dX. 카메라 기본주기1/18.5=54.054ms, 정착50ms, Guard20ms, 지연50µs, Jitter±5µs, 노출도 여유에 포함합니다.

노출 중심 보정: tCommand=tCross−50µs−노출/2. 허용blur와 X도착시간을 각각 통과해야 하며, 요구한 2/4점을 자동 축소하지 않습니다.
