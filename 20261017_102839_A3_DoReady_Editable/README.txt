A3 DoReady · 수정 가능한 Stage / Process 시퀀스
2026-10-17

"DoReady 시나리오" 탭의 기존 이미지 흐름도를 제거하고,
Stage와 Process의 두 세로축·노란 동작상자·신호 화살표로 교체했습니다.
그림이 아니라 텍스트/도형 32개와 선/화살표 9개, 총 41개의 Excel 객체입니다.
이 파일 안에는 이미지 객체와 이미지 파일이 없습니다.

수정 방법
- 문구 수정: 해당 상자를 선택하고 더블클릭하거나 우클릭해 텍스트를 편집합니다.
- 위치/크기 수정: 객체를 선택한 뒤 이동하거나 크기 조절점을 드래그합니다.
- 화살표 수정: 선을 선택해 끝점·방향·선 모양을 편집합니다.
- 선택이 어려우면 Excel의 선택 창에서 이름으로 객체를 선택합니다.
- 하단 상세 표와 도형 문구는 각각 직접 수정합니다.

내용
1~4: Stage/Prc DoReady ABLE·START 확인과 응답
5: Stage Ready 이동과 Process Script·0선방어·MOF/Melsec 데이터 준비 병행
6: Process 데이터·Script 준비 완료 시 Prc COMPLETE ON (Stage 도착과 독립)
7: Prc COMPLETE 확인 AND 실제 Ready 도착 시 Stg COMPLETE ON
8: Stg COMPLETE 후 Zero Set·A1/Task 실행·8개 Task 실제 RUN·Laser/Precheck 전체 준비
다음 Process: 8단계 전체 완료 AND Stg Process ABLE 확인 후 처리
ABLE 선도착 시 8단계 완료까지 보류하며, 준비가 먼저 끝나면 ABLE을 기다립니다.

Ready는 "−120 mm 가기 전 위치"이며 실제 설정 좌표는 별도 확인 대상입니다.
첨부 예시의 All OFF를 기존 7·8단계로 대체하지 않았습니다.
OFF 복귀 순서·유지 조건·실제 시간 간격·미정 주소·설비 내부 세부 순서는 별도 확인합니다.

기존 상세 1~8단계 표는 71행부터 있습니다.
"평가 체크리스트"의 24개 평가항목·8개 Task 기록·32개 미평가 판정을 보존했습니다.
파일 구조/객체 텍스트/원본 보존 대조와 재import 렌더링을 검증했습니다.
작성 환경에 Excel 앱이 없어 실제 Excel 앱에서의 편집 동작과 실장비 시험은 미실시입니다.

ZIP 구성: 편집형 Excel, 이 README 2개.
기존 이미지 버전은 과거 날짜 폴더에 보존되어 있습니다.
