# A3 LD 완료 항목 고객 설명 자료

[고객 설명용 엑셀 열기](A3_LD_완료항목상세탭_고객사설명용_20261014.xlsx)

고객사에 기능의 목적, 화면 위치, 프로그램 동작을 설명하는 자료입니다. 기존 체크시트와 113개 상세 탭을 유지하며, 발표자가 본문 순서대로 설명할 수 있도록 문장을 정리했습니다.

## 발표 순서

1. `확인할내용`에서 해당 기능이 무엇을 확인하는지 한 문장으로 설명합니다.
2. `UI 부분화면`의 화살표로 조작 위치나 표시 영역을 안내합니다. 영어 화면 용어는 바로 옆의 쉬운 설명과 연결합니다.
3. `프로그램 동작`의 순서를 설명한 뒤, 현재 적용 범위와 추가 확인이 필요한 부분을 구분합니다.

화면에 값이 표시되는 것, 명령이 전달되는 것, 실제 장치가 이동·측정·가공을 완료하는 것은 서로 다른 단계입니다. 시뮬레이션 캡처의 값은 실제 측정값이나 현장 합격 결과가 아닙니다.

## 반영 내용

- 모든 상세 탭의 제목을 `1. 확인할내용`, `2. UI 부분화면`, `3. 프로그램 동작`으로 통일했습니다.
- 기존 4·5번 구역과 `코드 분석 판정` 줄의 내용을 제거했습니다. 이전에 제거한 6번 이하 구역도 복원하지 않았습니다.
- 전문 용어·내부 함수명 중심의 설명을 기능 목적과 동작 순서 중심으로 바꾸었습니다. 코드 본문은 넣지 않았습니다.
- 작은 캡처 34개를 확대하고 화살표도 같은 비율로 조정했습니다. 레시피 관련 4개 항목은 화살표가 이름을 가리지 않도록 위치를 보완했습니다.
- 직접 해당 기능을 보여주지 않는 캡처는 참고 화면으로 구분했습니다. 상위 통신, Stage 이동, 자동 파워 보정 등 남은 연동 범위를 명시했습니다.
- 원본 체크시트, 탭 이름·순서, 색상·글꼴·열 너비·남은 병합·연결을 유지했습니다. 상세 탭의 행 높이와 여백은 가독성에 필요한 범위만 조정했습니다.

## 분석 기준과 검증

기능 설명은 기존 분석의 [A3 원본 Commit 0c501c1](https://github.com/kjuws10-rgb/A3_LD_Process_SW_IPS/commit/0c501c104dec1cebab87bd909de29b1b1395a8b4)을 기준으로 합니다. 이번 산출물은 고객 설명용 편집본이며, 신규 개발 완료 판정이나 실제 장비 시험 결과를 추가한 자료가 아닙니다. A3 원본 저장소는 수정하지 않았습니다.

총 114개 탭, 내부 연결 450개, 파일 구성 연결 347개를 확인했습니다. 원본 캡처 113개와 화살표 113개를 보존했고, 15개 대표 항목의 렌더링에서 설명 문장과 이미지 배치를 확인했습니다. 원본 체크시트와 스타일 정의는 동일합니다. 원본 파일은 별도로 보존했습니다.

파일 무결성과 보존 검사 결과는 [검증 기록](검증기록.json)에 있습니다.
