A3 LD · Process SW 개발 — 페이지별 붙여넣기 묶음

[시작]
index.html을 열어 페이지를 선택합니다. 본문을 검토하고 '소스 전체 선택'을 누른 뒤 Ctrl+C로 복사합니다.
또는 pages 폴더의 해당 .storage.xhtml.txt를 메모장에서 열어 전체 선택·복사합니다.
Confluence의 각 페이지 소스 편집기에 붙여넣습니다. 일반 본문 입력창과 구별하세요.

[구성]
상위 페이지1 + 주제 페이지16 + 과거 부록3 = 총20개 독립 소스.
00_페이지생성_순서.txt에 제목·부모·첨부 파일을 정리했습니다.
01~16은 Process SW 개발 아래, 14-1~14-3은 14 아래에 생성합니다.
같은 Space의 정확한 제목을 링크하므로 제목 변경 시 링크도 점검합니다.
attachments의 PNG는 지정된 페이지에 업로드합니다. SVG는 그림 수정용 원본입니다.
그림이 없어도 본문의 설명·절차·표를 읽을 수 있습니다.

[기준과 한계]
Main 구현 기준 Ver11.17.0(UI 프로젝트 Version 2026.11.13.0), 사용자 제공 과거표 2026-08-09.
과거51요구/137WBS/36일정은 현재 진행상태를 뜻하지 않습니다.
정식 설비 Build·장비운전·Laser 출력·고객 Acceptance 및 사내 Confluence 저장은 미실행입니다.
이번 수정본은 XML·원문·링크·파일 대조로 검증했으며 실제 사내 렌더링은 미검증입니다.
사내 페이지 저장과 생산코드 변경은 수행하지 않았습니다.

[본문 코드]
외부 소스를 열도록 안내하는 코드 참조 표를 제거하고 실제 구현의 핵심 코드를 본문에 직접 넣었습니다.
13개 기술 페이지의 코드 발췌 26개에는 입력·분기·결과와 적용 범위 설명을 함께 넣었습니다.
Confluence code 매크로의 언어는 csharp입니다. 코드 발췌는 독립 실행용 전체 프로그램이 아닙니다.
sources.json은 페이지별 본문 코드 목록, manifest.json은 소스파일 SHA와 첨부 배치입니다.
원본 저장소·고객 원첨부·운영 측정 CSV·세션 원문·인증정보는 이 배포ZIP에 넣지 않습니다.
