## 이번 변경에서 눈여겨볼 점

| 변화 | 현장에서 의미하는 점 |
| --- | --- |
| Review Data 파일 트리·Cell/Shot 맵·적용 미리보기 | 저장 결과를 다시 보고 현재값+추가값=최종값을 비교합니다. 맵 클릭이 실이동·재측정을 수행하지는 않습니다. |
| 최신 Review Offset Rollback | 마지막 보정파일을 보관하고 직전 파일로 돌아갑니다. 이미 준비한 가공은 DoReady를 다시 해야 합니다. |
| Review/Align 보정율 기본100% | 저장 원본은 유지하고 다음 가공 기여만 조정합니다. 0%도 저장값 삭제가 아닙니다. |
| Masking을 Cell 설계 위치로 고정 | 보정값 변경 때문에 제외 Shot 목록이 바뀌는 문제가 개선됐습니다. Shift된 실제 위험영역의 물리 우회 기능은 별도입니다. |
| Default 십자는 중심1회 측정 | DOE16점 피팅과 분리합니다. DOE 없는 Zero Order 생산 모드 전체를 구현한 뜻은 아닙니다. |
| 포함 Setting의 분해능·Flip 변경 | 0.0025→1 mm/pixel, Y Flip ON→OFF입니다. 동일한 수신 단위라면 환산 길이400배·Y방향 변화이므로 실제 단위를 먼저 맞춰야 합니다. |

정상 AUTO 결과도 새 파일 화면에서 다시 Apply할 수 있는 구조와 손상 CSV의 무효 오차가0으로 바뀌는 경로를 우선 보완 대상으로 제안합니다. 이 보고서는 분석이며 생산 코드 패치·실제 장비 운전·현장 성능 합격 판정은 수행하지 않았습니다. 다음 예약 비교 기준은 이 README의 **원본 최신 Commit a116220…**입니다.
