모델 1~5 · Cell 내부 Masking

기준점은 각 Cell의 첫 DOE 가공 중심입니다. X는 오른쪽, Y는 아래쪽이 양수이며 모든 거리는 mm입니다. 첫 샷이 Off여도 원점은 같습니다.

Edge X/Y는 해당 모서리 Pixel에서 Cell 안쪽으로 잰 0 이상 길이입니다. 상좌는 오른쪽·아래쪽, 상우는 왼쪽·아래쪽, 하좌는 오른쪽·위쪽, 하우는 왼쪽·위쪽으로 적용합니다. 대칭이면 네 모서리 모두 (2, 2) mm로 입력하세요. 첫–마지막 Pixel 거리는 (해상도−1)×Pixel size이며 우측·하단 좌표는 자동 계산합니다. 모서리 장변 사각형은 각 모서리에서 max(X,Y) 크기의 금지박스로 적용합니다. 전체 변의 띠는 별도 선택합니다.

모델은 형상만 선택합니다. 해당 모델을 사용하는 모든 Cell에 각자의 원점으로 적용합니다. 예제 수치는 계산 확인용입니다. 실제 모델별 Edge 좌표와 Hole 치수를 입력하세요.

Cell별 배치와 모델 선택

X/Y는 공통 얼라인 기준에서 해당 Cell의 첫 픽셀(첫 빔)까지의 거리(mm)입니다. 여기서 C26을 회전시켜 더한 첫 샷 중심이 그 Cell의 Masking 원점입니다. 회전은 X 오른쪽·Y 아래쪽에서 시계방향 양수입니다.

검증 범위

이 프로그램은 기준 Excel의 16,742개 중심 명령좌표를 재현하고, 지정한 기하 형상의 접촉 여부로 발진 조건을 계산합니다. C26은 (픽셀 크기 × 피치 ÷ 축당 분기 수) × (분기 수 − 1) ÷ 2로 자동 계산합니다. 명령표는 좌표와 발진 상태를 담은 제어기 독립 형식이며, 장비 전용 Script 언어로 실행하려면 명령 매핑이 필요합니다. 각 Cell 내부 Hole은 PPID의 좌상단·Size(Box) 기준 금지박스입니다. 평가 예제의 Edge는 각 모서리에서 max(X,Y) 장변으로 만든 사각형 금지박스입니다. Hole은 첫 샷 중심 A 기준입니다. 전역 보정은 공정 이동으로 취급해 고정 Masking 형상에 대한 조사 위치 변화에 포함합니다. 실측 DOE 분기 보정·장비 정렬 보정·MOF 노광 중 이동 및 Gate 응답 지연은 장비 연동 단계에서 적용해야 합니다.
