02. Align·첫 Pixel B·첫 샷 중심 A

Cell 배치 입력 X/Y는 얼라인 기준에서 해당 Cell의 첫 Pixel B까지 거리입니다. 각 Cell마다 첫 샷 중심 A를 계산하고, Hole과 샷 판정은 그 A를 원점으로 사용합니다. A가 Off여도 원점은 이동하지 않습니다.

Δ = Pixel size × Pitch = 0.09×30 = 2.7000 mm b = Δ / 분기 수 = 2.7/4 = 0.6750 mm c = b×(분기 수−1)/2 = 0.675×1.5 = 1.0125 mm B [A 기준] = (−c,−c) = (−1.0125,−1.0125) mm A [Cell 1 Global] = (25.5+c, c) = (26.5125,1.0125) mm

이미 측정된 A 좌표를 입력할 때는 시뮬레이션의 입력 기준을 “확인된 A”로 선택합니다. 내부적으로 B 좌표로 환산하여 c를 두 번 더하지 않습니다. Cell 회전 θ는 X 오른쪽·Y 아래쪽 규약에서 시계방향이 양수입니다.

03. 샷 격자·Global·Head 출력

NX = floor(864/30) = 28 / NY = floor(512/30) = 17 샷 중심 P [A 기준] = (ix×2.7, iy×2.7) mm Cell당 28×17 = 476개 / 45 Cell 전체 21,420개 ix=0…27 / iy=0…16 회전 θ=0인 Cell (열 j, 행 k; 0부터 시작) Global X = 25.5 + j×100 + c + ix×2.7 Global Y = k×200 + c + iy×2.7 Head 구간 번호 h = floor(Global X/110)+1 Head Center X = 55 + 110×(h−1) GY = Global X − Head Center X GX_STAGE = −(Global Y +120 + (홀수 h ? 380 : 0))

사용자 예상표의 첫 열은 위 식의 GY, 둘째 열은 GX_STAGE와 같은 표시 순서입니다. 실제 장비의 GX/GY 축 매핑은 장비 연결 규격에서 별도로 적용합니다.

Cell 1, ix=0, iy=0, Head 1 GY = 25.5+1.0125−55 = −28.4875 mm GX_STAGE = −(1.0125+120+380) = −501.0125 mm 다음 X 중심은 +2.7000 mm / 다음 Y 행은 GX_STAGE −2.7000 mm

각 Head 안에서 Y 행 순서, 같은 행에서는 Cell 열·X 인덱스 순서로 정렬합니다. Masking은 이 좌표·Head·순번을 수정하거나 삭제하지 않습니다. 회전된 Cell은 B에서 R(θ)(c+ixΔ, c+iyΔ)를 적용하여 Global 좌표를 계산하고, Masking 판정은 A 기준 Local로 역변환합니다.

05. 모델별 Hole·모서리 금지박스

Common의 CELL_MODEL_TYPE_COUNT는 모델 종류 수 1~5입니다. 각 Cell의 CELLn_MODEL_TYPE으로 형상 세트를 선택합니다. 모델은 Hole 21개 입력과 Edge 8개 입력, 총 29개 항목을 갖습니다.

06. 가공영역·접촉 판정 사각형

샷 중심점만으로 판정하면 빔 또는 가공영역이 금지박스에 걸린 경우를 놓칠 수 있습니다. 선택한 사각형의 네 경계를 만들어 금지영역과 겹치는지 확인합니다.

선택 기준반폭 h이번 조건 전체 크기
DOE 빔 중심 외곽(Δ/n)×(n−1)/22.025×2.025 mm
Pitch 타일Δ/22.700×2.700 mm

Pitch 타일은 각 빔에 중심 간격의 반만큼 영역을 할당한 뒤 4×4 배열을 감싸는 사각형입니다. 이는 광학 스폿 직경의 측정값이 아닙니다. 이번 예상표는 Pitch 타일 기준으로 검증합니다.

판정 사각형 [P 중심, 반폭 h=1.35] bL=Px−h / bR=Px+h / bT=Py−h / bB=Py+h Cell과 DOE 상대 회전각 α hAABB = h×(|cosα|+|sinα|) + 빔 반경 + 위치 여유

회전 시에는 보수적인 외접 사각형을 사용합니다. 빔 반경과 위치 여유는 둘 다 입력하거나 둘 다 비우며, 양수 여유는 판정 영역을 확장합니다.

07. 모서리 사각형 접촉 계산

09. MOF 순서·최종 발진

최종 Gate 미배정 Head → 출력에서 제외 (전체 진단에는 Off로 표시) 배정된 Head + Hole/Edge 접촉 → Off 배정된 Head + 접촉 없음 → Base Gate 유지 Off는 좌표 삭제가 아니라 같은 MOF 경로의 비발진 통과입니다.

10. 하이브리드 Cell·레시피 구조
