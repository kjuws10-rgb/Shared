②SVD = 계산 구조를 펼쳐 보기

③전체 기판 = 핀에 고정한 얇은 막

핀을 그대로 두고 중간을 가능한 덜 굽게 잇는 선택이 가능합니다. 실제 기판이 그 모양이라는 뜻은 아니므로 중간과 엣지를 따로 확인해야 합니다.

2. 같은 측정값으로 전체 기판을 그리면

가상 공통 좌표 · 장비 명령 아님

원은 측정 제약, 격자는 모델 예측입니다. A1~A4는 Align, D1~D6는 중앙 Distortion입니다. 예제 Align도 X 두 줄 배치이며, 기판 외곽 전체를 측정한 것이 아닙니다. 모든 시각적 비교는 동일 배율입니다. 잔류 색 지도는 합성 정답이 있는 시연에서만 계산합니다.

기판 테두리는 어떻게 정하는가

왼쪽 엣지의 X방향 변위 예측. 엣지에 측정점이 없으면 세 곡선의 차이를 실측 우열로 판단할 수 없습니다.

측정한 곳 / 연결한 곳 / 바깥으로 뻗은 곳

음영은 측정점 볼록껍질입니다. 안쪽도 직접 측정한 면은 아니며, 바깥쪽 외삽은 별도 검증이 필요합니다. 색은 통계적 신뢰구간이 아닙니다.

왜 ‘10점이니까 9차’로 전체 면을 만들지 않는가

10점이 하나의 선 위에 있는 문제와 기판의 2D 면 문제는 다릅니다. 총 3차 2D 다항식은 계수가 10개지만 배치에 따라 풀리지 않을 수 있습니다. 예제처럼 점이 X=a, X=b 두 줄에만 있으면 (x−a)(x−b)는 모든 Key에서 0이 됩니다. 이 성분을 더해도 Key 값은 같으므로 계수를 유일하게 정할 수 없습니다. 차수를 높이는 것만으로 미측정 정보가 생기지 않습니다.

라그랑주 비교판은 공통 좌표로 환산된 Align 양끝을 각 열에 포함하므로 Distortion 6개일 때 열당 5점·4차입니다. 실제 raw pixel 프로파일의 카메라당 Distortion 3점·2차와 구별합니다. X 두 줄이 아닌 레시피에서는 이 단순 비교판을 보류하고 일반 산포점 TPS만 계산합니다.

해결은 독립된 관측과 모델 검증

대표 Model에서 중앙 사이·좌우 엣지·상하 끝·가공 경로 부근의 추가 점을 검증용으로 확보합니다. Z 휨은 2D pixel만으로 분리하기 어려우므로 광학·높이 영향도 별도 확인합니다.

시연의 추가 변형은 모든 레시피 Key를 피한 영역 안에만 존재합니다. 사용자가 Key 위치를 그 영역으로 바꾸면 이 반례는 자동으로 꺼집니다. ‘엣지 곡선만 정확하면 내부도 정확하다’는 주장도 성립하지 않습니다. 경계에서 0인 내부 변형을 더할 수 있기 때문입니다.

수식으로 보는 ‘같은 점, 다른 전체 모양’
u₂(q) = u₁(q) + α b(q) e b(qᵢ)=0 (모든 측정 Key), 그러나 미측정 영역에서는 b(q)≠0 → 두 변형장은 동일한 관측값을 만들지만 전체 가공 위치는 달라집니다. 경계만 알고 있을 때의 예: b(s,t)=s(1−s)t(1−t) → 네 테두리에서는 0, 내부에서는 0이 아님.

실제 시연은 Key가 없는 작은 타원 안에서 b=(1−r²)³, 바깥에서 b=0으로 둔 매끈한 국부 변형입니다. 어떤 선택 모델도 관측하지 않은 이 변형을 자동으로 알아낼 수는 없습니다.

5. 전체 가공 좌표를 만드는 개발 순서

관측을 정렬 후 한 상태로 맞춤

카메라 대응과 실제 Align 변환을 적용해 설계 Key qᵢ의 실제 위치를 정합니다. 원 pixel은 수정하지 않습니다.

변위값을 제약으로 고정

dᵢ=실제 위치−명목 위치. 모든 Key에서 u(qᵢ)=dᵢ를 만족하도록 계산합니다.

미측정 영역의 연결 규칙 선택

라그랑주 연결을 기준선으로 두고 최소 굽힘 2D 후보를 비교합니다. 차이는 모델 가정입니다.

전체 레시피의 각 점에서 평가

시작점만 보정하지 않고 선·곡선·해칭의 전체 경로에서 u(q)를 구합니다. 곡선 오차 기준으로 점을 더 나눕니다.

가공계로 합성하여 검증

G를 공통 기판 좌표→가공 명령 좌표 변환으로 정의하면 가공 위치=G(q+u(q)). 기존 Align을 G에 포함했는지 확인해 중복 적용을 막습니다. 가공 영역·기울기·접힘·속도·트리거 조건을 점검합니다.

Key 밖의 가공 결과를 확인

보정에 쓰지 않은 점과 실제 가공 자국으로 검증합니다. Model·레시피·가공계 대응 버전별로 승인합니다.

보정 방향: 휜 재료 위의 목표를 따라갑니다

재료의 설계점이 오른쪽으로 옮겨졌다면 레이저도 그 실제 재료점을 따라가야 합니다. 이 정의에서는 q+u(q)입니다. 영상 원복의 역변환 F⁻¹와 혼동해 무조건 빼면 안 됩니다. 장비가 역보정 맵을 요구하면 해당 계약에 맞춰 역함수를 계산합니다.

엣지에서 전체 면으로의 확장 규칙

현재 네 테두리의 연속 측정값은 없습니다. 라그랑주 비교는 X 두 줄의 곡선을 선형 연결·외삽하고, TPS는 점 전체를 만족하는 최소 굽힘 함수로 엣지와 내부를 함께 예측합니다. 한쪽 엣지 값을 안쪽에 그대로 복사하거나 거리 비율로 약하게 만드는 임의 보정은 사용하지 않습니다.

향후 네 엣지를 실제로 촘촘하게 측정한다면, 코너가 일치하는 네 경계 곡선의 Coons 연결이나 물리 모델을 비교할 수 있습니다. 그래도 내부만의 휨은 따로 검증해야 합니다. 현재 10점을 네 경계 곡선으로 가장하지 않습니다.

6. Auto Tune은 무엇을 바꾸는가

실제 Key 값 유지 · 연결 모델 검증

‘약한 보정/강한 보정’으로 실제값을 축소하는 대신 직접 연결 / 면 연결 / Auto Tune 연결이라는 단어를 사용합니다. Auto Tune이 고르는 것은 관측점 사이의 연결 후보입니다. 어떤 후보도 현재 기판의 Key 값을 줄이지 않습니다.

직접 연결

라그랑주 기준선. 점과 경로가 어떻게 이어졌는지 쉽게 설명합니다.

면 연결

정확 통과 TPS. 전체 면을 덜 굽게 잇는 가정을 사용합니다.

Auto Tune 연결

과거의 독립 검증점에서 후보를 비교하고, 뒤쪽 과거 구간에서도 일치할 때 다음 기판 후보로 선택합니다.

라그랑주 잔류TPS 잔류이전 이력으로 선택한 Auto 후보아래쪽이 합성 검증점에 더 가까움
시연에는 합성 검증점이 있습니다. 실제 10점만으로는 이 승자를 고를 수 없습니다. 실측에서는 Key 값·방향·곡률 추세를 보존하되, 독립된 내부·엣지·가공 결과가 없으면 Auto Tune 갱신을 보류합니다. 동일 Key 재촬영만으로 점 사이의 보정 정확도를 평가하지 않습니다. 기판매수가 늘었다는 이유만으로 정확도가 저절로 높아지지는 않습니다.

각 시연 기판은 잡음 없이 생성됩니다. 비교 지표는 Key 이외의 합성 내부·엣지 점에서 계산합니다. 후보 선정은 현재 기판 이전 이력만 사용하며, 과거 앞 구간과 뒤 구간의 선택이 일치할 때 다음 기판에 선택합니다. 보라색은 그때 선택한 후보의 독립 합성 검증 잔류입니다. 이력이 부족하면 라그랑주 기준선을 유지합니다. Model·레시피·Key 수·변형 시연 조건을 바꾸면 이력은 새로 시작합니다. 본 그래프는 생산 신뢰구간·수율 예측이 아닙니다.

7. 개발 판단과 검증 범위

이번 조건에서 권하는 순서

  1. 원측정 10점과 정렬/촬영 문맥을 보존합니다.
  2. 카메라별 라그랑주 프로파일을 기준선으로 확인합니다.
  3. 공통 좌표 대응·정렬 후 제약이 성립하면 정확 통과 TPS/SVD로 전체 면 후보를 만듭니다.
  4. 추가 검증점으로 엣지·내부·가공 경로의 우열을 확인합니다.
  5. 확인된 Model 레시피 버전에서 전체 가공 경로에 적용합니다.

계산 성공과 가공 성공은 다릅니다

Key 정확 통과는 필요한 조건입니다. 외삽, 국부 변형, Z/광학 영향, 좌표 대응 오류, 정렬 중복, 과한 기울기·접힘은 별도 확인 대상입니다. 스캐너 명령을 생성하기 전에 전체 경로·가공 영역과 장비의 보정 방향 계약을 점검해야 합니다.

현재 도구는 오프라인 교육·개발 검토용입니다. 실측 기판이나 레이저 가공 정확도·통신·축 동작을 검증한 결과로 표시하지 않습니다.

수학 근거와 해석

Berrut & Trefethen · Barycentric Lagrange Interpolation: 1D 다항 보간의 정확 통과와 계산 방식. 임의의 2D 기판 형상 복원 보증으로 확대하지 않았습니다.

LAPACK · SVD: 분해와 특이벡터 관계. 작은 특잇값이 어떤 의미인지는 적용 행렬에 따라 해석했습니다.

SciPy · RBFInterpolator: smoothing=0 정확 보간, TPS의 r² log r 및 affine 항·행렬 조건. 이 문서의 TPS 코드는 별도의 소규모 교육 구현입니다.

Duchon · Interpolation des fonctions de deux variables suivant le principe de la flexion des plaques minces (1976): 전체 평면의 굽힘 반노름을 최소화하는 보간과 다항식·모멘트 조건. 실제 척킹 기판의 재료 모델로 동일시하지 않습니다.

Boyd & Vandenberghe · Convex Optimization, equality constraints: 정확 제약의 자유 변수 축소를 설명하는 참고입니다. 이 페이지의 형상 가정·반례·개발 판단은 해당 원리를 현재 촬영 구조에 적용한 분석입니다.
