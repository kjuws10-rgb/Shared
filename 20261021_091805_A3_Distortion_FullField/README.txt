원문 출처·이전 버전 링크를 열 때만 인터넷이 필요합니다.

사용자 확정 배치: 최초 Align 4점(4 Camera) + 정렬 후 중앙 Distortion 6점(그중2 Camera,Y 이동).
10개 실제 pixel을 노이즈로 축소하지 않습니다. 6/4/2 선택은 중앙 계산에 사용할 Key만 고릅니다.
기존 두 기능: A 원측정 상태/척킹 확인·Retry/Hold, B 적합 기판의 전체 가공 위치 보정.
이번 실행 시연은 기능 B의 연결 알고리즘 중심이며 실제 척킹 합격 기준을 임의 생성하지 않습니다.

핵심 판단:
1) 같은 기저·같은 정확 통과 조건에서 해가 유일하면 라그랑주와 SVD 계산은 같습니다.
2) 전체 면은 점을 연결하는 추가 모델이 필요합니다. TPS 최소 굽힘 정확 보간을 SVD로 계산해 비교합니다.
3) 이 후보는 SVD만 덧붙인 고전 라그랑주와 다른2D 기저입니다. 두 모델 모두 측정값을 그대로 만족합니다.
4) 작은 특잇값 방향이 보편적인 최적 공간은 아닙니다. 정확 제약의 영공간은 제약을 유지한 최적화에 쓸 수 있습니다.
5) Align 4점은 정렬 전 관측이므로 공통 정렬 후 상태로 옮기는 조건을 확인해야 합니다.
6) 미측정 엣지·내부 형상은 모델 예측입니다. 추가 검증점·가공 결과 없이 우열을 확정하지 않습니다.

실제 pixel 입력:
Camera·Key·ScanPose·ROI/광학 조건 버전·정렬 단계가 같은 기준 pixel을 입력합니다.
설계치만으로 기준 pixel이나 카메라–가공 좌표 대응을 생성하지 않습니다.
실제 입력은 카메라별 상대 pixel로만 표시하며 전체면/장비 명령을 내보내지 않습니다.
가상값 채우기로 만든 기록은 synthetic-demo, 직접 입력은 manual로 구분합니다.
기록은 원측정·기준·레시피 snapshot을 보존합니다. 같은 Model/Glass ID의 중복 기록은 막습니다.
기준값·카메라 대응을 확보하지 않은 상태에서 단위·축 부호를 추정해 가공에 적용하지 마세요.

시연:
전체면 시연은 공통 좌표로 환산된 정렬 후10점이 있다고 가정한 합성 예제입니다.
실제 pixel과 별도이며, 무차원 변위를 확대해 그립니다. 물리 mm/µm 성능값이 아닙니다.
가상 Lot을 추가하면 이전 기판의 독립 공간 검증으로 다음 후보를 고르고 보라선으로 평가합니다.
현재/미래 기판은 선택에 사용하지 않습니다. 합성 시연에는 추가 위치의 정답이 있습니다.
실제10점만 쌓이는 경우에는 Key밖 검증자료가 없으므로 자동 갱신을 보류해야 합니다.
