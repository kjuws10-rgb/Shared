PROCESS SW 개발 · 그림 중심 페이지별 붙여넣기 묶음

1. index.html을 열어 페이지를 선택합니다.
2. Confluence에 페이지_제목과_첨부목록.txt의 제목으로 페이지를 만듭니다.
3. pages의 해당 페이지 폴더에 있는 PNG를 먼저 그 페이지에 첨부합니다.
4. 같은 폴더의 페이지소스.storage.xhtml.txt를 열어 전체 복사합니다.
   또는 미리보기의 소스 전체 선택 → Ctrl+C를 사용합니다.
5. 해당 페이지의 소스 편집기에 붙여넣고 저장합니다.
6. 본문 그림과 상위·주제 링크를 확인합니다.

상위1 + 기능별16 = 17페이지입니다.
핵심 흐름도17개와 기존 설명 그림을 정리한 세부 그림10개를 담았습니다.
각 페이지는 그림, 짧은 핵심 설명, 표와 확인 항목으로 구성했습니다.
attachments는 전체 PNG·SVG 모음입니다. 페이지별 폴더에는 필요한 PNG가 함께 있습니다.
그림_모아보기.html에서 27개 그림을 한 번에 볼 수 있습니다.

붙여넣기 소스의 그림은 Confluence 첨부파일을 참조합니다.
텍스트를 붙여넣는 것만으로 PNG가 업로드되지는 않으므로 3단계를 먼저 수행하세요.

검증 범위: 문서 XML, 제목·링크·그림 연결, 파일과 그림 대조.
실제 사내 페이지 저장·렌더링과 장비 실행은 별도 확인이 필요합니다.
