선택에서 완료 응답까지 · 구현 기본안

  1. ModelCode로 PPID와 Pin Profile을 선택하고 이번 요청의 데이터를 고정합니다.
  2. 선택 Header / Entry의 유효성과 버전을 대조하고 실제 핀 축의 이동 허가를 확인합니다.
  3. 기판 투입과 동시 이동합니다. 핀끼리의 이동 순서·그룹은 실제 기구 사양 C07 협의로 정합니다.
  4. 사용 핀 전체의 위치 / 완료 센서 결과를 확인해 PinReady + AckSeq + 적용 Version을 반환합니다.
  5. 가공 PC가 반송·핀·설정 응답을 합류합니다. 합류 시점 C03 협의, 실패 시 Recovery C05 협의.
