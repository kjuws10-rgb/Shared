1. 두 기능의 목적과 구현

기능 A

잘못 척킹된 기판을 걸러냅니다

목적 · 정상 범위를 벗어난 척킹 상태에서 가공을 시작하지 않습니다.

구현 · Fine Align 완료 후 10점을 취득하고, 승인된 Bench mark 대비 편차를 판정합니다. Distortion 6점의 축별 허용편차를 넘으면 Stage에 Retry Chucking을 요청합니다.

결과 · PASS / Retry / Hold와 초과한 Key·축·편차.

기능 B

정상 기판의 변형을 따라 가공합니다

목적 · 기판마다 달라지는 평면 내 변형에 맞춰 가공 위치를 이동합니다.

구현 · 기능 A가 통과한 측정값으로 변위장을 만들고 가공점마다 보정량을 계산합니다. 보정률·한계값을 확인한 뒤 해당 기판의 좌표 Snapshot을 활성화합니다.

결과 · 기판별 보정 Map·가공좌표·적용 버전.

판정과 보정을 분리합니다. 척킹 판정에는 평활화·가중치 적용 전의 유효 측정편차를 사용합니다. 보정률을 낮추거나 작은 특잇값 공간만 남겨 척킹 NG를 PASS로 바꾸지 않습니다.

Fine 4점 + 좌우 3쌍 Distortion 6점. 이 XY 관측은 척킹에 따른 평면 변형 지표이며, 기판 전체의 Z warpage·평탄도를 직접 보증하지 않습니다.

4. 알고리즘 발상에 대한 검토 의견

대표 공간의 사전 계산은 타당합니다. 다만 “가장 작은 특잇값 방향이 언제나 최적”은 아닙니다. 무엇을 작게 만드는 행렬인지 먼저 정해야 합니다.

추천 방향 · 임의의 작은 σ 공간에서 해를 찾기보다, 측정 일치 + 물리적으로 타당한 매끄러움 + 필요한 경계 조건을 목적함수로 먼저 정의합니다. 그다음 SVD로 안정적인 해 또는 제약을 유지하는 축소 해를 구하는 접근이 적합합니다.

라그랑주로 변형을 단순하게 연결

좌우 가장자리에서 Y 방향 5개 편차를 각각 4차 라그랑주로 잇고, 같은 Y에서 좌우를 선형으로 연결합니다. X·Y 편차를 각각 계산합니다.

u(s,t) = (1−s) Σ ℓⱼ(t) dLⱼ + s Σ ℓⱼ(t) dRⱼ
가공점 = 기준점 + 보정률 × u(s,t)

Barycentric 형태로 계산하며, 기준점과 일치하면 그 값을 직접 반환합니다. 측정점의 노이즈·편중과 실제 형상에 따라 오차가 달라집니다. 계산식을 안정적으로 구현해도 부적절한 점 배치의 문제까지 없어지지는 않습니다. [1]

이번에 구현한 SVD 활용

L = “노드 값 → 이산 곡률”로 둡니다. L의 작은 특잇값 모드는 덜 굽는 형상을 나타냅니다. 원측정 일치와 곡률 감소를 함께 최적화한 뒤 라그랑주로 잇습니다.

min ‖c−d‖² + λ² ‖L̄c‖²
선택 제약: c₀=d₀, c₄=d₄
L̄ = L / σmax(L)

c는 보정용 근사 노드, d는 원측정 편차입니다. λ=0이면 원래 라그랑주와 같습니다. 끝점 유지 옵션은 끝점 제약의 영공간에서 내부 3개 노드만 최적화한 것과 같습니다. 곡률 감소가 실제 정답에 가까워짐을 보장하지는 않습니다.

분해할 행렬작은 특잇값 방향의 의미발상에 대한 판단

한계·리스크와 검증 기준

측정으로 보이지 않는 형상두 가장자리에서 0인 내부 변형은 10점만으로 복원할 수 없습니다. 보간식 변경보다 내부 검증점의 확보가 먼저입니다.
평활화의 반대 효과λ가 크면 잡음은 줄어도 실제 급격한 휨도 지웁니다. 학습 Key의 잔차가 아니라 별도 내부 측정점의 RMS·Max로 선택합니다.
공간의 재사용 범위점 위치·기저·단위·가중치·경계 조건이 고정되면 분해를 재사용할 수 있습니다. 측정값 d만 바뀌면 다시 분해할 필요가 없습니다.
의견의 조건과 개발 시 주의점 더 보기
  • 공간을 좁힌다고 같은 목적함수의 최솟값이 좋아지지는 않습니다. 부분공간 S에 대해 minS J ≥ min전체 J입니다. 축소의 이점은 계산·잡음 억제·사전 지식이며, 실제 성능은 편향과 분산의 균형으로 평가합니다. 이번 이차 목적함수는 I+λ²L̄ᵀL̄가 양의 정부호여서 유일한 전역해를 직접 계산할 수 있습니다.
  • 목적함수 Hessian을 뜻했다면 해석이 또 달라집니다. 작은 고유값 방향은 평평한 방향이지 해가 있는 방향이라는 뜻이 아닙니다. 역행렬로 이동량을 구하면 불안정해질 수 있습니다. 일반 비대칭 행렬의 우측 특이벡터를 목적함수 곡률 방향으로 바로 해석하면 안 됩니다.
  • “Flexible하므로 라그랑주가 맞다”는 자동 결론은 아닙니다. 순한 변형에는 적합할 수 있으나 미끄럼·국부 불연속·실제 3D 휨을 단일 4차식이 설명하지 못할 수 있습니다. 이 예제는 2D 미소 변위장 가정입니다.
  • 사전 공간의 물리적 근거가 중요합니다. 실제 강성/에너지 행렬의 작은 모드는 유연한 변형일 수 있습니다. 경계·척킹·재료·자세 모드를 구분하고 실측과 검증해야 하며, 임의 보간 행렬의 작은 모드와 동일하지 않습니다.
  • 단위·좌표·기저·노름을 고정해야 합니다. 열의 크기나 측정 가중치를 바꾸면 작은 σ의 순위·벡터도 달라질 수 있습니다. 잡음 공분산을 알고 있다면 whitening 후 모델을 재검증합니다. 이 모형은 동일 분산의 독립 잡음을 가정합니다.
  • 작은 σ를 0으로 간주하는 허용값은 근사 제약입니다. 실제 허용 편차로 ‖CZz‖를 제한해야 합니다. 정확한 CZ=0과 구분하고 유효 랭크·조건수를 기록합니다. 먼저 Cc₀=b인 실현 가능한 기준해가 필요합니다.
  • 끝점 유지도 무조건 유리하지 않습니다. Fine Key 자체가 noisy하면 그 오차까지 고정합니다. 기준·교정 반복성 검증 후 옵션을 승인합니다. 측정 실패·결측은 값을 0으로 치환하거나 보간해 생산 승인하지 않습니다.
  • λ·공간 차원 k의 최적값은 아직 모릅니다. 시뮬레이터의 값은 비교용이며 최적값을 자동 추정하지 않습니다. 독립 기판·내부점으로 검증하고, 드문 불량·모델 변경·온도·재척킹 사례를 별도 시험합니다. 이력 행렬 D는 평균 형상·중심화·정규화를 정의해야 하며, 행/열 배치를 뒤집으면 공간 모드는 U 쪽으로 바뀝니다.
  • 계산량 감소와 성능 향상은 별개입니다. 5×5 분해는 작고 직접 보간도 저렴합니다. 사전 계산의 실용적 이득은 모델·속도·연산량을 실측해야 합니다. 큰 변형·비선형 반복해석에서는 Jacobian이 변해 공간을 갱신해야 할 수 있습니다.
구현식·추천 검증 순서
A=UΣVᵀ → 관측 역산: c=Σᵢ (uᵢᵀd / σᵢ)vᵢ
L̄=UΣVᵀ → 무제약 평활화: c=V diag(1/(1+λ²σᵢ²)) Vᵀd
제약 최적화: Cc=b, c=c₀+Zz, CZ=0
min_z ‖c₀+Zz−d‖²+λ²‖L̄(c₀+Zz)‖²

위에서 L̄의 σ는 정규화된 곡률 특잇값입니다. 끝점 유지 ON에서는 내부 3개 변수에 대해 축소된 곡률 행렬을 SVD하여 같은 이차 목적함수의 해를 구합니다. 일반 행렬의 SVD 정의는 [4], 영공간 일반해는 [3]를 참고했습니다.

  1. 독립 기준계산과 단위·영변형·선형·4차식 재현·구간 경계 검증.
  2. 잡음·점 편중·국부 휨·미관측 내부 변형·결측·Retry·보정 제한 시험.
  3. 같은 실측 데이터로 선형 / 라그랑주 / 정규화 방식을 비교. 별도 내부점·기판에서 선택한 λ와 모델을 평가.
  4. 실제 Stage/Vision 연동과 좌표 부호·전체 가공점·DOE Field 검사 후 실가공 승인. 모형 통과와 분리하여 기록.

이 모형의 Max 보정 검사는 17×31 가상 격자 검사로, 연속 영역 전체의 극값 보증이 아닙니다. 최종 장비에서는 실제 전체 가공 좌표를 검사해야 합니다. 무작위 잡음은 고정 seed를 써 방법 간 비교 조건을 유지합니다.
