## 실제 응답의 의미

“Review 좌표를 계산하고 Vision에 전달하는 코드를 찾아, 현재 흐름을 실제 파일 근거로 설명해줘.”를 실제 앱에 입력했다. AutoFine/Flying 흐름의 계산 함수, mm 좌표의 PLC/IOF 전달, Vision1001의6정수 식별정보, TCP 송신, 수신 픽셀→mm, 로컬 CSV 저장을 구분하고 실제 소스 근거19개를 반환했다. 전 근거의 파일 SHA·행·본문을 선택된 최신 사본과 대조했다. 질문 처리 중 제안·코드 변경·빌드·장비 실행은0이다.

이 결과는 **소스 검증 역할지도 조회**이며 LLM 생성 정확도 통과로 계산하지 않는다. 앞선 실제8B 자유생성은 CSV를 Vision payload로 혼동해 불합격으로 보존했다. 역할지도를 추가한 자유추론은 장시간 지연으로 취소했으며 정확도 통과로 기록하지 않았다. 도구는 검증된 일반 흐름 조회와 LLM 추론을 구분한다. 진단·편집·다른 모드·상세 요청은 로컬 모델을 사용하며 오류 가능성을 별도 확인해야 한다.

소스 역할 메모는 전체 파일 SHA가 확인한 버전과 일치할 때만 사용한다. 원문이 바뀌면 해당 메모·빠른 조회를 제외한다. 새 코드 구조는 다시 검토해 메타데이터를 갱신해야 하며 가중치 재학습을 뜻하지 않는다. Codex 동급 정확도를 검증한 상태도 아니다.

## 실행·보존 범위

도구 publish는 성공했다. 실제 A3 전체 기준 빌드에는 기존 Common.Log/CLogManager 관련19오류가 남아 있다. 실장비·스캐너·물리 NIC 분리·새 노트북 OS 초기 설치는 검증하지 않았다. 추론과 조회는 로컬 loopback이며 정상 시작은 외부 Git 접속을 하지 않는다.

기존 앱·프로젝트·모델은 보존하고 최신 master를 별도 사본으로 준비했다. 원본 A3 저장소 파일/Commit/Push는 변경하지 않았다. 공개 ZIP에는 장비 소스·내부 자료·모델 가중치·사용자 상태·실제 QA 원문이 없다. 기존0.5 배포 파일도 보존했다.
