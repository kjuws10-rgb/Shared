## 현장에서 달라지는 점

| 변화 | 의미와 적용 범위 |
| --- | --- |
| Review Data 재검사 목록 | 여러 Cell의 선택 Shot/NG Shot을 모으고 Beam을 바꿔 이동·측정·새 결과 저장을 할 수 있습니다. 임의 Line Flying이나 기준 Shot 보정 복사와는 다른 기능입니다. |
| 수동 MOF Shift 확인 | 마지막 성공 MOF의 X/Y Shift를 수동 리뷰에 적용하거나 0으로 검사할 수 있습니다. 이력에는 Recipe/Glass/Head가 없어 대상 확인이 필요합니다. |
| AUTO Shift 0 고정 | AUTO 가공과 AUTO Fine은 Shift를 0으로 만듭니다. Shift 유지 AUTO 가공 요구가 구현된 것은 아닙니다. |
| 보정 적용 중복 확인 | 같은 날·같은 경로의 결과에 대한 적용 이력을 조회합니다. AUTO는 중복 알람, 수동은 사용자 확인입니다. 날짜 변경·파일 복사·재검사 새 파일까지 전역으로 막지는 않습니다. |
| 결과 CSV 확장 | Shift X/Y와 실측 출처를 보관하고 재검사는 원본을 덮지 않는 Revision 파일로 저장합니다. |
| 실행 설정 변화 | 기본 Vision 주소가 loopback, MELSEC가 SIMUL=1이며 분해능/0선/FollowUp도 바뀝니다. 현장용 설정과 분리해 검수해야 합니다. |
