Test 항목.

1\. 상위 프로그램을 통해 Script 생성 후, 실제 Automation1에서 생선된 Script가 실행되는지 확인 완료.(Simulation)

 - 상위프로그램: Client / 상위 프로그램을 통한 Automation Server 연결

 - Scanner1~4번 총 8개의 Scanner X,Y축 동작 확인.

 - 현재 프로그램은 Stage 구동 및 Simulation이 불가한 상황으로 Stage 구동 관련 확인 함수 주석 후 구동 확인 완료.

2\. BufferedRun으로 동작 확인 완료.

 - 현재 Drill 관련 Script는 외부변수가 필요 없음.

 - BufferedRun인 경우 Script 실행 동작 중이면 QueueRunning / 일반적인 Script 실행일 경우는 ProgramRunning.


추가적으로 첨부파일 참고해서 우리가 가공기판에 대한 PPID 정보 기반으로 각 셀들에 대한 가공좌표를 생성했고 이때 각 스캐너들에 대한 가공좌표를 생성한 스크립트를 기반으로 Buffered Run에 대한 동작 평가를 진행했어

여기까지가 현재 진행된 내용이고 제공한 자료과 정보들을 기반으로 ppt 작성해줘 \

추가적으로 마지막 부분에 이제 여기에 더해서 PPID 정보중에 Edge Masking과 Hole Masking 정보와 추가적으로 Chess 가공을 했을때에도 가공좌표를 동일하게 생성해서 시뮬레이션테스트를 진행하겠다는 부분과 함께 고객사에 요청할 부분으로 평가하기 위한 데이터가 부족하다는 부분도 마지막에 언급해주면 좋을거같아. 예를 들면 스캐너 가공속도나 가감속 그리고 Edge Masking과 Hole Masking를 생성하기위한 파라미터 정보와 시뮬레이션을 위해 우리가 더 고려할 부분들은 없는지 추가적으로 필요한 테스트는 더 없는지 이러한 민감하지만 공유가능하다면 사전에 충분히 시뮬레이션 검증을 통해 향후 설비셋업때 문제가 없이 진행되도록 가이드를 받고자함 에 대한 내용까지 포함해서 ppt 3장으로 작성해줘
