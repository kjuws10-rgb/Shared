02

측정값은 먼저 ‘Head 원점’으로 바꿉니다

이후의 O₄·O₅는 영상의 임의 홀 위치가 아니라, 설계 변위를 제거한 각 Head 원점입니다.

이 문서에서 사용하는 O

O는 현재 Default B가 적용된 시험가공의 유효 원점입니다. B까지 제거한 기계 원점을 사용한다면 뒤의 B_new=B_base+ΔB 식을 그대로 사용하지 않습니다.

공통 mm로 한 번만 변환

Review가 영상 잔여 δ를 주면 M=촬영 시 광축 위치 E+δ, 이미 절대 좌표 M을 주면 E를 다시 더하지 않습니다. 서로 다른 카메라의 Pixel을 직접 평균하지 않습니다.

03

4·5번 사이에 기판 X 중심을 맞춥니다

신규 셋업에서 H4/H5 실측 중간을 기준으로 선택하는 경로입니다. 기계 HOME을 바꾸는 작업은 아닙니다.

  1. 기준 준비기판의 θ 정렬·현재 위치와 공통 mm 변환을 확인합니다.
  2. H4/H5 측정두 Head를 구분해 시험 가공하고 원점 O₄x/O₅x를 구합니다.
  3. 중심 고정대칭 배치라면 Cₓ=(O₄x+O₅x)/2를 이번 셋업 기준으로 고정합니다.
  4. 기판 정렬Stage 제어 경로로 Gₓ를 Cₓ에 맞추고 실제 도착·Align 결과를 확인합니다.
  5. 새 측정 시작H4/H5를 새로 가공·측정하고, 그 결과로 X Default를 계산합니다.
기존 승인 중심이 있다면

승인된 기판/ESC/Teaching C_ref를 유지하고 H4/H5를 그 목표에 맞춥니다. 측정 중간값으로 승인 기준을 덮어쓰지 않습니다. 비대칭 Head 배치에서는 dX₄/dX₅를 반영해 공통 기준을 구합니다.

기판 이동 후 주의

기존 마크도 기판과 함께 이동합니다. 이동 전 마크를 현재 Pose의 새 가공 결과로 쓰거나, 그 마크로 중심을 다시 계산하지 않습니다. Stage 정렬량을 Default에 다시 더하지 않습니다.

04

X 작업 순서 · H4/H5 → 나머지 Head

H4/H5에서 방향과 적용을 확인한 뒤 바깥 Head로 확장합니다. 앞 Head의 측정 오차를 다음 Head로 넘기지 않습니다.

  1. H4/H5 목표 계산T₄x=Cₓ−P/2, T₅x=Cₓ+P/2. 중심과 설계 Pitch는 고정합니다.
  2. H4/H5 보정·검증새 실측 O와 목표 T의 차이로 권장값을 적용하고, 다시 새 마크로 확인합니다.
  3. 나머지 Head 측정3·6 → 2·7 → 1·8 순서로 각 Head를 직접 가공·측정합니다.
  4. 나머지 Head 적용각각 Tₕx=Cₓ+dₕx, Cₕx=Tₕx−Oₕx로 계산·적용·새 검증합니다.
나머지 Head의 실측은 반드시 필요

H4/H5 결과로 알 수 있는 것은 공통 기준과 목표 위치입니다. H1·H2 등의 개별 설치 편차는 해당 Head를 측정해야 알 수 있습니다.

05

Y 작업 순서 · 설계 단차를 보존합니다

X 적용을 마친 상태로 새 가공·측정합니다. 두 Head가 앞뒤로 배치되어 있다면 그 설계 차이를 지우지 않습니다.

  1. Y 기준 고정승인된 절대 기준 또는 합의한 평균 그룹으로 Y_ref를 고정하고 Head별 dY를 읽습니다.
  2. H4/H5 새 측정O₄y/O₅y를 구하고 bₕ=Oₕy−dₕy를 확인합니다.
  3. H4/H5 보정Tₕy=Y_ref+dₕy, Cₕy=Tₕy−Oₕy로 적용한 뒤 새 마크로 확인합니다.
  4. 나머지 Head 확장각 Head도 동일 Y_ref+dₕy 목표로 직접 측정·적용·검증합니다.
  5. X/Y 재확인Y 보정 후 X도 다시 확인합니다. 축 결합이 크면 검증된 J로 공동 계산합니다.
평균 기준으로 작업할 때

설계 단차를 뺀 H4/H5 잔여 평균을 상대 정렬 기준으로 선택할 수 있습니다. 이 그룹은 이번 개발 권고안이며, 기존 승인 그룹이 있으면 유지합니다. 선택한 모드·그룹을 저장하고 ‘Head 간 상대 정렬 완료’와 ‘기판 절대 Y 검증’을 구분합니다.

권장 새 총량을 쓰는 API라면 기존값을 교체합니다. 기존 B에 B_new를 다시 더하지 않습니다. 같은 측정·후보를 반복 적용하지 않도록 Candidate ID와 Base Revision을 확인합니다.

07

8개 Head 계산 예시를 비교합니다

단위는 mm입니다. ‘측정 후 새 가공’을 가정한 교육용 데이터이며 장비 명령·보정 적용은 하지 않습니다.

Pitch=110 mm, H4/H5의 dY는 각각 +2/0, 예시 g는 H1~H4:+1·H5~H8:−1입니다. 실제 값은 Head별로 확인합니다. 기준을 바꾸면 실기에서는 새 가공·새 측정이 필요합니다.
