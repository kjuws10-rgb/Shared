4·5번 스캐너 기준과 기판 중심 정렬부터 X/Y 셋업, 나머지 Head의 권장 Offset을
핵심 설명과 그림으로 정리한 자료입니다.

내용
- 신규 H4/H5 중심 선택·고정과 기존 승인 기준 보존.
- Stage 기판 중심 정렬 후 새 가공·새 측정.
- X: H4/H5 → 바깥 Head, 고정 중심과 설계 Pitch에서 각 목표 직접 계산.
- Y: 설계 단차 제거/복원, 절대·상대 모드의 검증 범위 구분.
- 물리 이동 → 필드 입력 증분 → 권장 새 총량, 중복 적용 방지.
- 8개 Head 계산 예제와 전체 X/Y 새 가공 검증·개발 필수 기능.
