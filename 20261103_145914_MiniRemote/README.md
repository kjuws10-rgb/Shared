# MiniRemote 0.1.0 — 화면·키보드·마우스 원격 접속

조작받을 Windows PC에서 앱을 실행하고 접속을 승인하면, 다른 기기의 브라우저로 화면을 보면서 키보드·마우스를 조작합니다.

**현재는 프로그램 배포 파일입니다. 외부 접속에는 별도로 준비한, 사용 권한이 있는 HTTPS 중계 서버가 필요합니다.** 공용 서버는 배포하지 않았으며 실제 두 PC의 OS 입력·회사망/외부망 접속은 검증 전입니다. 회사의 방화벽·프록시·보안 차단을 우회하는 기능은 없습니다.

## 다운로드

| 파일 | 내용 |
| --- | --- |
| [MiniRemote-Light.exe](MiniRemote-Light.exe) | 221,288 bytes, 약216 KiB. Windows10/11 x64 + .NET10 Desktop Runtime 필요 |
| [MiniRemote-0.1.0.zip](MiniRemote-0.1.0.zip) | 실행 파일 2종, 중계 서버, 소스, 배포 예제, 한글 안내. 46,505,149 bytes, 약44.4 MiB |
| [시작안내.html](시작안내.html) | 연결 구조 그림과 순서. 내려받아 브라우저에서 열기 |
| [share-manifest.json](share-manifest.json) | 공유 파일별 SHA-256과 검증 범위 |

ZIP을 해제한 뒤 `시작안내.html`을 여세요. .NET이 없는 대상 PC에는 ZIP 안 `host-portable/MiniRemote.exe`를 사용합니다. 런타임 포함 파일은51,654,982bytes(약49.3MiB)입니다. 조작하는 기기는 데스크톱 브라우저만 있으면 됩니다.

## 사용 순서

1. 서버 관리자가 승인된 서버·도메인으로 HTTPS 중계 서버를 준비합니다. ZIP 안 `deploy/README.md`와 `deploy/compose.yaml`에 설정 예제가 있습니다.
2. 조작받을 PC에서 앱을 실행하고 `https://승인된-서버-주소`를 입력합니다.
3. **초대 링크 만들기 → 링크 복사**를 누르고, 필요한 상대에게 전달합니다.
4. 상대가 링크에서 **연결**을 누르면 대상 PC에서 **지금 허용**을 선택합니다.
5. 상대가 브라우저의 화면을 누르면 조작됩니다. **Esc**는 일시정지, 앱의 **즉시 중단 / Ctrl+Alt+F12** 또는 브라우저의 **접속 중단**은 종료입니다.

초대 링크는 접속 비밀키를 포함하므로 필요한 상대에게만 전달하세요. 표시 이름은 상대가 입력한 값이며 신원 인증 정보가 아닙니다. 승인 대기30초, 초대 대기5분, 연결 최대1시간이며 한 번 사용한 초대는 다시 사용할 수 없습니다.

## 로컬 시험

ZIP 안 `로컬시험.cmd`는 이 PC의 `127.0.0.1:8787`에서만 중계 서버를 실행하고 앱을 엽니다. 이 시험에는 .NET10 ASP.NET Core Runtime이 필요합니다. 서버 콘솔을 닫으면 종료됩니다. `localhost` 초대 링크는 다른 PC나 외부망에서 사용할 수 없습니다. 같은 PC에서 접속하면 화면이 반복돼 보일 수 있습니다.

## 동작 범위와 확인한 것

- 주 모니터1개, 최대1280×900 비율 유지 JPEG, 초당 최대5장과 키보드·마우스 입력을 제공합니다.
- 대상 PC의 승인 전에는 화면 전송·입력을 시작하지 않습니다. 연결 끊김·중단에서 원격으로 누른 키/버튼을 해제하도록 구현했습니다.
- TLS 검증, 방향별 AES-256-GCM, 순서 검사와1회용 초대를 사용합니다. 브라우저 프로그램을 제공하는 중계 서버와 관리자를 신뢰해야 합니다.
- 로그인/UAC 보안 화면, 관리자 앱, 브라우저·OS가 가로채는 단축키는 조작이 제한될 수 있습니다. 한글 IME와 전체 키보드 배열은 실기 확인이 필요합니다. 서명 없는 실행 파일이므로 회사에서 승인한 방식으로 배포해야 합니다.
- 로컬 릴레이/모의 입력 통합32항목, 릴레이30항목, JavaScript24항목, headless 브라우저 합성 시나리오10묶음과 C#↔JS 암호호환2방향을 통과했습니다. 실제 사용자 화면 캡처·OS 입력 주입은 이 시험에서 하지 않았습니다.
- 실제 두 PC의 키/마우스, 회사망/외부망, HTTPS 운영 배포, Docker Compose 구동은 미검증입니다. 코드·합성 시험 완료와 회사망 사용 가능 여부를 구분해야 합니다.

ZIP에 포함된 `verification.json`, `PROTOCOL.md`, 테스트 소스가 확인 범위를 설명합니다. 공유 파일 게시와 중계 서버 운영 배포는 별개입니다.
