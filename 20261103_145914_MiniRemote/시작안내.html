MiniRemote

화면을 보면서 키보드·마우스만 조작하는 Windows 원격 프로그램

PC용 앱과 중계 서버 파일까지 만들어졌습니다.
실제 외부 접속을 시작하려면 승인된 HTTPS 서버 주소가 필요합니다. 공용 서버는 아직 설치하지 않았으며 회사망 접속도 시험 전입니다.

어디에 무엇을 놓나요?

약 49.3 MiB · .NET 포함

두 파일 중 하나를 선택하세요. Windows 10/11 x64가 대상이며 조작받을 PC에서만 실행합니다.

연결 순서

  1. 서버 관리자가 승인된 HTTPS 중계 서버를 준비합니다. ZIP 안 서버 설치 안내
  2. PC 앱에 https://승인된-서버-주소를 넣고 초대 링크 만들기 → 링크 복사를 누릅니다.
  3. 필요한 상대에게 링크를 전달합니다. 상대는 브라우저에서 열고 연결을 누릅니다.
  4. 조작받을 PC의 승인창에서 지금 허용을 누릅니다.
  5. 상대가 브라우저 화면을 누르면 조작됩니다. 브라우저의 Esc는 일시정지입니다.

즉시 종료: PC 앱의 즉시 중단 또는 Ctrl+Alt+F12. 브라우저의 접속 중단도 연결을 끝냅니다.

로컬 시험과 사용 범위

ZIP 안 로컬시험.cmd는 같은 PC에서만 동작하는 서버와 앱을 엽니다. 생성되는 localhost 링크로 다른 PC에서는 접속할 수 없습니다. 실제 외부 접속은 HTTPS 서버를 준비한 뒤 시험하세요.

주 모니터 1개 · 최대 초당 5장 · 키보드·마우스 · 1회용 초대 · 승인 대기 30초 · 접속 최대 1시간. 링크는 접속 비밀키를 포함하므로 필요한 상대에게만 전달하세요.

회사 방화벽·프록시·보안 프로그램의 차단은 우회하지 않습니다. 로그인·UAC 화면과 관리자 앱은 조작이 제한될 수 있습니다. 실제 두 PC 조작과 회사망 접속은 검증 전이며 한글 IME 조합·모든 키보드 배열도 실기 확인이 필요합니다.
