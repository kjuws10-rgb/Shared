# A3 LD 시뮬레이션 평가 개발리스트

기존 시뮬레이션 보완 18개를 개발 작업 19개로 정리했습니다. 빌드 복구를 추가하고 실행 엔진과 평가 보고서를 나누며, 좌표·Align 정답 데이터는 하나로 묶었습니다.

기준: 원본 Commit `8872e4ed`와 첨부 평가 69개를 대조한 앞선 분석. 아래는 개발할 작업과 완료 기준이며, 현재 구현 완료 목록이나 일정 확정표가 아닙니다.

## 개발 우선순위

- P0: 시뮬레이션 개발·시험을 위한 필수 기반
- P1: 시나리오별 기능 보완과 업무 연결
- P2: 전체 자동 평가와 보고서 통합. 다만 평가번호·정답 형식과 기록 구조는 4번에서 먼저 정의합니다.

## 구현 전에 확인할 기준

1. 보호윈도우 교체 조건: 기존 2 OR와 새 첨부 3 OR, ATT 예측 입력·계산 방식.
2. Fine 보간식: 첨부 선형과 현행 Lagrange 중 승인한 방식.
3. 0선 통신 주기: 새 첨부의 포인트별 주기와 기존 단일 세션 자료 중 최종 계약. 새 첨부의 큰 주기는 현재 코드와 일치합니다.
4. Stage 허용 좌표·DistKey 주소·단위·최종 버전.
5. 품질 NG와 미검출의 재시도 정책, SectionComplete 펄스 또는 ACK 유지 계약.

기준이 미정인 분기는 조건부로 남기되 빌드·격리·공통 실행 기반은 먼저 개발할 수 있습니다.

## 재사용할 기능과 역할 범위

기존 수동 신호 입력, Stage 이동 모델·소유권, MELSEC 고장 API, Vision codec·패킷 API, 측정 결과 주입점과 PowerTable 시험 저장 구조를 우선 재사용합니다. 기능 전체를 새로 만드는 목록이 아닙니다.

가공SW는 요청·결과 처리·자기 완료 판단을 개발하고, Stage·PLC·Vision 모사기는 상대 응답을 제공합니다. Pin·Gate·ACS 내부 제어 전체를 가공SW에 복제하지 않습니다. 실제 PEG·촬영·축 정지·레이저 차단·카세트·가공 정밀도는 별도 현장 검수입니다.
