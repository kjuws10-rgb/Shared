A3 LD 시뮬레이션 평가 개발리스트

시나리오 평가를 위해 필요한 개발 작업 19개를 우선순위·선행조건·완료 기준으로 구분했습니다.

앞선 보완 18개에 빌드 복구를 추가하고, 실행 엔진과 평가 보고서를 나누며 좌표·Align 정답 데이터는 합쳤습니다.

분석 기준 8872e4ed · 현재 구현 완료표나 확정 일정표가 아닙니다.

먼저 빌드·장치 차단·저장 격리를 복구한 뒤 엄격한 상태 판정과 비정상 응답 시험을 연결합니다. 정책 미정 분기는 아래 기준 확정 후 반영합니다.

평가 보고서 통합은 마지막이지만, 정답·기록 형식은 04번에서 먼저 정의합니다. 각 행의 선행 작업은 제안 의존관계이며 담당자·소요일은 별도 배정합니다.

02P0완전 시뮬레이션 실행 차단막

Stage·Vision·Automation·Laser·ATT·PowerMeter 모드를 일괄 확인하고 실제 장치가 섞이면 완전 시뮬레이션 시작을 막습니다.

선행 작업 01		완전 시뮬레이션에서 실제 장치 명령 0건. 혼합 시험은 별도 표시·승인 경로로 분리합니다.
03P0시험 데이터 저장소 격리

복사 Recipe와 전용 Offset·Result·Product·매수 저장소를 적용하고 시험 출처를 기록합니다.

선행 작업 01		시험 전후 생산 파일 해시가 같고, 재시작·모드 변경 후 시험 최신파일이 생산에 자동 반영되지 않습니다.
04P0시나리오 실행 엔진과 가상시간

시나리오 JSON, 고정 난수 seed, 공통 가상시계와 RunId를 만들고 Pause·Resume·이벤트 한 단계 실행을 제공합니다.

선행 작업 01, 02, 03		동일 설정과 seed로 같은 입력·순서·결과를 재현합니다. 자동응답 OFF와 전체 일시정지를 구분합니다.
05P0공통 Stop Cancel Reset 정리

공유 소유권·Task·모션·핸드셰이크·잔여 응답을 묶어 정지하고 새 시험 초기화 범위를 명확히 합니다.

선행 작업 02, 03, 04		다른 메뉴 STOP도 소유 작업에 일관되게 전달되며, 정지·정리 실패 시 재시작이 차단됩니다.
06P1Ready 위치 Busy 엄격 검사

시연용 자동 OK와 검수용 모드를 분리하고 위치 오차·Busy·피드백 유효시간으로 Ready를 판단합니다.

선행 작업 04, 05		미도착·Busy ON·오래된 위치값에서는 PEG 게시·ABLE가 진행되지 않고 우회는 BYPASS로 표시됩니다.
07P1가상 엔코더와 MOF Task 연동

Head별 완료 타이머와 별도로 가상 Stage Y·엔코더 count가 Task·Shot 진행을 결정하는 모드를 추가합니다.

선행 작업 04, 05, 06		Y 정지·Head 미준비·RUN 실패에서 가공이 타이머만으로 완료되지 않으며 W8034와 Process COMPLETE를 구분합니다.
08P1독립 Stage 모사기와 핸드셰이크

가공SW 요청을 관찰하는 독립 Stage 모사기를 만듭니다. DoReady·Process·Review는 3점(ABLE·START·COMPLETE), TPM은 2점(ABLE·COMPLETE), 거래별 양측 OFF 복귀를 구현합니다.

선행 작업 04, 05, 06		준비와 도착 순서를 바꿔도 정상 처리하고, 이전 COMPLETE·순서 역전·OFF 누락을 잘못된 성공으로 소비하지 않습니다.
09P1MELSEC 고장 주입 UI

기존 시험 API를 화면에 연결해 주소·단계별 값 고착·무응답·첫 실패·읽기 오류·연결 해제를 선택합니다.

선행 작업 04, 05, 08		지정한 시점·횟수에만 고장이 발생하고 Timeout·재시도·복귀 결과와 종료 후 설정 해제를 확인합니다.
10P1IOF Buffer Trigger Grab 모사

배열 기록·읽기·Buffer 준비·가상 Y/X 이동·Trigger·Grab·구간 완료를 별개 이벤트로 생성합니다.

선행 작업 04, 07, 08, 09		잘린 배열·잘못된 Count·X 지각·누락 또는 중복 촬영을 검출하고 Buffer 준비를 촬영 완료로 오인하지 않습니다.
11P1Vision 패킷 고장 시험 클라이언트

기존 codec를 사용하는 격리 Vision 클라이언트에 UID·Count NCK·지연·중복·분할 응답 시나리오를 추가합니다.

선행 작업 02, 04, 05, 08		실제 패킷 경로에서 NCK 후 1003 미송신, 재시도 방향·한도와 Line·Point 결과 귀속을 자동 확인합니다.
12P10선 비정상 결과와 완료 합류

Head·Point별 OK·품질 NG·미검출·NCK·무응답과 가공/0선 완료 선후를 선택하고 FollowUp 분기를 연결합니다.

선행 작업 07, 08, 10, 11		최종 0선 결과 전 Process COMPLETE 금지, 현재 MOF 종료 정책 유지, 후속 요청은 NG AND FollowUp ON에서만 발생합니다.
13P1Review 결과 유형과 Retry 정책 분리

품질 NG·미검출·Count NCK·통신 실패를 분리해 재시도·보정 차단·종료·이력에 전달합니다.

기준 확정: 품질 NG 재측정 정책 확정

선행 작업 10, 11		승인된 원인별 정책대로 처리하고 실제 끝점·다음 Line 방향·늦은 결과를 정확히 관리합니다.
14P1좌표 보정 Align 정답 시나리오

Head/Cell·Mask/Beam·부호·좌표계·Align 키·측정 세대별 고정 입력과 기대 Offset·다음 가공좌표를 구성합니다.

기준 확정: Fine 수식·Stage 범위·DistKey 최종 버전 확정

선행 작업 03, 04, 05, 08		Simple 덮어쓰기·Rough 누적·Fine 보간·저장 결과가 정답과 같고, 무효값·이전 Glass 결과가 적용되지 않습니다.
15P1Power 신규 샘플과 장치 고장 모델

샘플 번호·측정시각·유효성·Head·Sensor를 전달하고 램핑·노이즈·파워 저하·ATT 한도·미수렴·공유 센서를 모사합니다.

선행 작업 02, 03, 04, 05		새 유효 샘플만 평균하며 측정 실패를 0 또는 정상 완료로 바꾸지 않고 취소·실패 때 정리 결과를 남깁니다.
16P1AUTO TPM 업무 시퀀스 연결

공통 파워 측정 core를 AUTO의 4신호·결과 저장·W8050 재측정·종료에 연결합니다. 교체가 없으면 일반 경로, 교체 시에는 Shift/실교체 후 기본 측정 1회를 수행합니다.

선행 작업 03, 05, 08, 09, 15		저장 후 COMPLETE, 양측 OFF 복귀, 재측정 중 후속 가공 차단, TPM 동작으로 가공 매수 증가 없음을 확인합니다.
17P1보호윈도우 조건과 전체 완료 연결

기존 매수·TrayCount 경로에 승인된 교체 조건과 ATT 예측 입력을 연결합니다. Stage 모사기는 Shift·실교체·평탄도·TPM·전체 종료를 분리합니다.

기준 확정: PTW 2 OR/3 OR와 ATT 예측 입력·계산 계약 확정

선행 작업 03, 05, 08, 09, 15, 16		승인 조건별 분기·공식 Count 인계가 맞고, 교체·평탄도·TPM 실패 또는 미완료 시 다음 가공을 차단합니다.
18P1완료 펄스 매수 재시작 복구

승인된 edge 보존 또는 ACK 유지 계약을 구현하고 1초 펄스·위상·지터·중복 완료·저장 실패·ON/ON 재시작을 시험합니다.

기준 확정: SectionComplete 펄스/ACK 계약 확정

선행 작업 04, 05, 08, 09, 17		누락·이전 완료 오소비를 검출하고 정확한 Recipe에 매수를 1회 인계하며 실패 시 필요한 요청·차단 상태를 유지합니다.
19P269개 자동 평가와 결과 리포트

평가번호별 시나리오·정답·실제 파형·화면·저장파일을 연결하고 기록·재생 및 자동 판정·보고서를 제공합니다.

선행 작업 04, 05, 06, 07, 08, 09, 10, 11, 12, 13, 14, 15, 16, 17, 18		동일 조건 재실행이 가능하며 PASS·FAIL·BYPASS·BLOCKED·현장 미평가가 근거와 함께 구분됩니다.

구현 전에 확인할 기준

  1. 보호윈도우 교체 조건: 기존 2 OR와 새 첨부 3 OR, ATT 예측 입력·계산 방식.
  2. Fine 보간식: 첨부 선형과 현행 Lagrange 중 승인한 방식.
  3. 0선 통신 주기: 새 첨부의 포인트별 주기와 기존 단일 세션 자료 중 최종 계약. 새 첨부의 큰 주기는 현재 코드와 일치합니다.
  4. Stage 허용 좌표·DistKey 주소·단위·최종 버전.
  5. 품질 NG와 미검출의 재시도 정책, SectionComplete 펄스 또는 ACK 유지 계약.

기준이 미정인 분기는 조건부로 남기되 빌드·격리·공통 기반은 먼저 개발할 수 있습니다.

재사용과 역할 범위

기존 수동 신호 입력, Stage 이동 모델·소유권, MELSEC 고장 API, Vision codec·패킷 API, 측정 주입점과 PowerTable 시험 저장 구조를 재사용합니다.

가공SW는 자기 요청·결과·완료 판단을 개발하고 독립 모사기는 Stage·PLC·Vision의 상대 응답을 제공합니다. Pin·Gate·ACS 내부 제어 전체를 가공SW에 다시 구현하지 않습니다.

실제 PEG·촬영·축 정지·레이저 차단·카세트·가공 정밀도는 별도 현장 검수 대상입니다. 이 개발목록 작성으로 구현·검수 완료를 뜻하지 않습니다.
