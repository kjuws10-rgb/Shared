A3 LD Default Offset · 16분기빔 중심 기준 작업절차
2026-10-28 개정판

포함 내용
- 좌상·우상 Align 측정 → 가운데로 실제 이동 → 도착 엔코더 저장.
- DOE 16개 실제 마크를 측정해, 실제 홀이 없는 가운데의 중심 계산.
- Head 중앙명령(0,0)·추가 Shift0·현재 Default를 적용한 시험가공.
- H4/H5부터 H3/H6 → H2/H7 → H1/H8 순서의 X 조정.
- 상단 기준 Y와 설계 거리·Head별 앞뒤 간격을 이용한 Y 조정.
- 필요한 이동량·Head 방향·현재값을 반영한 추천 새 Default 계산.
- X만/Y만/전체XY 보정 전후 그림과 8Head 계산 예제.
- 개별 이동·시험가공·16마크측정·실패마크재측정·추천/입력·새가공확인·복원 기능.

사용 방법
ZIP을 풀어 HTML을 브라우저로 엽니다. 본문·그림·예제는 인터넷 없이 동작합니다.
상단 목차, 그림 확대, 개발 상세 펼치기, 인쇄 기능이 있습니다.
계산 예제에서 기준값·Head·측정값과 비교 모드를 바꿀 수 있습니다.

구성: 11개 설명 절 / 그림15개(정적14+계산그림1).
렌더링55항목, 개념29항목, 요구21항목 검토 통과.
