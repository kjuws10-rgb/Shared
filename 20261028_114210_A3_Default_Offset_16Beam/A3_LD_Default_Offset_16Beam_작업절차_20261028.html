16분기빔 중심으로 맞추는
스캐너 Default Offset

상단 Align 마크로 기판 기준을 저장하고, 각 스캐너가 만든 16개 마크의 중심을 측정합니다.
목표 위치와의 차이에서 추천 Offset을 계산해 X → Y → 전체 순서로 맞춥니다.

1. 무엇을 맞추는 작업인가요?

기판 중심과 설계 간격에 맞게, 각 스캐너의 가공 위치를 X/Y로 옮기는 작업입니다.

기판 기준

좌상단·우상단 Align 마크의 가운데에서 엔코더값을 저장합니다.

가공 중심

DOE 16분기빔이 만든 마크 16개의 가운데를 계산합니다.

Default Offset

목표 중심과 가공 중심의 차이를 Head별 기본값에 반영합니다.

2. DOE가 장착되면 ‘16개 마크의 가운데’를 구합니다

한 번 가공하면 4×4 배열의 마크가 생깁니다. 가운데에 홀을 하나 더 찾는 작업이 아닙니다.

시험가공 조건을 먼저 맞춥니다

선택 Head의 중앙 명령 (0, 0)에서 한 번 출사합니다. 추가 X/Y Shift는 0으로 두고, 현재 Default X/Y는 적용한 상태로 가공합니다. 이렇게 만든 16개 중심을 그 Head의 현재 가공 중심으로 비교합니다.

  1. 선택 Head로 한 번 시험가공Head 번호와 가공줄을 선택합니다. 가공할 때의 Main Y 위치와 현재 Default를 기록하고, 다른 시험가공과 구분되도록 새 마크 묶음 번호를 붙입니다.
  2. 16개 마크의 위치 측정한 화면에 다 보이면 한 번에 측정하고, 다 보이지 않으면 카메라를 이동해 나누어 측정합니다. 같은 묶음의 16개 마크를 모읍니다.
  3. X 평균·Y 평균 계산각 마크의 위치를 mm로 모은 후, X 16개를 더해 16으로 나누고 Y도 같은 방법으로 계산합니다.
  4. 계산한 중심 표시·이동16/16 측정이 끝나면 중심 좌표를 표시합니다. 이 중심이 해당 Head의 가공 위치입니다.
측정 화면에 꼭 보여줄 것

마크 번호 1~16, 측정한 개수, 각 마크의 X/Y, 계산한 중심 X/Y. 빠진 마크는 해당 마크만 다시 측정한 뒤 중심을 계산합니다.

3. 상단 Align 2개로 기판 기준을 저장합니다

가운데를 계산하는 단계와, 실제 도착한 위치를 저장하는 단계를 나눕니다.

  1. [좌상단 Align 측정]좌측 상단 Align 마크를 Review 화면 십자선 중앙에 맞추고 [현재 위치 저장]을 누릅니다. Review X와 Main Y 엔코더값을 mm로 저장합니다.
  2. [우상단 Align 측정]우측 상단 Align 마크도 같은 방법으로 측정합니다. 좌·우 위치를 화면에 함께 표시합니다.
  3. [가운데 계산]두 X값의 평균과 두 Y값의 평균을 계산합니다. 화면에는 계산 위치를 먼저 보여줍니다.
  4. [가운데로 이동]계산 위치로 Review X와 Main Y를 이동합니다. 이동 중에는 저장 버튼을 끄고, 도착 확인 후 켭니다.
  5. [기판 기준 저장]실제 도착한 엔코더값을 저장합니다. 이름은 ‘기판 중앙 X’와 ‘상단 기준 Y’로 표시합니다.
Y 기준은 이렇게 연결합니다

상단 Align 두 개로 얻은 Y는 상단 기준줄입니다. 가공할 줄의 목표 Y는 여기에 ‘상단 기준에서 가공줄까지의 설계 거리’를 더해 구합니다.

4. 카메라에서 본 위치를 쉽게 이해하면

마크를 화면 중앙에 맞추고 저장하면, 작업자는 복잡한 좌표 계산을 하지 않아도 됩니다.

5. X Default: 중앙 4·5번부터 좌우 간격을 맞춥니다

저장한 기판 중심에서 각 Head의 목표 X를 구하고, 실제 16마크 중심과 비교합니다.

  1. H4·H5 시험가공 → 각각 16개 측정두 Head를 구분해서 가공하고 각 Head의 중심 X를 계산합니다.
  2. [X 추천값 계산]설계 간격과 저장된 기판 중심으로 목표 X를 구합니다. 목표에서 실측 중심을 빼 필요한 이동량을 구합니다.
  3. [H4 X 입력] / [H5 X 입력]Head별 방향을 반영한 추천 새 Default X를 입력합니다. 현재값·입력할 보정량·추천 새값을 함께 보여줍니다.
  4. [새 가공으로 X 확인]바뀐 Default로 새 마크를 가공합니다. 16개를 다시 측정해 목표 X와 차이가 줄었는지 확인합니다.
  5. 3·6 → 2·7 → 1·8도 같은 방법모든 Head의 목표는 저장한 기판 중심과 설계 간격에서 직접 구합니다. 바로 옆 Head의 측정 오차를 이어받지 않습니다.

6. Y Default: 설계된 가공줄에 앞뒤 위치를 맞춥니다

먼저 ‘어느 Y줄이 목표인지’를 정하고, 각 Head의 측정 중심 Y를 그 줄에 맞춥니다.

  1. 각 Head의 목표 Y를 화면에 표시상단 기준 Y, 가공줄까지 설계 거리, Head별 앞뒤 간격을 합쳐 목표를 계산합니다.
  2. X 조정 후 새 마크를 가공·측정현재 Default가 반영된 16개 마크를 측정합니다. Y값 16개를 평균해 중심 Y를 구합니다.
  3. [Y 추천값 계산] → [선택 Head Y 입력]목표 Y에서 측정 중심 Y를 뺍니다. Head별 방향을 반영한 새 Default Y를 입력합니다.
  4. [새 가공으로 Y 확인]16개 중심을 다시 구해 목표 Y와 비교합니다. H4·H5부터 나머지 Head도 같은 방법으로 진행합니다.
설계상 앞뒤 간격은 남겨 둡니다

Y 보정은 모든 Head를 무조건 같은 Y에 모으는 작업이 아닙니다. Head별 목표 Y가 다르면 그 목표 차이를 유지하면서 오차만 줄입니다.

7. X만 맞춘 결과와 Y까지 맞춘 결과는 다릅니다

초록 점선은 목표 중심, 파란 16마크 묶음은 실제 가공 위치입니다. 오차는 확대해서 그렸습니다.

8. 추천 Offset은 ‘입력란에 저장할 새 값’으로 보여줍니다

위치 차이를 그대로 입력하지 않고, 각 Head의 이동 방향과 현재 Default를 반영합니다.

필요한 이동 = 목표 중심 − 측정 중심
추천 새 Default = 현재 Default + Head 방향을 반영한 입력 보정량

측정 중심현재 Default로 가공한 16개 마크의 계산 중심

개발 기능 · Head별 방향을 처음 확인하는 방법
  1. 현재 Default로 시험가공 A16개 중심 X/Y와 현재 Default X/Y를 저장합니다.
  2. X Default만 설정한 시험량만큼 변경 → 새 시험가공 B새 중심이 어느 방향으로 얼마나 변했는지 X와 Y를 모두 기록합니다. X 입력을 늘릴 때 측정 X가 늘면 같은 방향, 줄면 반대 방향입니다.
  3. Y도 같은 방법으로 시험X 시험 전 값으로 돌아간 뒤 Y만 변경해 새 마크를 측정합니다. 입력값 1 mm당 측정 중심이 몇 mm 변하는지 저장합니다.
  4. 방향·이동 비율을 추천 계산에 사용X 입력 때문에 Y도 함께 움직이는 Head는 두 축 변화를 함께 계산합니다. 작업자 화면에는 변환이 끝난 추천 X/Y만 표시합니다.
추천 계산용 데이터

측정 당시의 Default와 방향·이동 비율을 묶어서 저장합니다. 그 뒤 설정값이 바뀌면 새로 측정한 결과로 추천값을 다시 계산합니다.

9. 값을 바꾸며 추천값과 전후 결과를 비교합니다

H4·H5부터 선택해 보세요. 필요한 이동과 추천 새값이 다른 이유를 숫자로 확인할 수 있습니다.

Head목표 X실측 X필요 이동 X추천 새 X필요 이동 Y추천 새 Y반영 후 X/Y 오차

계산 예제입니다. 홀수 Head의 설계 Y 간격은 +2 mm, 짝수 Head는 0 mm로 두었습니다. Head별 Default 입력 방향도 예제에 따라 서로 다르게 설정했습니다.

10. Default Offset 메뉴는 단계별 버튼으로 만듭니다

작업자는 한 Head씩 실행할 수도 있고, 같은 기능을 연결한 자동 셋업으로 진행할 수도 있습니다.
