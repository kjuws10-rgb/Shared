실제 A3 571파일 중 558개를 검색하며 편집299/읽기전용259/정상제외13(DLL12)/실패0이었다. Qwen3-8B를 CPU4스레드·4K 문맥으로 재사용했다. 새 5GB 모델 전체 다운로드는 반복하지 않았다. 실제 단일 파일 읽기 결과는 별도 QA 원문으로 검증하며 이를 일반 코드 생성 정확도나 Codex 동급 검증으로 확대하지 않는다.

검증에서 2K 문맥 부족과 4K 프롬프트 과대 이스케이프·신규 형식 참조 누락을 찾아 수정했다. 읽기 전용 모델 입력에는 실제 행번호를 붙이고 구조화된 원문 인용과 편집용 원문은 보존했다.

A3 전체 빌드는 기존 `Drilling.Common.Log`/`CLogManager` 누락 19오류가 남는다. 준비 완료와 빌드 합격을 구분해 경고로 표시한다. 읽기 입력으로 사용한 A3 기준 clone의 Commit·추적 파일 무변경을 확인했으며, 검증 중 생산 A3 원본에는 Commit/Push하지 않았다. Shared는 이후 이 배포 자료를 공개하는 저장소다.

별도 새 노트북의 OS 초기 설치, 물리 NIC 분리, 실장비 가공·스캐너 실행, A3 대형 모델 가중치 학습은 미검증이다. 지식 갱신은 검색·개발 스타일 갱신이고 가중치 학습과 다르다.

이 공개 요약은 공유 시점에 저장소 범위 표현을 명확히 했다. 실행 ZIP 안의 검증 요약은 제작 완료 시점 기록이며, 실행 ZIP과 소스 ZIP의 바이트는 변경하지 않았다.
