자동으로 준비하는 범위

  • 대상 주소: https://github.com/kjuws10-rgb/A3Drilling.git / master
  • 코드: 이미 선택한 정상 작업 폴더를 재사용합니다. 없으면 새 사본을 받아 연결하고 Push URL을 비활성화합니다. 기존 코드에 강제 Pull·병합·덮어쓰기를 하지 않습니다.
  • Git: 기존 Git을 우선 사용합니다. 없으면 온라인 준비에서 고정 버전의 공식 MinGit을 해시 확인 후 로컬 폴더에 준비합니다.
  • 모델: 기존 검증 묶음, App/Models, 다운로드 캐시를 우선 사용합니다. 없으면 Qwen3-8B Q4_K_M 약 5GB를 받습니다. CPU 스레드·문맥 크기는 PC 메모리를 보고 설정합니다.
  • 검색: 현재 코드와 추가 자료를 색인하고 A3 개발 스타일을 갱신합니다. 실제 모델 가중치 학습은 별도 기능입니다.
  • 기준 빌드: 수정 전 오류가 있는지 검사합니다. 기존 오류가 있으면 경고와 로그를 남기고 채팅 준비 상태와 구분합니다.

화면은 간단하게, 세부 기능은 필요할 때

기본 화면에는 자동 준비 상태와 대화창을 둡니다. 모델 선택·작업 경로·파일 인식 결과·자료 추가·백업·온라인 새 사본 전환은 고급 설정 안에서 확인합니다.

실행 상태는 모델의 답변과 별도로 표시합니다. ‘파일 변경’, ‘빌드 실행’ 표시는 호스트가 실제 동작을 수행했을 때만 켜집니다. 빌드가 실패해도 이미 적용된 파일을 적용 전 상태라고 표시하지 않습니다.

노트북 준비와 오프라인 사용

  • Windows x64, 기본 8B 모델에는 RAM 16GB 이상이 필요하며, 다른 앱과 함께 사용할 때는 32GB 이상을 권장합니다. 여유 메모리와 코드 크기에 따라 속도가 달라지고 CPU 답변은 수 분 걸릴 수 있습니다. Pi 도구 사용에 필요한 4K 문맥을 확보하지 못하면 채팅 준비를 차단하고 앱 정리 또는 작은 모델 사용을 안내합니다.
  • 최초 다운로드·설치에는 코드와 전체 백업 공간 외에 약 20GB 이상의 여유 공간을 권장합니다. 모델 캐시와 실행용 모델 사본을 보관합니다.
  • 인터넷이 되는 곳에서 Setup-A3.cmd를 완료한 같은 Windows 사용자·PC로 현장에 들어가면 이후 실행·검색·채팅은 오프라인으로 동작합니다. 다른 노트북도 현장 반입 전에 동일한 한 번의 준비를 완료하세요.
  • App 폴더 전체를 유지하세요. EXE 하나만 복사하면 Node·Pi·실행기·SDK가 없어 준비가 차단됩니다.
  • 최초 Microsoft VC++ 구성 요소가 없는 PC는 동봉된 공식 설치 화면에서 OS 설치 승인이 필요할 수 있습니다. Git·Node·모델을 수동 설치할 필요는 없습니다.
  • 새 코드는 고급 설정의 온라인 새 사본 준비/열기로 전환할 수 있습니다. 기존 작업과 백업은 보존됩니다. 자동 준비 버튼은 기존 작업 폴더가 있으면 이를 우선 사용합니다.
검증 범위

자동 준비·백업·자연어 적용/원복은 가상 프로젝트를 포함한 프로그램 검사로 확인합니다. 실제 A3 사본에서는 온라인 준비·파일 분류·읽기·기준 빌드와 로컬 모델 연결을 확인합니다. 별도 새 노트북에 처음 설치하는 전체 과정과 설비 운전은 미검증입니다. A3 전체 소스의 기존 빌드 오류는 별도 해결 대상이며, 실장비 동작 합격·Codex 동급 정확도·A3 대형 모델 가중치 학습을 보장하는 자료는 아닙니다.
